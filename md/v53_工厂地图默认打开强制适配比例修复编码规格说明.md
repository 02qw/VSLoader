# v53 工厂地图默认打开强制适配比例修复编码规格说明

## 1. 问题背景

v52 增加了地图运行时诊断信息。

用户通过截图确认：

```text
地图默认打开时显示不全。
窗口手动拉大后，地图逐步显示完整。
```

底部诊断信息暴露出关键问题：

```text
vp:605x609 | scale:1 | bounds:1248x841
```

这个状态在数学上不合理：

```text
视口宽度 605
内容边界宽度 1248
如果要完整显示，scale 必须小于 1
scale 应约为 0.4 到 0.5
```

但默认打开时实际为：

```text
scale:1
```

因此右侧内容必然超出当前视口，并被 `MapViewport ClipToBounds=True` 裁剪。

## 2. 已定位根因

这次问题不是：

```text
画布太小
JSON 缺少右侧设备
设备坐标超出 canvas
窗口右侧存在不可绘制禁区
```

真实问题是：

```text
默认打开地图窗口时，首次 FitToView 没有可靠地把地图缩小到当前视口。
旧的 scale=1 状态残留。
只有当用户手动拉大窗口触发 SizeChanged 后，地图才重新计算比例并逐步显示完整。
```

用户截图中的诊断变化也验证了这一点：

```text
vp:605x609 scale:1 bounds:1248x841
vp:720x609 scale:0.519 bounds:1248x841
vp:992x787 scale:0.737 bounds:1248x841
vp:1293x847 scale:0.921 bounds:1248x841
vp:1426x919 scale:1 bounds:1248x841
```

说明：

1. 内容边界一直是 `1248x841`。
2. 窗口变大后 `scale` 会重新计算。
3. 默认打开时没有正确执行初始适配。

## 3. 需求目标

修复默认打开地图窗口时的初始适配问题。

修复后：

1. 地图默认打开时，如果视口小于内容边界，`scale` 必须小于 1。
2. 地图默认打开时能看到完整设备布局。
3. 不需要用户手动拉大窗口才能完整显示。
4. 后续用户滚轮缩放、拖动画布、编辑拖动设备功能不回退。
5. 调整窗口大小后仍可重新适配。
6. 状态栏 debug 摘要不能重复追加成长串文本。

## 4. 核心实现思路

将当前模糊的：

```text
ResetMapView
ScheduleResetMapView
CalculateFitScale
CenterMap
```

重构为一个语义明确的方法：

```csharp
private bool FitMapToView()
```

`FitMapToView()` 只负责一件事：

```text
根据当前 MapViewport 尺寸和内容边界，强制计算并应用默认全局适配比例。
```

它应该保证：

```text
如果 ContentBounds.Width > MapViewport.ActualWidth，则 fitScale < 1。
如果 ContentBounds.Height > MapViewport.ActualHeight，则 fitScale < 1。
如果内容本身小于视口，则 fitScale 可以为 1。
```

## 5. FitMapToView 规则

输入：

```text
MapViewport.ActualWidth
MapViewport.ActualHeight
ContentBounds
ViewPadding
```

计算：

```csharp
availableWidth = Math.Max(1, MapViewport.ActualWidth - ViewPadding * 2);
availableHeight = Math.Max(1, MapViewport.ActualHeight - ViewPadding * 2);

scaleX = availableWidth / contentBounds.Width;
scaleY = availableHeight / contentBounds.Height;

fitScale = Math.Min(1.0, Math.Min(scaleX, scaleY));
userScale = 1.0;
```

居中：

```csharp
mapOffsetX = (MapViewport.ActualWidth - contentBounds.Width * fitScale) / 2
    - contentBounds.Left * fitScale;

mapOffsetY = (MapViewport.ActualHeight - contentBounds.Height * fitScale) / 2
    - contentBounds.Top * fitScale;
```

应用：

```csharp
MapScaleTransform.ScaleX = fitScale;
MapScaleTransform.ScaleY = fitScale;
MapTranslateTransform.X = mapOffsetX;
MapTranslateTransform.Y = mapOffsetY;
```

返回：

```text
true 表示成功适配。
false 表示当前视口或内容边界尚未 ready。
```

## 6. 调度策略

当前问题说明单次 `DispatcherPriority.Loaded/Render` 仍可能不够可靠。

推荐改为：

```text
请求适配 -> DispatcherPriority.ContextIdle 执行 -> 如果失败则有限重试
```

原因：

```text
ContextIdle 比 Loaded/Render 更靠后，更适合等待窗口首次布局稳定。
```

建议实现：

```csharp
private bool pendingFitToView;
private int fitRetryCount;
private const int MaxFitRetryCount = 12;

private void RequestFitMapToView()
{
    if (pendingFitToView)
    {
        return;
    }

    pendingFitToView = true;
    Dispatcher.BeginInvoke(new Action(() =>
    {
        pendingFitToView = false;
        if (FitMapToView())
        {
            fitRetryCount = 0;
            return;
        }

        if (IsVisible && fitRetryCount < MaxFitRetryCount)
        {
            fitRetryCount++;
            RequestFitMapToView();
        }
    }), DispatcherPriority.ContextIdle);
}
```

## 7. 触发时机

必须在以下时机请求适配：

1. `RenderMap()` 完成绘制后。
2. `ContentRendered` 事件触发后。
3. `Loaded` 事件触发后。
4. `MapViewport.SizeChanged` 后。
5. 地图窗口重新显示后。

建议在构造函数中订阅：

```csharp
Loaded += (_, _) => RequestFitMapToView();
ContentRendered += (_, _) => RequestFitMapToView();
```

说明：

```text
RenderMap 完成后请求一次。
Loaded / ContentRendered 再请求一次。
SizeChanged 再请求一次。
重复请求通过 pendingFitToView 合并。
```

## 8. 状态栏 Debug 文本修复

当前状态栏会重复追加：

```text
设备：53 | 连线：0 | vp:605x609 | scale:1 | bounds:1248x841 | vp:...
```

这会干扰观察，也不适合作为长期状态显示。

必须修复为：

1. 保留基础状态文本字段。
2. 每次更新状态栏时重新生成完整文本。
3. 不在原文本后无限追加。

推荐新增字段：

```csharp
private string baseStatusText = "地图未加载";
```

方法：

```csharp
private void SetStatusText(string text)
{
    baseStatusText = text;
    RefreshStatusText();
}

private void RefreshStatusText()
{
#if DEBUG
    StatusText.Text = $"{baseStatusText} | vp:{...} | scale:{...} | bounds:{...}";
#else
    StatusText.Text = baseStatusText;
#endif
}
```

所有原先：

```csharp
StatusText.Text = ...
AppendDebugStatusSummary()
```

应改为：

```csharp
SetStatusText(...)
```

或：

```csharp
RefreshStatusText()
```
