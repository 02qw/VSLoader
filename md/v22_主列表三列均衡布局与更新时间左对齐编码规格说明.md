# v22 主列表三列均衡布局与更新时间左对齐编码规格说明

## 1. 需求背景

当前 VSLoader 主列表已经具备：

- 单行快捷项展示。
- 名称、备注、更新时间三列。
- 列宽不可拖动。
- 列头点击三态排序。
- 窗口默认比例接近当前较舒适的紧凑状态。

但当前列表仍存在视觉问题：

1. 三列之间的空白不均匀。
2. 名称列和备注列之间有较大空白。
3. 备注列和更新时间列之间有较大空白。
4. `更新时间` 列头和时间内容的相对位置关系，与 `名称`、`备注` 两列不一致。
5. 时间列右对齐导致整体观感不协调。

本次 v22 需求需要优化主列表三列的空间分配和对齐方式，让三列看起来更均衡、统一、稳定。

## 2. 需求目标

本次开发目标：

1. 三列间距更均匀。
2. 三列都采用一致的左对齐关系。
3. `更新时间` 列头不再强制右对齐。
4. `更新时间` 内容不再强制右对齐。
5. 保持当前窗口打开比例和整体舒适度。
6. 保持单行快捷项展示。
7. 保持排序功能。
8. 保持列宽不可拖动。
9. 不改变业务逻辑。

## 3. 修改范围

主要修改文件：

- `VSLoader\MainWindow.xaml`

原则上不需要修改：

- `VSLoader\MainWindow.xaml.cs`
- `VSLoader\ViewModels\MainViewModel.cs`
- `VSLoader\Services\ShortcutSortService.cs`
- 其他服务层和模型层代码

本次属于列表视觉布局优化。

## 4. 当前问题来源

当前列宽大致为：

```text
名称：280
备注：*
更新时间：180
```

其中备注列使用 `*` 吃掉所有剩余空间，导致：

- 名称和备注之间存在明显空白。
- 备注和更新时间之间存在明显空白。
- 更新时间列被推到较远位置。

当前时间列还存在右对齐：

```xml
<Setter Property="TextAlignment" Value="Right" />
<Setter Property="HorizontalContentAlignment" Value="Right" />
```

导致：

```text
名称列：列头和内容从左侧开始
备注列：列头和内容从左侧开始
更新时间列：列头和内容偏右
```

三列视觉关系不一致。

## 5. 新布局原则

本次采用统一原则：

```text
三列都左对齐，三列宽度按比例分配。
```

具体原则：

- 名称列头左对齐。
- 名称内容左对齐。
- 备注列头左对齐。
- 备注内容左对齐。
- 更新时间列头左对齐。
- 更新时间内容左对齐。
- 三列采用比例列宽，减少无意义大片空白。

## 6. 推荐列宽策略

推荐将列宽改为：

```text
名称：1*
备注：1.6*
更新时间：1*
```

XAML 可写为：

```xml
Width="1*"
Width="1.6*"
Width="1*"
```

如果 WPF `DataGridLength` 对小数星号表现不稳定，可使用整数比例：

```text
名称：5*
备注：8*
更新时间：5*
```

优先推荐整数比例：

```xml
名称：5*
备注：8*
更新时间：5*
```

理由：

- 名称和更新时间列宽接近。
- 备注列略宽。
- 三列会随窗口等比例伸缩。
- 不会出现备注列无限吃掉所有剩余空间的情况。

## 7. 更新时间列对齐调整

### 7.1 移除独立右对齐 HeaderStyle

当前 `更新时间` 列可能有单独：

```xml
<DataGridTextColumn.HeaderStyle>
    ...
    <Setter Property="HorizontalContentAlignment" Value="Right" />
    ...
</DataGridTextColumn.HeaderStyle>
```

本次要求移除该独立 `HeaderStyle`。

让 `更新时间` 列头使用全局 `DataGrid.ColumnHeaderStyle`，和 `名称`、`备注` 一致。

### 7.2 时间内容改为左对齐

当前可能有：

```xml
<Setter Property="TextAlignment" Value="Right" />
```

本次要求移除或改为：

```xml
<Setter Property="TextAlignment" Value="Left" />
```

### 7.3 保留时间内容样式

可以继续保留：

```xml
<Setter Property="Foreground" Value="#6B7280" />
<Setter Property="FontSize" Value="13" />
<Setter Property="TextTrimming" Value="CharacterEllipsis" />
<Setter Property="VerticalAlignment" Value="Center" />
```

只取消右对齐。

## 8. 排序箭头要求

当前 v19 已实现表头文字箭头：

```text
名称 ↑
备注 ↓
更新时间 ↑
```

本次不改变排序逻辑。

但由于更新时间列头不再右对齐，排序箭头也应跟随标题从列左侧显示：

```text
更新时间 ↑
```

不需要额外处理，只要移除右对齐 HeaderStyle 即可。

## 9. 窗口尺寸要求

保持 v16 后的窗口尺寸策略，不修改：

```xml
Width="960"
Height="720"
MinWidth="900"
MinHeight="560"
```

用户当前认可此窗口比例，不要在本次改动中调整窗口默认尺寸。

## 10. 保持不变的内容

必须保持：

- 单行一项。
- 主列表行高。
- 顶部按钮布局。
- 列宽不可拖动。
- 列顺序不可拖动。
- 搜索过滤。
- 三态排序。
- 显式文字箭头。
- 右键菜单。
- 双击打开。
- AdminUI 功能。
- 自动获取连接功能。

## 11. 不允许改变的内容

本次不允许：

- 恢复目标路径列。
- 改成双行列表。
- 改成卡片列表。
- 改变窗口尺寸。
- 改变排序算法。
- 改变业务逻辑。
- 允许用户拖动列宽。
- 允许用户拖动列顺序。

## 12. 验收标准

### 12.1 三列间距

启动应用后：

- 名称、备注、更新时间三列之间间距更均匀。
- 不再出现大片无意义空白。
- 备注列仍比名称和更新时间略宽。

### 12.2 对齐一致性

启动应用后：

- `名称` 列头和名称内容左对齐。
- `备注` 列头和备注内容左对齐。
- `更新时间` 列头和时间内容左对齐。
- 三列的“列头相对于子项”的位置关系一致。

### 12.3 信息不遮挡

- 名称过长时使用省略号。
- 备注过长时使用省略号。
- 更新时间应尽量完整显示。
- 不出现内容相互遮挡。

### 12.4 排序功能

- 点击 `名称`、`备注`、`更新时间` 仍可排序。
- 三态排序仍正常。
- 箭头仍正常显示/消失。

### 12.5 窗口比例

- 程序打开后的窗口比例和当前舒适观感保持一致。
- 不恢复横向过长窗口。

### 12.6 编译验收

执行：

```powershell
dotnet build .\VSLoader.sln
```

期望：

```text
0 warnings
0 errors
```

如果提示 `VSLoader.exe` 被占用，说明程序正在运行，应先关闭 VSLoader 后重新构建。

## 13. 建议实施步骤

1. 打开 `VSLoader\MainWindow.xaml`。
2. 找到三列 `DataGridTextColumn`。
3. 将列宽调整为：
   - 名称：`5*`
   - 备注：`8*`
   - 更新时间：`5*`
4. 删除 `更新时间` 列独立 `HeaderStyle`。
5. 将 `更新时间` 内容的 `TextAlignment` 改为 `Left` 或移除。
6. 保留时间列字体和颜色弱化样式。
7. 编译项目。
8. 手动验证列间距、对齐和排序箭头。

## 14. 明确不做的事情

本次不做：

- 调整窗口大小。
- 调整顶部工具区。
- 修改排序状态机。
- 修改弹窗组件。
- 修改业务功能。
