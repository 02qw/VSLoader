# v99 地图窗口自动获取连接进度遮罩归属编码规格说明

## 1. 背景

v98 已经在工厂地图窗口增加了“自动获取连接”按钮。

当前按钮点击后会复用主界面的：

```csharp
MainViewModel.DownloadAdminUiLinksCommand
```

下载逻辑本身正确，但是进度遮罩仍然显示在主界面中。用户在地图窗口点击按钮后，视觉反馈却出现在左侧主窗口，会造成操作归属感不清晰。

因此需要调整为：

- 如果用户从主界面点击“自动获取连接”，进度遮罩继续显示在主界面。
- 如果用户从地图窗口点击“自动获取连接”，进度遮罩显示在地图窗口内部。

## 2. 目标

在不复制 AdminUI 下载逻辑的前提下，实现 Busy 进度遮罩显示位置的归属切换。

地图窗口触发自动获取连接时：

- 地图窗口内部显示覆盖遮罩。
- 遮罩内容与主界面一致，包括：
  - 忙碌标题
  - 进度条
  - 当前进度文字
  - 当前处理项文字
- 地图窗口遮罩显示期间，地图窗口内容不可继续操作。
- 下载完成或失败后，地图窗口遮罩自动消失。

主界面触发自动获取连接时：

- 原有主界面遮罩行为保持不变。

## 3. 设计原则

### 3.1 下载逻辑继续唯一

不允许在 `FactoryMapWindow` 中重新实现 AdminUI 下载流程。

仍然统一复用：

```csharp
MainViewModel.DownloadAdminUiLinksCommand
```

以及它内部已有的：

- Busy 状态控制
- AdminUI 网络预检查
- 下载进度更新
- 结果统计
- 异常捕获
- 成功/失败提示

### 3.2 只分离“显示位置”

本次不改变下载业务，只增加一个轻量的 Busy 遮罩显示归属机制。

建议引入一个简单状态：

```csharp
BusyOverlayHost
```

用于描述当前 Busy 遮罩应该显示在哪里。

可选值建议：

```csharp
Main
Map
```

或者使用布尔属性：

```csharp
IsMainBusyOverlayVisible
IsMapBusyOverlayVisible
```

实际实现时以最小修改为优先。

## 4. 影响范围

主要修改：

- `VSLoader/ViewModels/MainViewModel.cs`
- `VSLoader/MainWindow.xaml`
- `VSLoader/MainWindow.xaml.cs`
- `VSLoader/Views/FactoryMapWindow.xaml`
- `VSLoader/Views/FactoryMapWindow.xaml.cs`

可能新增或调整测试：

- Busy 遮罩归属判断测试
- 地图入口触发时遮罩宿主切换测试

不修改：

- `AdminUiService`
- AdminUI 下载地址拼接算法
- AdminUI 文件保存位置
- 单个快捷项右键获取 AdminUI 连接逻辑
- 主界面按钮的命令绑定方式

## 5. 现状分析

当前 Busy 状态集中在 `MainViewModel` 中：

```csharp
IsBusy
BusyMessage
BusyProgressValue
BusyProgressMaximum
BusyProgressText
BusyCurrentItemText
```

主界面遮罩在 `MainWindow.xaml` 中直接绑定：

```xml
Visibility="{Binding IsBusy, Converter={StaticResource BooleanToVisibilityConverter}}"
```

地图窗口当前没有绑定 `MainViewModel` 的 Busy 状态，也没有自己的 Busy 遮罩层。

v98 中地图按钮通过 `MainWindow.DownloadAdminUiLinksFromMap()` 触发主命令，因此下载期间 `IsBusy` 会变为 `true`，主界面遮罩自然出现。

本次需要保留这套状态数据，但让地图窗口也能显示这些状态。

## 6. 推荐实现方案

### 6.1 MainViewModel 增加 Busy 遮罩宿主

新增枚举：

```csharp
public enum BusyOverlayHost
{
    Main,
    Map
}
```

或等价内部类型。

`MainViewModel` 增加属性：

```csharp
private BusyOverlayHost busyOverlayHost = BusyOverlayHost.Main;
public BusyOverlayHost BusyOverlayHost { get; set; }
```

并提供派生属性：

```csharp
public bool IsMainBusyOverlayVisible => IsBusy && BusyOverlayHost == BusyOverlayHost.Main;
public bool IsMapBusyOverlayVisible => IsBusy && BusyOverlayHost == BusyOverlayHost.Map;
```

注意：

- `OnIsBusyChanged` 时需要通知两个派生属性变化。
- `OnBusyOverlayHostChanged` 时也需要通知两个派生属性变化。

### 6.2 主界面遮罩绑定改为主界面可见属性

`MainWindow.xaml` 原本绑定：

```xml
Visibility="{Binding IsBusy, Converter={StaticResource BooleanToVisibilityConverter}}"
```

改为：

```xml
Visibility="{Binding IsMainBusyOverlayVisible, Converter={StaticResource BooleanToVisibilityConverter}}"
```

这样地图入口触发时，主界面不会再显示遮罩。

### 6.3 地图窗口增加 Busy 遮罩层

`FactoryMapWindow.xaml` 最外层建议改为 `Grid` 包裹原有内容：

```xml
<Grid>
    <DockPanel>
        原有地图窗口内容
    </DockPanel>

    <Border Visibility="{Binding IsMapBusyOverlayVisible, Converter={StaticResource BooleanToVisibilityConverter}}">
        进度卡片
    </Border>
</Grid>
```

遮罩样式应参考主界面现有遮罩：

- 半透明黑色背景
- 白色居中卡片
- 进度条
- 文本绑定相同 Busy 字段

地图窗口遮罩卡片宽度建议略小于主窗口，例如：

```xml
Width="420"
MaxWidth="520"
```

避免地图窗口较窄时内容溢出。

### 6.4 地图窗口绑定 MainViewModel

创建 `FactoryMapWindow` 后，应让地图窗口可以绑定到主界面的 `MainViewModel`。

推荐在 `MainWindow` 创建地图窗口时设置：

```csharp
_factoryMapWindow.DataContext = DataContext;
```

注意：

- 不改变地图窗口原有构造函数职责。
- 地图窗口现有逻辑主要使用控件名和委托，不依赖自己的 ViewModel，因此共享 `DataContext` 风险较低。
- 如果后续地图窗口有独立 ViewModel，再考虑拆分 Busy 状态代理对象。

### 6.5 地图入口触发前设置遮罩宿主

`MainWindow.DownloadAdminUiLinksFromMap()` 中，在执行命令前设置：

```csharp
viewModel.BusyOverlayHost = BusyOverlayHost.Map;
```

执行结束后恢复：

```csharp
viewModel.BusyOverlayHost = BusyOverlayHost.Main;
```

推荐使用：

```csharp
try
{
    viewModel.BusyOverlayHost = BusyOverlayHost.Map;
    await viewModel.DownloadAdminUiLinksCommand.ExecuteAsync(null);
}
finally
{
    viewModel.BusyOverlayHost = BusyOverlayHost.Main;
}
```

这样即使下载异常，也不会让后续 Busy 遮罩继续错误显示在地图窗口。

### 6.6 主界面入口保持默认宿主

主界面按钮无需改命令绑定。

为了稳妥，可以在 `DownloadAdminUiLinksAsync()` 开始前确保默认宿主不被旧状态污染，但不要覆盖地图入口刚设置的 `Map`。

推荐更保守的方式：

- 只在地图入口显式设置 `Map`。
- 所有 Busy 结束清理时恢复为 `Main`。

## 7. 行为要求

### 7.1 主界面点击自动获取连接

预期：

- 主界面显示 Busy 遮罩。
- 地图窗口不显示 Busy 遮罩。
- 下载逻辑与原来一致。

### 7.2 地图窗口点击自动获取连接

预期：

- 地图窗口显示 Busy 遮罩。
- 主界面不显示 Busy 遮罩。
- 下载逻辑与主界面按钮一致。
- 下载期间地图窗口不可继续点节点、拖动画布、切换按钮。

### 7.3 地图窗口关闭或隐藏

如果下载期间地图窗口被关闭或隐藏，应避免崩溃。

推荐策略：

- 遮罩只是绑定显示，不拥有下载任务。
- 下载任务仍由 `MainViewModel` 执行。
- 如果地图窗口关闭，下载可继续完成。
- `finally` 中恢复 `BusyOverlayHost = Main`。

### 7.4 命令不可执行

如果 `DownloadAdminUiLinksCommand.CanExecute(null)` 为 `false`：

- 不切换 Busy 宿主。
- 不显示地图遮罩。
- 不重复执行命令。

### 7.5 其他 Busy 操作

软件更新、全局配置导入导出等其他 Busy 操作默认仍显示在主界面。

本次只改变“地图窗口入口触发自动获取连接”这一条路径。

## 8. UI 要求

地图窗口 Busy 遮罩视觉应与主界面一致，但尺寸适配地图窗口：

- 背景：`#80000000`
- 卡片背景：白色
- 卡片边框：`#DDE1E7`
- 圆角：`6`
- 内边距：`24`
- 标题字号：`16`
- 进度条高度：`10`
- 文本居中、允许换行

遮罩应覆盖：

- 顶部工具栏
- 地图画布
- 底部状态栏

这样用户不会在下载过程中继续操作地图。

## 9. 测试建议

建议新增或调整测试：

1. `IsMainBusyOverlayVisible`：
   - `IsBusy = true` 且宿主为 `Main` 时为 `true`。
   - `IsBusy = true` 且宿主为 `Map` 时为 `false`。

2. `IsMapBusyOverlayVisible`：
   - `IsBusy = true` 且宿主为 `Map` 时为 `true`。
   - `IsBusy = false` 时始终为 `false`。

3. 地图入口命令不可执行：
   - `CanExecute = false` 时不切换宿主、不执行命令。

4. 地图入口执行完成：
   - 执行前切换为 `Map`。
   - 执行结束后恢复为 `Main`。

如果 UI 层测试成本较高，优先覆盖 ViewModel 派生属性和入口判断函数。

## 10. 验收标准

满足以下条件即完成：

- 主界面点击“自动获取连接”时，进度遮罩仍显示在主界面。
- 地图窗口点击“自动获取连接”时，进度遮罩显示在地图窗口内部。
- 地图入口触发时，主界面不再同时显示进度遮罩。
- 下载逻辑仍然复用 `MainViewModel.DownloadAdminUiLinksCommand`。
- 没有新增第二套 AdminUI 下载逻辑。
- 下载完成、失败、异常后 Busy 遮罩归属恢复正常。
- `dotnet test .\VSLoader.sln -c Debug --no-restore` 通过。
- `dotnet build .\VSLoader.sln -c Debug --no-restore` 通过。
