# v39 单修饰键键盘快捷键支持与高风险组合拦截编码规格说明

## 1. 需求背景

当前 VSLoader 已经支持全局快捷键唤起或隐藏程序窗口。

现有键盘快捷键规则要求：

```text
至少两个修饰键 + 一个主键
```

例如当前允许：

```text
Ctrl + Alt + V
Ctrl + Shift + Space
Alt + Shift + F8
```

但用户希望支持更轻量的两个按键组合，例如：

```text
Alt + V
Ctrl + V
Shift + V
```

也就是：

```text
一个修饰键 + 一个主键
```

本次需求采用方案 B：允许单修饰键键盘快捷键，同时保留系统高风险组合拦截。

## 2. 需求目标

调整键盘快捷键校验规则，使程序支持：

```text
Alt + V
Ctrl + V
Shift + V
Ctrl + Alt + V
Ctrl + Shift + V
Alt + Shift + V
Ctrl + Alt + Shift + V
```

继续禁止：

```text
V
Ctrl
Alt
Shift
Alt + F4
Alt + Space
Ctrl + Alt + Delete
```

说明：

- `Alt + V` 必须可以录制、保存、注册和触发。
- 已有三键快捷键继续可用。
- 已有鼠标侧键快捷键规则保持不变。

## 3. 当前代码现状

快捷键配置模型：

`VSLoader/Models/HotkeyConfig.cs`

当前字段：

```csharp
public bool Enabled { get; set; }
public bool Ctrl { get; set; }
public bool Alt { get; set; }
public bool Shift { get; set; }
public string InputType { get; set; } = "Keyboard";
public string Key { get; set; } = string.Empty;
```

全局快捷键服务：

`VSLoader/Models/Services/GlobalHotkeyService.cs`

当前键盘快捷键校验重点逻辑：

```csharp
var modifierCount = CountModifiers(config);
if (modifierCount < 2)
{
    return SaveResult.Fail("快捷键至少需要两个修饰键和一个主键。");
}
```

这段逻辑导致 `Alt + V` 无法保存。

设置窗口录制逻辑：

`VSLoader/Views/SettingsWindow.xaml.cs`

当前录制逻辑已经可以捕获：

```text
Ctrl
Alt
Shift
主键
Mouse4
Mouse5
```

因此本次大概率不需要修改录制逻辑，只需要调整校验规则和高风险组合判断。

## 4. 技术实现方案

### 4.1 键盘快捷键最低要求

将键盘快捷键最低要求从：

```text
至少两个修饰键 + 一个主键
```

改为：

```text
至少一个修饰键 + 一个主键
```

即修改 `GlobalHotkeyService.Validate`：

```csharp
if (modifierCount < 1)
{
    return SaveResult.Fail("快捷键至少需要一个修饰键和一个主键。");
}
```

### 4.2 鼠标侧键规则保持不变

当前鼠标侧键规则：

```csharp
if (CountModifiers(config) < 1)
{
    return SaveResult.Fail("鼠标侧键快捷键至少需要一个修饰键。");
}
```

本次不修改。

仍然要求：

```text
Ctrl + Mouse4
Alt + Mouse5
Shift + Mouse4
```

不允许：

```text
Mouse4
Mouse5
```

### 4.3 保留已有系统组合拦截

继续保留：

```text
Alt + F4
Ctrl + Alt + Delete
```

当前已有逻辑：

```csharp
if (config.Alt && key == Key.F4)
{
    return SaveResult.Fail("快捷键可能与 Windows 系统快捷键 Alt + F4 冲突，请更换。");
}

if (config.Ctrl && config.Alt && key == Key.Delete)
{
    return SaveResult.Fail("快捷键可能与 Windows 系统快捷键 Ctrl + Alt + Delete 冲突，请更换。");
}
```

本次保留。

### 4.4 新增高风险组合拦截

新增禁止：

```text
Alt + Space
```

原因：

- `Alt + Space` 是 Windows 窗口系统菜单快捷键。
- 如果注册为全局快捷键，容易影响用户对窗口菜单的常规操作。

建议新增逻辑：

```csharp
if (config.Alt && key == Key.Space)
{
    return SaveResult.Fail("快捷键可能与 Windows 系统快捷键 Alt + Space 冲突，请更换。");
}
```

### 4.5 关于 Alt + Tab

当前主键支持范围是：

```text
A-Z
0-9
NumPad0-NumPad9
F1-F12
Space
```

不包含 `Tab`。

因此 `Alt + Tab` 当前无法被录制为有效快捷键，不需要额外处理。

如果未来支持 `Tab` 作为主键，再补充 `Alt + Tab` 拦截。

## 5. 不建议强制拦截的组合

以下组合确实常见，但本次不强制禁止：

```text
Ctrl + C
Ctrl + V
Ctrl + X
Ctrl + S
Ctrl + A
```

原因：

1. 用户明确希望支持 `Alt + V` 这种轻量组合。
2. 有些用户可能确实想主动使用 `Ctrl + V` 之类的全局快捷键。
3. Windows `RegisterHotKey` 如果发现组合被系统或其他程序占用，会注册失败并返回错误。

因此本次策略是：

```text
系统级高风险组合强制禁止；
普通应用级常用组合允许用户自行选择。
```

## 6. 现有触发逻辑保持不变

快捷键触发后的窗口行为已经由现有逻辑处理。

当前效果：

1. 如果 VSLoader 窗口正在显示，按快捷键会隐藏或最小化。
2. 如果 VSLoader 窗口隐藏、最小化或在托盘中，按快捷键会恢复显示。
3. 程序最小化到托盘时，快捷键仍然监听。

本次不修改触发后的窗口切换逻辑。

## 8. 验收场景

实现完成后手工验证：

1. 打开设置窗口。
2. 点击录制快捷键。
3. 按下 `Alt + V`。
4. 页面显示 `Alt + V`。
5. 保存成功。
6. 按下 `Alt + V`，VSLoader 窗口可以显示或隐藏。
7. 设置 `Alt + F4` 时保存失败并提示冲突。
8. 设置 `Alt + Space` 时保存失败并提示冲突。
9. 原有 `Ctrl + Mouse4` 仍可保存并触发。
