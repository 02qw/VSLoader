# v18 主列表排序显式文字箭头反馈编码规格说明

## 1. 需求背景

v17 已经实现主列表列头点击排序：

- 点击 `名称` 按名称排序。
- 点击 `备注` 按备注排序。
- 点击 `更新时间` 按更新时间排序。
- 同一列重复点击可切换升序/降序。

但当前界面没有显示排序箭头。

原因是：当前主列表已经对 `DataGridColumnHeader` 做了自定义样式，WPF 默认排序箭头显示不稳定。  
虽然代码中设置了：

```csharp
DataGridColumn.SortDirection
```

但表头视觉上没有可靠显示默认箭头。

本次 v18 需求需要改成显式文字箭头反馈，不再依赖 WPF 默认排序箭头。

## 2. 需求目标

本次开发目标：

1. 当前排序列的表头文字显示箭头。
2. 升序显示 `↑`。
3. 降序显示 `↓`。
4. 未排序列不显示箭头。
5. 初始状态默认 `名称 ↑`。
6. 点击其他列后，旧列箭头消失，新列显示箭头。
7. 排序功能继续沿用 v17 已实现逻辑。
8. 不改变主列表数据和业务逻辑。

## 3. 修改范围

主要修改文件：

- `VSLoader\MainWindow.xaml.cs`

可能少量涉及：

- `VSLoader\MainWindow.xaml`

原则上不需要修改：

- `VSLoader\ViewModels\MainViewModel.cs`
- `VSLoader\Services\ShortcutSortService.cs`

如果 v17 排序逻辑已正常工作，本次只补充 UI 反馈。

## 4. 当前问题来源

当前代码可能类似：

```csharp
column.SortDirection = ListSortDirection.Ascending;
```

但用户看不到箭头。

原因：

- WPF 默认排序箭头依赖控件模板。
- 当前项目自定义了表头样式。
- 默认箭头没有稳定渲染出来。

因此需要改用直接可见、可控的表头文字：

```text
名称 ↑
备注
更新时间
```

## 5. 推荐实现方案

### 5.1 使用显式 Header 文本

不依赖默认 `SortDirection` 的视觉效果。

排序后直接设置列头：

```csharp
column.Header = "名称 ↑";
```

或：

```csharp
column.Header = "名称 ↓";
```

未排序列恢复为原始标题：

```csharp
column.Header = "备注";
column.Header = "更新时间";
```

### 5.2 保留 SortDirection

虽然不依赖默认箭头显示，仍建议保留：

```csharp
column.SortDirection = direction;
```

原因：

- 保留 WPF 排序状态语义。
- 后续如果样式恢复默认箭头，仍可兼容。
- 不影响显式文字箭头。

## 6. 推荐代码结构

### 6.1 新增列标题常量

在 `MainWindow.xaml.cs` 中增加：

```csharp
private static readonly Dictionary<string, string> SortHeaderTitles = new()
{
    ["Name"] = "名称",
    ["Description"] = "备注",
    ["UpdatedAt"] = "更新时间"
};
```

### 6.2 新增更新表头方法

新增方法：

```csharp
private void UpdateSortHeaders(DataGridColumn sortedColumn, ListSortDirection direction)
```

逻辑：

1. 遍历 `ShortcutsGrid.Columns`。
2. 根据 `SortMemberPath` 找到原始标题。
3. 所有列先恢复原始标题。
4. 当前排序列追加箭头。

示例：

```csharp
private void UpdateSortHeaders(DataGridColumn sortedColumn, ListSortDirection direction)
{
    foreach (var column in ShortcutsGrid.Columns)
    {
        if (!SortHeaderTitles.TryGetValue(column.SortMemberPath, out var title))
        {
            continue;
        }

        column.Header = title;
        column.SortDirection = null;
    }

    var arrow = direction == ListSortDirection.Ascending ? " ↑" : " ↓";
    sortedColumn.Header = $"{SortHeaderTitles[sortedColumn.SortMemberPath]}{arrow}";
    sortedColumn.SortDirection = direction;
}
```

### 6.3 初始状态设置

当前已有或应新增：

```csharp
SetInitialSortDirection();
```

该方法应调整为同时设置表头文字：

```csharp
private void SetInitialSortDirection()
{
    var nameColumn = ShortcutsGrid.Columns.FirstOrDefault(column => column.SortMemberPath == "Name");
    if (nameColumn is not null)
    {
        UpdateSortHeaders(nameColumn, ListSortDirection.Ascending);
    }
}
```

### 6.4 点击排序时更新表头

在 `ShortcutsGrid_Sorting` 中，当前排序逻辑完成后：

```csharp
viewModel.ApplySort(field);
UpdateSortHeaders(e.Column, viewModel.CurrentSortDirection);
e.Handled = true;
```

如果当前已有 `ApplySortDirection` 方法，可以：

- 替换为 `UpdateSortHeaders`。
- 或修改 `ApplySortDirection`，让它同时负责文字箭头。

## 7. 箭头样式规范

推荐使用：

```text
升序：↑
降序：↓
```

显示示例：

```text
名称 ↑
备注 ↓
更新时间 ↑
```

不推荐使用复杂图标或自定义模板。

原因：

- 简单稳定。
- 不受 WPF 模板影响。
- 用户能直观看懂。
