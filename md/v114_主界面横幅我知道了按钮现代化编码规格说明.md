# v114 主界面横幅我知道了按钮现代化编码规格说明

## 1. 背景

当前主界面顶部存在几类横幅提示：

- 普通状态提示
- 更新提醒
- 更新检测失败提醒

其中“更新提醒”和“更新检测失败提醒”右侧带有关闭按钮，当前按钮文案是：

```text
×
```

并且按钮使用的是公共图标按钮样式：

```xml
ModernIconButtonStyle
```

该样式当前没有完整重写按钮模板，因此鼠标悬停时可能出现 WPF 默认按钮的蓝色背景。这个蓝色 hover 与横幅自身的黄色、红色语义不一致，看起来突兀。

另外，`×` 的语义偏“关闭/删除”，而这里实际含义是“我已经看到这条提醒，本次先隐藏”。因此需要将横幅右侧操作改为更明确的：

```text
我知道了
```

## 2. 目标

本次目标：

- 将主界面横幅右侧 `×` 按钮改为 `我知道了`。
- 移除横幅按钮鼠标悬停时的默认蓝色背景。
- 新增横幅专用按钮样式，避免影响其他图标按钮和标题栏按钮。
- 横幅按钮颜色跟随横幅语义：
  - 更新提醒：黄色/暖色体系。
  - 更新检测失败：红色体系。
- 保持现有关闭命令逻辑不变。

## 3. 非目标

本次不做以下事项：

- 不修改更新检测业务逻辑。
- 不修改 `CloseUpdateNoticeCommand` 和 `CloseUpdateFailureCommand` 的 ViewModel 行为。
- 不重构横幅显示/隐藏机制。
- 不改普通状态提示横幅是否可关闭。
- 不重构 `ModernIconButtonStyle`，避免影响标题栏、弹窗、其他图标按钮。
- 不改变横幅在页面中的位置和显示顺序。

## 5. 推荐设计

### 5.1 新增横幅专用按钮样式

在 `ModernTheme.xaml` 中新增横幅按钮样式：

```xml
ModernBannerActionButtonStyle
```

该样式用于主界面横幅右侧“我知道了”按钮。

基础视觉建议：

- 高度：`28`
- 最小宽度：`72`
- Padding：`12,0`
- 圆角：`6`
- 字号：`13`
- 字重：`SemiBold`
- 默认背景：透明或轻微同色系浅底
- 默认边框：透明或同色系浅边框
- 禁用默认焦点虚线：`FocusVisualStyle="{x:Null}"`
- 鼠标指针：`Hand`

### 5.2 更新提醒按钮样式

更新提醒横幅背景当前为：

```text
#FFF7D6
```

文字颜色当前为：

```text
#6B4E00
```

按钮建议沿用该文字颜色，hover 使用暖色浅底：

```text
默认文字：#6B4E00
Hover 背景：#FDE68A 或 #FFE9A8
Pressed 背景：#FCD34D
Focus 边框：#D97706
```

如果统一一个基础横幅按钮样式，不拆不同颜色样式，也可以通过按钮上的 `Foreground` 和 `Tag` 不做复杂参数化。为了最小实现，允许在 `MainWindow.xaml` 的两个按钮上分别覆盖 `Foreground`、`Background` 或局部资源。

更推荐新增两个派生样式：

```xml
ModernWarningBannerActionButtonStyle
ModernErrorBannerActionButtonStyle
```

这样主界面 XAML 更干净，也方便后续复用。

### 5.3 更新失败按钮样式

更新检测失败横幅背景当前为：

```text
#FEE2E2
```

文字颜色当前为：

```text
#7F1D1D
```

按钮建议沿用红色体系：

```text
默认文字：#7F1D1D
Hover 背景：#FECACA
Pressed 背景：#FCA5A5
Focus 边框：#DC2626
```

不允许出现蓝色 hover。

### 5.4 按钮文案

两个横幅右侧按钮文案统一改为：

```text
我知道了
```

语义解释：

- 用户不是删除错误。
- 用户只是确认已读，并临时隐藏该提醒。
- 比 `×` 更符合当前功能实际含义。

### 5.5 横幅布局

现有横幅内部是两列：

```xml
<ColumnDefinition Width="*" />
<ColumnDefinition Width="Auto" />
```

该结构可以保留。

只需要把原来 `Width="28"` 的小图标按钮改成自适应文字按钮：

```xml
MinWidth="72"
Height="28"
Padding="12,0"
Content="我知道了"
```

为防止横幅文本很长时挤压按钮：

- 左侧 `TextBlock` 保持 `TextWrapping="Wrap"`。
- 右侧按钮保持 `Grid.Column="1"`，垂直居中。
- 按钮与文本之间保留 `Margin="12,0,0,0"`。

## 7. 编码要求

### 7.1 样式实现

在 `ModernTheme.xaml` 中新增：

```xml
ModernBannerActionButtonStyle
ModernWarningBannerActionButtonStyle
ModernErrorBannerActionButtonStyle
```

其中：

- `ModernBannerActionButtonStyle` 放通用结构。
- `ModernWarningBannerActionButtonStyle` 配黄色体系。
- `ModernErrorBannerActionButtonStyle` 配红色体系。

样式应使用完整 `ControlTemplate`，避免 WPF 默认按钮 hover 样式泄漏。

模板内至少包含：

- `Border x:Name="Root"`
- `ContentPresenter`
- `IsMouseOver` 触发器
- `IsPressed` 触发器
- `IsKeyboardFocused` 触发器
- `IsEnabled=False` 触发器

### 7.2 主界面替换

在 `MainWindow.xaml` 中：

更新提醒横幅按钮改为：

```xml
Style="{StaticResource ModernWarningBannerActionButtonStyle}"
Content="我知道了"
```

更新失败横幅按钮改为：

```xml
Style="{StaticResource ModernErrorBannerActionButtonStyle}"
Content="我知道了"
```

保留原命令：

```xml
CloseUpdateNoticeCommand
CloseUpdateFailureCommand
```

### 7.3 不影响普通图标按钮

本次不要修改 `ModernIconButtonStyle` 的行为。

原因：

- 标题栏按钮、公告关闭按钮、其他图标按钮可能依赖现有尺寸。
- 横幅“我知道了”已经不是图标按钮，不应继续套用图标按钮样式。

满足以下条件即完成：

- 更新提醒横幅右侧显示 `我知道了`。

- 更新失败横幅按钮 hover 是红色体系。

- `dotnet build .\VSLoader.sln -c Debug --no-restore` 通过。

## 10. 风险与边界

### 10.1 文本按钮宽度风险

`我知道了` 比 `×` 宽，可能挤压横幅文本。

解决：

- 保持右侧 `Auto` 列。
- 左侧文本允许换行。
- 按钮只设置 `MinWidth`，不要设置过大的固定宽度。

### 10.2 默认样式泄漏风险

如果新增样式没有自定义 `ControlTemplate`，WPF 默认 hover 颜色仍可能出现。

因此横幅按钮样式必须重写模板。

### 10.3 影响范围扩大风险

不要直接改 `ModernIconButtonStyle`。

本次需求只针对主页面横幅提示按钮。如果未来要统一所有图标按钮 hover，再单独出规格处理。
