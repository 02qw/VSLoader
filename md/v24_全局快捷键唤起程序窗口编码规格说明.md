# v24 全局快捷键唤起程序窗口编码规格说明

## 1. 需求背景

当前 VSLoader 需要用户通过任务栏、桌面图标或窗口切换手动找到程序窗口。

用户希望在 `设置` 中增加一个配置项，用于设置程序快捷键。  
当 VSLoader 正在运行时，用户按下该快捷键，可以快速唤起 VSLoader 主窗口。

该需求本质是 Windows 全局快捷键：

```text
Global Hotkey
```

需要使用 Win32 API 注册系统级热键。

## 2. 需求目标

本次开发目标：

1. 在设置窗口中新增 `程序快捷键` 配置区域。
2. 支持用户配置快捷键。
3. 支持两个到三个按键组合的常见快捷键形式。
4. 快捷键默认关闭。
5. 程序运行期间，按下快捷键可唤起 VSLoader 主窗口。
6. 如果窗口最小化，恢复窗口。
7. 如果窗口被遮挡，将窗口激活到前台。
8. 保存设置时尝试注册快捷键。
9. 如果快捷键非法或被占用，提示用户并阻止保存或回滚注册。
10. 尽量避免与 Windows 自带快捷键冲突。

## 3. 需求边界

### 3.1 本次实现范围

本次只实现：

```text
VSLoader 程序正在运行期间，通过全局快捷键唤起 VSLoader 窗口。
```

### 3.2 本次不实现

本次不实现：

- 程序退出后仍能通过快捷键启动 VSLoader。
- 后台常驻托盘。
- 开机自启。
- 系统服务。
- 多快捷键配置。
- 快捷键云同步。

说明：

Windows 全局热键只能在程序运行期间生效。  
如果程序已经退出，普通 `RegisterHotKey` 无法响应快捷键。

## 4. 推荐交互设计

在设置窗口中新增分组：

```text
程序快捷键
```

建议 UI：

```text
[ ] 启用快捷键

快捷键：[ Ctrl + Alt + V ] [录制] [清除]
```

交互规则：

1. 默认不启用。
2. 勾选启用后，必须配置合法快捷键。
3. 点击 `录制` 后，用户按下一组快捷键。
4. 程序解析并显示，例如：

```text
Ctrl + Alt + V
```

5. 点击 `清除` 后，清空快捷键并取消启用或保持未配置状态。
6. 点击设置窗口 `保存` 时校验并注册快捷键。

## 5. 快捷键组合规则

### 5.1 支持的修饰键

第一版支持：

```text
Ctrl
Alt
Shift
```

第一版不支持：

```text
Win
```

原因：

- `Win` 组合键更容易与 Windows 系统快捷键冲突。
- 不同 Windows 版本和系统组件占用不同。
- 第一版优先稳定。

### 5.2 主键

主键支持：

- 字母键：`A-Z`
- 数字键：`0-9`
- 功能键：`F1-F12`

可选支持：

- `Space`
- `Escape`
- `Oem` 特殊符号键

第一版推荐只支持：

```text
A-Z
0-9
F1-F12
Space
```

### 5.3 最小组合要求

为避免误触和系统冲突，建议要求：

```text
至少 2 个修饰键 + 1 个主键
```

合法示例：

```text
Ctrl + Alt + V
Ctrl + Shift + Space
Alt + Shift + V
Ctrl + Alt + F9
```

不合法示例：

```text
V
Ctrl + V
Alt + F4
Ctrl + Alt + Delete
Win + L
```

说明：

用户最开始提到“两个~三个按键组合”，但从防冲突角度，第一版建议采用：

```text
两个修饰键 + 一个主键
```

即通常为三个键组合。

## 6. Windows 快捷键冲突策略

不能百分百提前知道所有系统和第三方软件占用的快捷键。

因此采用两层策略：

### 6.1 规则层禁止明显冲突组合

禁止：

```text
Alt + Tab
Alt + F4
Ctrl + Alt + Delete
Win + L
Win + D
Win + E
Win + R
Win + I
Win + Tab
单独主键
单修饰键 + 主键
```

由于第一版不支持 `Win`，所有 Win 组合默认不允许。

### 6.2 注册层验证是否被占用

使用 Win32 API：

```csharp
RegisterHotKey
UnregisterHotKey
```

保存设置时尝试注册。

如果注册失败：

```text
快捷键注册失败，可能已被系统或其他程序占用，请更换快捷键。
```

保存应失败或回滚，不应保存一个无法使用的快捷键。

## 7. 配置模型设计

新增模型：

```text
VSLoader\Models\HotkeyConfig.cs
```

推荐结构：

```csharp
public sealed class HotkeyConfig
{
    public bool Enabled { get; set; }

    public bool Ctrl { get; set; }

    public bool Alt { get; set; }

    public bool Shift { get; set; }

    public string Key { get; set; } = string.Empty;
}
```

在 `AppConfig` 中新增：

```csharp
public HotkeyConfig Hotkey { get; set; } = new();
```

配置 JSON 示例：

```json
{
  "Hotkey": {
    "Enabled": true,
    "Ctrl": true,
    "Alt": true,
    "Shift": false,
    "Key": "V"
  }
}
```

## 8. 配置兼容性

旧配置文件没有 `Hotkey` 字段时，应自动补默认值：

```csharp
config.Hotkey ??= new HotkeyConfig();
```

位置：

```text
ConfigService.Load()
```

不要因为旧配置缺少该字段导致配置读取失败。

## 9. 设置窗口 ViewModel 要求

修改：

```text
SettingsViewModel
```

新增属性：

```csharp
public HotkeyConfig Hotkey { get; set; }
public string HotkeyDisplayText { get; }
public bool IsRecordingHotkey { get; set; }
```

新增命令：

```csharp
StartRecordHotkeyCommand
ClearHotkeyCommand
```

保存时：

1. Trim 现有配置。
2. 校验 VSCode 路径。
3. 校验 AdminUI 配置。
4. 校验快捷键。
5. 将 Hotkey 配置写回结果。

## 10. 设置窗口 UI 要求

修改：

```text
Views\SettingsWindow.xaml
Views\SettingsWindow.xaml.cs
```

新增 `GroupBox`：

```text
程序快捷键
```

建议放在 `AdminUI 密码` 下方或上方。

UI 推荐：

```xml
<GroupBox Header="程序快捷键">
    <StackPanel>
        <CheckBox Content="启用快捷键" IsChecked="{Binding Hotkey.Enabled}" />
        <Grid>
            <TextBox Text="{Binding HotkeyDisplayText}" IsReadOnly="True" />
            <Button Content="录制" Command="{Binding StartRecordHotkeyCommand}" />
            <Button Content="清除" Command="{Binding ClearHotkeyCommand}" />
        </Grid>
    </StackPanel>
</GroupBox>
```

### 10.1 录制快捷键

录制时可在 `SettingsWindow.xaml.cs` 捕获 `PreviewKeyDown`：

1. 用户点击 `录制`。
2. ViewModel 进入录制状态。
3. 用户按键。
4. Code-behind 将按键事件转换为 `HotkeyConfig`。
5. ViewModel 更新显示文本。
6. 退出录制状态。

注意：

- 录制时不要把按键输入到 TextBox。
- 要处理 `SystemKey`，例如 Alt 组合。
- 主键不能是单独的 Ctrl/Alt/Shift。

## 11. 全局热键服务设计

新增服务：

```text
VSLoader\Services\GlobalHotkeyService.cs
```

职责：

- 注册全局快捷键。
- 注销全局快捷键。
- 监听 `WM_HOTKEY`。
- 触发窗口唤起回调。

### 11.1 Win32 API

需要 P/Invoke：

```csharp
[DllImport("user32.dll", SetLastError = true)]
private static extern bool RegisterHotKey(IntPtr hWnd, int id, uint fsModifiers, uint vk);

[DllImport("user32.dll", SetLastError = true)]
private static extern bool UnregisterHotKey(IntPtr hWnd, int id);
```

消息：

```csharp
private const int WM_HOTKEY = 0x0312;
```

修饰键：

```csharp
MOD_ALT = 0x0001
MOD_CONTROL = 0x0002
MOD_SHIFT = 0x0004
```

第一版不使用：

```csharp
MOD_WIN = 0x0008
```

### 11.2 注册时机

在主窗口加载完成后注册。

建议在：

```text
MainWindow.xaml.cs
```

的 `Loaded` 事件中：

```csharp
_hotkeyService.Initialize(this, OnHotkeyPressed);
_hotkeyService.Register(config.Hotkey);
```

或通过 MainViewModel 暴露配置。

### 11.3 注销时机

在窗口关闭时注销：

```csharp
_hotkeyService.Dispose();
```

避免程序退出后热键残留。

## 12. 主窗口唤起行为

收到快捷键后：

```csharp
if (WindowState == WindowState.Minimized)
{
    WindowState = WindowState.Normal;
}

Show();
Activate();
Topmost = true;
Topmost = false;
Focus();
```

目标：

- 最小化则恢复。
- 被遮挡则置前。
- 已显示则激活。

## 13. 保存设置后的注册更新

当用户在设置中保存快捷键后：

1. 注销旧快捷键。
2. 如果新快捷键启用，尝试注册新快捷键。
3. 注册成功后保存配置。
4. 注册失败则提示错误，不保存无效快捷键。

实现方式可选：

### 13.1 推荐方式

在 `OpenSettings()` 保存逻辑中：

1. 获取新配置。
2. 调用全局热键服务尝试更新注册。
3. 成功后写入 `_config.Hotkey`。
4. 保存配置。

### 13.2 注意

不要只保存配置而不注册，否则用户要重启程序才生效。

## 14. 快捷键校验服务

建议新增：

```text
HotkeyValidationService
```

或放在 `GlobalHotkeyService` 中。

职责：

- 判断是否启用。
- 判断是否有主键。
- 判断是否至少两个修饰键。
- 判断是否使用 Win。
- 判断是否明显系统冲突。

返回错误文案：

```text
快捷键至少需要两个修饰键和一个主键。
第一版暂不支持 Win 键组合。
该快捷键可能与 Windows 系统快捷键冲突，请更换。
```

## 15. 失败处理

### 15.1 非法快捷键

保存设置时提示：

```text
快捷键无效：xxx
```

设置窗口不关闭。

### 15.2 注册失败

提示：

```text
快捷键注册失败，可能已被系统或其他程序占用，请更换快捷键。
```

设置窗口不关闭或保存失败。

### 15.3 未启用快捷键

不注册。

保存正常。

## 16. 不允许改变的内容

本次不允许改变：

- VSCode 路径配置逻辑。
- AdminUI 配置逻辑。
- AdminUI 密码配置逻辑。
- 快捷项列表逻辑。
- 批量新增识别逻辑。
- 自动获取连接逻辑。
- 配置文件路径。
- 主窗口默认布局。

## 17. 验收标准

### 17.1 默认状态

首次启动或旧配置升级后：

- 快捷键默认关闭。
- 程序不注册全局快捷键。
- 不影响启动。

### 17.2 设置合法快捷键

设置：

```text
Ctrl + Alt + V
```

保存后：

- 配置写入 `config.json`。
- 快捷键立即生效。
- 按下快捷键，VSLoader 被唤起到前台。

### 17.3 最小化唤起

将 VSLoader 最小化后按快捷键：

- 窗口恢复。
- 窗口激活到前台。

### 17.4 被遮挡唤起

用其他窗口遮挡 VSLoader 后按快捷键：

- VSLoader 回到前台。

### 17.5 冲突快捷键

尝试设置明显冲突快捷键：

```text
Alt + F4
Ctrl + V
Win + L
```

期望：

- 保存失败。
- 提示原因。

### 17.6 被占用快捷键

尝试设置已被系统或其他软件占用的快捷键：

- `RegisterHotKey` 失败。
- 设置窗口提示注册失败。
- 不保存无效快捷键。

### 17.7 清除快捷键

点击清除并保存：

- 注销旧快捷键。
- 配置中快捷键禁用或清空。
- 按旧快捷键不再唤起窗口。

### 17.8 编译验收

执行：

```powershell
dotnet build .\VSLoader.sln
```

期望：

```text
0 warnings
0 errors
```

如果提示 `VSLoader.exe` 被占用，说明程序正在运行，应先关闭 VSLoader 后重新构建。

## 18. 建议实施步骤

1. 新增 `HotkeyConfig` 模型。
2. 扩展 `AppConfig`。
3. 修改 `ConfigService.Load()`，补齐旧配置缺失的 `Hotkey`。
4. 新增 `GlobalHotkeyService`。
5. 新增快捷键校验逻辑。
6. 修改 `SettingsViewModel`，增加快捷键配置属性和命令。
7. 修改 `SettingsWindow.xaml`，增加程序快捷键分组。
8. 修改 `SettingsWindow.xaml.cs`，实现录制按键。
9. 修改 `MainWindow.xaml.cs`，注册/注销全局快捷键并处理唤起。
10. 修改 `MainViewModel.OpenSettings()` 或相关保存逻辑，使保存后立即更新热键注册。
11. 编译并人工验证。

## 19. 明确不做的事情

本次不做：

- 程序退出后快捷键启动 VSLoader。
- 托盘常驻。
- 开机自启。
- 支持 Win 键。
- 多快捷键。
- 保存多个快捷键方案。
