# v124 主快捷键后台恢复地图优先与旧层级快照清理编码规格说明

## 1. 背景

v121 到 v123 都围绕一个目标做了多轮尝试：

```text
主快捷键恢复 VSLoader 时，尽量还原主窗口和地图窗口之前的层级关系。
```

但实际体验中仍然出现问题：

```text
用户在地图窗口中右键节点打开 Web 页面后，浏览器位于最前，地图窗口退到下层。
此时按主快捷键，程序没有把地图窗口置于最前，而是把主窗口放到了上面。
```

这说明“维护历史层级快照”仍然不够稳定，也不符合用户当前最核心的使用意图。

用户新的需求描述更清晰：

```text
点按主快捷键后，只要地图没有被关闭，并且此时 VSLoader 处于后台，就直接显示地图，并还原上一次地图状态。
```

因此本次不再继续修补“层级快照”方案，而是改成更简单、更强约束的规则：

```text
VSLoader 在后台被主快捷键唤起时，只要地图仍处于打开状态，就优先恢复并置顶地图。
```

## 2. 问题描述

当前逻辑依赖这些运行时状态：

```text
_lastActiveVsLoaderWindow
_foregroundSnapshotBeforeMainWindowHide
_isMainWindowHotkeyHideInProgress
```

并通过：

```text
RestorePreferredForegroundWindow(...)
ShouldActivateFactoryMapAfterHotkeyRestore(...)
ResolveForegroundWindowForRestore(...)
```

决定主窗口和地图窗口谁在前。

但该方案仍然有天然缺陷：

- 右键打开 Web 页面时，焦点变化不一定能准确表达用户希望下次恢复地图。
- 浏览器、主窗口、地图窗口三者之间的前后台切换，会让“最后活跃窗口”语义变得含糊。
- 快照只能表达隐藏/最小化前的状态，不能很好表达“VSLoader 在后台时用户希望唤回地图工作区”。
- 旧逻辑的状态字段越来越多，继续叠加会增加维护风险。

所以应改为直接规则：

```text
VSLoader 当前在后台 + 地图没有被关闭 => 主快捷键恢复后地图在最前。
```

## 3. 根因分析

根因不是某一个 `Activate()` 调用顺序错误，而是需求模型选错了。

旧模型是：

```text
维护主窗口和地图窗口的历史层级关系。
```

新模型应是：

```text
主快捷键是“把 VSLoader 带回前台”的入口。
如果地图仍然打开，则地图是用户优先回到的工作界面。
```

这两种模型差别很大。

旧模型需要处理：

- 最后活跃窗口。
- 隐藏前快照。
- 快捷键隐藏事务。
- `Activated` 事件污染。
- `StateChanged` 二次覆盖。

新模型只需要判断：

```text
VSLoader 是否处于后台？
地图是否仍然处于打开状态？
```

因此新方案更稳定。

## 4. 目标

本次目标：

- 当 VSLoader 处于后台，用户按主快捷键恢复时：
  - 先恢复主窗口。
  - 如果地图没有被用户关闭，则恢复地图并把地图置于最前。
  - 如果地图已经被用户关闭，则只恢复主窗口。
- 地图被最小化但没有关闭时，也应恢复地图并置于最前。
- 保留主快捷键在 VSLoader 前台时隐藏/最小化 VSLoader 的行为。
- 清理 v121-v123 中不再需要的层级快照和事务代码。
- 不留下无用状态字段、无用静态判断方法、无用测试。
- 不改变地图窗口位置、大小、缩放、视口、节点、连线等业务逻辑。

## 5. 非目标

本次不做以下事项：

- 不再维护主窗口/地图窗口历史层级快照。
- 不再试图还原“隐藏前谁在上面”的复杂历史关系。
- 不引入配置文件持久化。
- 不引入 Win32 Z-Order API。
- 不重构全局快捷键注册服务。
- 不改变地图快捷键自身的打开/关闭语义。
- 不修改地图右键菜单、WebUI/AdminUI 打开逻辑。

## 6. 推荐方案

### 6.1 定义新的恢复规则

主快捷键行为改为：

```text
如果 VSLoader 当前在前台：
    隐藏/最小化主窗口，并同步隐藏地图。

如果 VSLoader 当前在后台：
    恢复主窗口。
    如果 _isFactoryMapOpen == true，则恢复地图并最终激活地图。
    如果 _isFactoryMapOpen == false，则最终激活主窗口。
```

其中：

```text
_isFactoryMapOpen == true
```

表示：

```text
地图没有被用户关闭。
```

即使地图窗口当前被隐藏、被主窗口联动隐藏、或处于最小化状态，只要 `_isFactoryMapOpen == true`，主快捷键从后台恢复时都应把地图恢复出来。

### 6.2 新增可测试判断方法

新增静态方法：

```csharp
internal static bool ShouldActivateFactoryMapWhenRestoringFromBackground(
    bool isFactoryMapOpen,
    bool hasFactoryMapWindow,
    bool isFactoryMapVisible,
    WindowState factoryMapWindowState)
{
    return isFactoryMapOpen;
}
```

说明：

- 只要地图逻辑状态是打开，就应该恢复地图。
- `hasFactoryMapWindow`、`isFactoryMapVisible`、`factoryMapWindowState` 暂时可作为测试参数保留，方便表达边界，但判断主条件只依赖 `isFactoryMapOpen`。
- 如果实现者觉得参数冗余，可以简化为：

```csharp
internal static bool ShouldActivateFactoryMapWhenRestoringFromBackground(bool isFactoryMapOpen)
{
    return isFactoryMapOpen;
}
```

推荐使用简化版，减少无意义参数。

### 6.3 简化 RestoreAndActivate

`RestoreAndActivate()` 改为固定顺序：

```csharp
private void RestoreAndActivate()
{
    Dispatcher.Invoke(() =>
    {
        RestoreMainWindowForHotkey();

        if (ShouldActivateFactoryMapWhenRestoringFromBackground(_isFactoryMapOpen))
        {
            RestoreFactoryMapForBackgroundActivation();
            return;
        }

        ActivateMainWindow();
    });
}
```

这里不再读取：

```text
_lastActiveVsLoaderWindow
_foregroundSnapshotBeforeMainWindowHide
```

### 6.4 新增地图后台恢复方法

新增方法：

```csharp
private void RestoreFactoryMapForBackgroundActivation()
{
    _isFactoryMapOpen = true;
    _isFactoryMapHiddenByMainWindow = false;
    _runtimeLayoutState.WasFactoryMapOpen = true;

    ShowFactoryMapIfNeeded();

    if (_factoryMapWindow is null)
    {
        ActivateMainWindow();
        return;
    }

    if (_factoryMapWindow.WindowState == WindowState.Minimized)
    {
        _factoryMapWindow.WindowState = WindowState.Normal;
    }

    _factoryMapWindow.Show();
    ActivateFactoryMapWindow();
    RefreshFactoryMap();
}
```

注意：

- 地图窗口如果还没创建，`ShowFactoryMapIfNeeded()` 应负责创建。
- 地图窗口如果被最小化，应恢复为 `Normal`。
- 最终必须调用 `ActivateFactoryMapWindow()`。
- 如果地图窗口创建失败或为空，兜底激活主窗口。

### 6.5 保留前台隐藏逻辑

主快捷键隐藏分支可以保留简化后的逻辑：

```csharp
private void ToggleWindowFromHotkey()
{
    if (ShouldRestoreFromHotkey(IsVisible, WindowState == WindowState.Minimized, IsVsLoaderActive()))
    {
        RestoreAndActivate();
        return;
    }

    SaveMainWindowBoundsToSession();
    HideFactoryMapWindow();
    WindowState = WindowState.Minimized;
}
```

由于不再维护层级快照，v123 的事务字段不再必要。

如果仍担心 `StateChanged` 重复隐藏地图，可以保留防重入字段，但本次目标是动作干净，推荐删除。

### 6.6 清理旧层级快照代码

必须删除以下内容：

```csharp
public enum VsLoaderForegroundWindow
private VsLoaderForegroundWindow _lastActiveVsLoaderWindow
private VsLoaderForegroundWindow? _foregroundSnapshotBeforeMainWindowHide
private bool _isMainWindowHotkeyHideInProgress
MainWindow_Activated(...)
FactoryMapWindow_Activated(...)
CaptureForegroundSnapshotBeforeMainWindowHide(...)
RestorePreferredForegroundWindow(...)
ShouldActivateFactoryMapAfterHotkeyRestore(...)
ResolveForegroundWindowForRestore(...)
ShouldHandleMainWindowMinimizedStateChanged(...)
HideMainWindowFromHotkey(...)
```

同时删除相关事件订阅：

```csharp
Activated += MainWindow_Activated;
_factoryMapWindow.Activated += FactoryMapWindow_Activated;
```

如果删除后有测试引用这些方法，也要删除或重写测试。

### 6.7 清理旧测试

删除或重写以下测试：

```text
ShouldActivateFactoryMapAfterHotkeyRestore_only_activates_visible_non_minimized_last_active_map
ResolveForegroundWindowForRestore_prefers_snapshot_from_before_hotkey_minimize
ResolveForegroundWindowForRestore_falls_back_to_current_last_active_when_snapshot_is_missing
ShouldHandleMainWindowMinimizedStateChanged_skips_when_hotkey_hide_transaction_is_running
```

新增测试：

```csharp
[Theory]

[InlineData(false, false)]

    bool isFactoryMapOpen,
    bool expected)
```

测试含义：

```text
只要地图逻辑上没有关闭，后台恢复就优先激活地图。
地图关闭后，后台恢复只激活主窗口。
```

## 7. 边界情况

### 7.1 地图处于下层但未关闭

场景：

```text
地图窗口中右键节点打开 Web 页面。
浏览器位于最前。
地图窗口处于下层。
VSLoader 处于后台。
按主快捷键。
```

期望：

```text
主窗口恢复。
地图窗口恢复并置于最前。
```

### 7.2 地图被主窗口联动隐藏

如果主快捷键隐藏 VSLoader 时调用过：

```csharp
HideFactoryMapWindow()
```

地图窗口可能不可见，但 `_isFactoryMapOpen == true`。

下次后台恢复时应显示地图并置顶。

### 7.3 地图被用户最小化

地图没有关闭，只是最小化。

按主快捷键从后台恢复时：

```text
恢复地图窗口到 Normal。
置顶地图。
```

### 7.4 地图被用户关闭

如果用户通过地图按钮或关闭动作关闭了地图：

```text
_isFactoryMapOpen == false
```

按主快捷键从后台恢复时：

```text
只恢复主窗口，不自动打开地图。
```

### 7.5 VSLoader 当前已经在前台

如果主窗口或地图窗口当前已经是活动窗口：

```text
IsVsLoaderActive() == true
```

按主快捷键应保持原有语义：

```text
隐藏/最小化 VSLoader，而不是置顶地图。
```

### 7.6 托盘恢复

托盘左键、双击、菜单“显示 VSLoader”当前也复用 `RestoreAndActivate()`。

本次推荐保持一致：

```text
托盘恢复时，如果地图未关闭，也优先显示并置顶地图。
```

如果用户后续觉得托盘恢复不应置顶地图，再单独拆分托盘恢复方法。

## 9. 编码要求

### 9.1 动作要干净

本次不是在 v121-v123 上继续叠逻辑。

必须删除旧层级快照方案相关代码。

最终代码中不应再出现：

```text
ForegroundWindow
foregroundSnapshot
HotkeyHideInProgress
ResolveForegroundWindowForRestore
RestorePreferredForegroundWindow
```

除非是文档或注释。

### 9.2 恢复逻辑必须简单

`RestoreAndActivate()` 中只允许有两个分支：

```text
地图打开 => 恢复并激活地图
地图关闭 => 激活主窗口
```

不要再判断“最后活跃窗口”。

### 9.3 地图打开状态以 _isFactoryMapOpen 为准

判断地图是否需要恢复时，以：

```csharp
_isFactoryMapOpen
```

为准。

不要用：

```text
_factoryMapWindow?.IsVisible
_factoryMapWindow?.IsActive
```

来替代地图是否打开。

### 9.4 保留地图可恢复能力

地图窗口可能处于以下状态：

```text
null
hidden
minimized
normal
maximized
```

`RestoreFactoryMapForBackgroundActivation()` 必须兜底处理这些状态。

### 9.5 不改变地图关闭语义

如果用户明确关闭地图：

```text
_isFactoryMapOpen = false
```

主快捷键不得自动重新打开地图。

## 11. 验收标准

满足以下条件即完成：

- VSLoader 在后台时，地图只要未关闭，主快捷键恢复后地图一定在最前。
- 地图因打开 Web 页面退到下层后，主快捷键能把地图带回最前。
- 地图被主窗口联动隐藏后，主快捷键恢复能显示并置顶地图。
- 地图最小化但未关闭时，主快捷键恢复能显示并置顶地图。
- 地图关闭后，主快捷键恢复不自动打开地图。
- VSLoader 在前台时，主快捷键仍隐藏/最小化 VSLoader。
- v121-v123 的无用层级快照代码已清理。
- 相关测试通过。
- Debug 构建通过。

## 12. 风险与注意事项

### 12.1 行为变化是有意的

新规则下：

```text
只要地图未关闭，后台恢复就优先置顶地图。
```

这意味着即使用户上一次在主窗口上方工作，只要地图仍打开，后台恢复也会优先显示地图。

这是为了换取更稳定、更符合地图工作流的行为。

### 12.2 不要保留旧快照逻辑作为兜底

旧快照逻辑已经多次造成干扰。

不要保留：

```text
如果地图无法激活再用快照判断
```

这种混合方案。

地图无法激活时直接兜底主窗口即可。

### 12.3 如果恢复地图后主窗口又抢前台

需要检查恢复顺序是否为：

```text
RestoreMainWindowForHotkey()
RestoreFactoryMapForBackgroundActivation()
ActivateFactoryMapWindow()
```

且 `ActivateFactoryMapWindow()` 必须是地图分支最后一步。

### 12.4 如果 ShowFactoryMapIfNeeded 无法恢复最小化地图

`RestoreFactoryMapForBackgroundActivation()` 需要在 `ShowFactoryMapIfNeeded()` 后显式处理：

```csharp
if (_factoryMapWindow.WindowState == WindowState.Minimized)
{
    _factoryMapWindow.WindowState = WindowState.Normal;
}
```

不能完全依赖 `ShowFactoryMapIfNeeded()`。
