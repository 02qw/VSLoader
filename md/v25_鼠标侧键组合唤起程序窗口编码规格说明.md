# v25 鼠标侧键组合唤起程序窗口编码规格说明

## 1. 需求背景

v24 已经实现程序运行期间的全局键盘快捷键，用于唤起 VSLoader 主窗口。

当前实现基于 Windows API：

```text
RegisterHotKey
```

它适合注册键盘组合键，例如：

```text
Ctrl + Alt + V
Ctrl + Shift + Space
```

但 `RegisterHotKey` 不支持鼠标侧键：

```text
Mouse4
Mouse5
Ctrl + Mouse4
```

用户现在希望支持：

```text
修饰键 + 鼠标侧键
```

例如：

```text
Ctrl + Mouse4
Ctrl + Mouse5
Alt + Mouse4
Shift + Mouse5
```

本次 v25 需求是在现有程序快捷键功能基础上，扩展支持鼠标侧键组合唤起 VSLoader。

## 2. 需求目标

本次开发目标：

1. 支持 `Mouse4`。
2. 支持 `Mouse5`。
3. 支持 `Ctrl / Alt / Shift + Mouse4/Mouse5`。
4. 鼠标侧键快捷键至少需要 1 个修饰键。
5. 不允许单独 `Mouse4` 或 `Mouse5`。
6. 点击设置中的 `录制` 后，可以录制鼠标侧键组合。
7. 显示文本例如：

```text
Ctrl + Mouse4
```

8. 程序运行期间按下该组合键可唤起 VSLoader。
9. 匹配成功后拦截本次 Mouse4/Mouse5 事件，避免同时触发浏览器后退/前进。
10. 保持现有键盘快捷键功能可用。

## 3. 需求边界

本次不实现：

- 单独 Mouse4/Mouse5。
- 鼠标左键、右键、中键快捷键。
- 双击鼠标侧键。
- 多个快捷键同时配置。
- 程序退出后通过鼠标侧键启动程序。
- 鼠标驱动层高级配置。

本次仍然只保存一个程序唤起快捷键。

该快捷键可以是：

```text
Keyboard
```

或：

```text
Mouse
```

二者二选一。

## 4. 技术方案概述

键盘快捷键继续使用：

```text
RegisterHotKey
```

鼠标侧键快捷键使用低级鼠标钩子：

```text
SetWindowsHookEx
WH_MOUSE_LL
```

监听：

```text
WM_XBUTTONDOWN
```

识别：

```text
XBUTTON1 -> Mouse4
XBUTTON2 -> Mouse5
```

同时判断：

```text
Ctrl / Alt / Shift 是否按下
```

匹配成功后：

```text
唤起 VSLoader 窗口
拦截本次鼠标侧键事件
```

## 5. 配置模型扩展

当前 `HotkeyConfig` 需要扩展输入类型。

建议新增：

```csharp
public string InputType { get; set; } = "Keyboard";
```

支持值：

```text
Keyboard
Mouse
```

完整模型建议：

```csharp
public sealed class HotkeyConfig
{
    public bool Enabled { get; set; }

    public bool Ctrl { get; set; }

    public bool Alt { get; set; }

    public bool Shift { get; set; }

    public string InputType { get; set; } = "Keyboard";

    public string Key { get; set; } = string.Empty;
}
```

配置示例：

```json
"Hotkey": {
  "Enabled": true,
  "Ctrl": true,
  "Alt": false,
  "Shift": false,
  "InputType": "Mouse",
  "Key": "Mouse4"
}
```

旧配置兼容：

- 如果旧配置缺少 `InputType`，默认视为 `Keyboard`。

## 6. 合法性规则

### 6.1 Keyboard 类型

保持 v24 当前规则：

- 支持 `Ctrl / Alt / Shift`
- 支持主键 `A-Z / 0-9 / F1-F12 / Space`
- 至少 2 个修饰键 + 1 个主键
- 不支持 Win

### 6.2 Mouse 类型

Mouse 类型规则：

- `Key` 必须是：

```text
Mouse4
Mouse5
```

- 至少 1 个修饰键：

```text
Ctrl
Alt
Shift
```

合法：

```text
Ctrl + Mouse4
Alt + Mouse4
Shift + Mouse5
Ctrl + Alt + Mouse4
```

不合法：

```text
Mouse4
Mouse5
LeftClick
RightClick
MiddleClick
```

## 7. 显示文本

显示规则：

```text
Ctrl + Mouse4
Ctrl + Alt + Mouse5
Shift + Mouse4
```

`GlobalHotkeyService.Format(...)` 或同等方法需要支持 Mouse 类型。

## 8. 设置窗口录制要求

当前设置窗口已经支持键盘录制。

本次需要增加鼠标侧键录制。

### 8.1 键盘录制保持不变

`PreviewKeyDown` 继续处理键盘快捷键。

### 8.2 鼠标侧键录制

在 `SettingsWindow.xaml.cs` 中新增或使用：

```csharp
PreviewMouseDown
```

识别：

```csharp
MouseButton.XButton1 -> Mouse4
MouseButton.XButton2 -> Mouse5
```

录制时：

1. 判断 `IsRecordingHotkey == true`。
2. 如果按下 Mouse4/Mouse5：
   - 读取当前 Ctrl/Alt/Shift 状态。
   - 设置 `InputType="Mouse"`。
   - 设置 `Key="Mouse4"` 或 `Key="Mouse5"`。
   - 退出录制状态。
   - 阻止事件继续在设置窗口内部传播。

注意：

- 这里是录制阶段，不是全局监听。
- 全局监听仍由低级鼠标钩子处理。

## 9. GlobalHotkeyService 扩展

当前服务负责键盘全局热键。

本次建议扩展同一个服务，统一管理：

- 键盘热键注册。
- 鼠标钩子注册。
- 注销所有热键。

### 9.1 注册入口

保持现有：

```csharp
public SaveResult Register(HotkeyConfig config)
```

内部根据：

```csharp
config.InputType
```

分支：

```text
Keyboard -> RegisterHotKey
Mouse -> SetWindowsHookEx
```

### 9.2 注销入口

`Unregister()` 需要同时处理：

- 已注册键盘热键：`UnregisterHotKey`
- 已安装鼠标钩子：`UnhookWindowsHookEx`

### 9.3 鼠标钩子字段

建议新增：

```csharp
private IntPtr _mouseHook;
private LowLevelMouseProc? _mouseProc;
private HotkeyConfig? _registeredMouseHotkey;
```

### 9.4 Win32 API

需要新增：

```csharp
[DllImport("user32.dll", SetLastError = true)]
private static extern IntPtr SetWindowsHookEx(
    int idHook,
    LowLevelMouseProc lpfn,
    IntPtr hMod,
    uint dwThreadId);

[DllImport("user32.dll", SetLastError = true)]
private static extern bool UnhookWindowsHookEx(IntPtr hhk);

[DllImport("user32.dll")]
private static extern IntPtr CallNextHookEx(
    IntPtr hhk,
    int nCode,
    IntPtr wParam,
    IntPtr lParam);

[DllImport("user32.dll")]
private static extern short GetKeyState(int nVirtKey);
```

常量：

```csharp
WH_MOUSE_LL = 14
WM_XBUTTONDOWN = 0x020B
XBUTTON1 = 0x0001
XBUTTON2 = 0x0002
VK_CONTROL = 0x11
VK_SHIFT = 0x10
VK_MENU = 0x12
```

### 9.5 钩子回调

回调中：

1. 判断 `nCode >= 0`。
2. 判断 `wParam == WM_XBUTTONDOWN`。
3. 读取 `MSLLHOOKSTRUCT.mouseData` 高位。
4. 识别 Mouse4/Mouse5。
5. 判断修饰键是否匹配配置。
6. 匹配成功：
   - 调用 `_hotkeyPressed`
   - 返回非零值，例如 `(IntPtr)1`，拦截事件。
7. 不匹配：
   - 调用 `CallNextHookEx`

## 10. 事件拦截策略

本次要求：

```text
匹配成功后拦截本次 Mouse4/Mouse5 事件。
```

原因：

- 用户明确将该组合设置为 VSLoader 唤起快捷键。
- 不应同时触发浏览器后退/前进。

未匹配时：

```text
事件继续传递
```

避免影响正常鼠标侧键使用。

## 11. 保存设置后的注册行为

保持 v24 行为：

1. 用户保存设置。
2. 注销旧快捷键/旧钩子。
3. 校验新配置。
4. 注册新配置。
5. 注册失败则提示，不保存无效配置。
6. 注册失败后尝试恢复旧快捷键。

Mouse 类型同样适用。

## 12. 主窗口唤起行为

保持 v24 行为：

```csharp
if (WindowState == WindowState.Minimized)
{
    WindowState = WindowState.Normal;
}

Show();
Activate();
Topmost = true;
Topmost = false;
Focus();
```

不需要修改。

## 13. 不允许改变的内容

本次不允许改变：

- 键盘快捷键现有能力。
- 设置窗口保存流程。
- 主窗口唤起逻辑。
- 配置文件路径。
- 主界面布局。
- AdminUI 逻辑。
- 列表逻辑。
- 弹窗组件。

## 14. 验收标准

### 14.1 录制 Ctrl + Mouse4

操作：

1. 打开设置。
2. 点击程序快捷键的 `录制`。
3. 按住 Ctrl，点击 Mouse4。

期望：

```text
显示 Ctrl + Mouse4
保存成功
```

### 14.2 唤起窗口

设置 `Ctrl + Mouse4` 后：

- 最小化 VSLoader。
- 按 `Ctrl + Mouse4`。

期望：

- VSLoader 恢复并置前。

### 14.3 被遮挡窗口

用其他窗口遮挡 VSLoader 后按：

```text
Ctrl + Mouse4
```

期望：

- VSLoader 回到前台。

### 14.4 禁止单独 Mouse4

录制或保存：

```text
Mouse4
```

期望：

- 保存失败。
- 提示至少需要一个修饰键。

### 14.5 Mouse5

设置：

```text
Alt + Mouse5
```

期望：

- 保存成功。
- 可唤起窗口。

### 14.6 键盘快捷键回归

设置：

```text
Ctrl + Alt + V
```

期望：

- 键盘快捷键仍正常工作。

### 14.7 清除快捷键

清除快捷键并保存后：

- 旧键盘热键或鼠标钩子被注销。
- 再按旧快捷键不唤起窗口。

### 14.8 编译验收

执行：

```powershell
dotnet build .\VSLoader.sln
```

期望：

```text
0 warnings
0 errors
```

如果提示 `VSLoader.exe` 被占用，说明程序正在运行，应先关闭 VSLoader 后重新构建。

## 15. 建议实施步骤

1. 扩展 `HotkeyConfig`，新增 `InputType`。
2. 修改 `HotkeyConfig.Clone()`。
3. 修改 `GlobalHotkeyService.Validate()`，区分 Keyboard/Mouse。
4. 修改 `GlobalHotkeyService.Format()`，支持 Mouse4/Mouse5。
5. 扩展 `GlobalHotkeyService.Register()`，Mouse 类型使用低级鼠标钩子。
6. 扩展 `Unregister()`，注销鼠标钩子。
7. 修改 `SettingsViewModel.SetRecordedHotkey()`，支持 input type。
8. 修改 `SettingsWindow.xaml.cs`，录制 Mouse4/Mouse5。
9. 编译项目。
10. 手动测试 Ctrl + Mouse4 / Alt + Mouse5。

## 16. 明确不做的事情

本次不做：

- 单独 Mouse4/Mouse5。
- 普通鼠标左/右/中键。
- 鼠标双击组合。
- 多快捷键配置。
- 后台托盘常驻。
- 退出后快捷键启动程序。
