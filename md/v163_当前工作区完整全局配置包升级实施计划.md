# 当前工作区完整全局配置包升级实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将全局配置包升级为可移植的当前工作区完整快照，同时保持旧版配置包可导入并避免污染本机运行状态。

**Architecture:** 配置包升级为 SchemaVersion 2，分为工作区业务配置、工作区界面偏好和本机配置。导入时先统一解析为内部模型，再分别写入 `config.json`、`factory-map.layout.json`、`window-layout.json` 和经过校验的 `app-settings.json` 字段。

**Tech Stack:** .NET 8、WPF、System.Text.Json、xUnit
