# v7 快捷项右键菜单编码规格说明

## 1. 文档目的

本文档用于指导编程 agent 或开发人员为 VSLoader 主界面快捷项列表增加右键菜单功能。

目标是让用户在某个快捷项上右键后，可以直接执行：

- AdminUI
- 编辑
- 删除

右键菜单功能必须复用现有主界面按钮逻辑，不重复实现业务逻辑。

## 2. 用户需求

用户在主界面快捷项列表中右键单击某一项后，弹出右键菜单。

菜单项：

```text
AdminUI
编辑
删除
```

点击菜单项后的行为与主界面顶部按钮完全一致：

| 右键菜单项 | 等价主按钮 | 行为 |
| --- | --- | --- |
| `AdminUI` | `AdminUI` | 打开当前快捷项对应的 `.jnlp` |
| `编辑` | `编辑` | 打开快捷项编辑窗口 |
| `删除` | `删除` | 弹确认框，确认后删除快捷项 |

## 3. 关键交互规则

### 3.1 右键哪一行，就操作哪一行

这是本需求最重要的规则。

如果当前选中项是 A，但用户右键 B：

```text
右键 B -> 自动选中 B -> 菜单操作 B
```

不能出现：

```text
右键 B -> 菜单操作 A
```

### 3.2 右键行时自动选中

用户右键某个 `DataGridRow` 时：

- 该行应自动成为当前选中项。
- `SelectedShortcut` 应更新为该行对应的快捷项。

### 3.3 右键空白区域

右键空白区域不应误操作旧选中项。

推荐处理：

```text
右键空白区域时不弹出菜单。
```

如果实现成本较高，也可以弹出菜单但菜单项不可用。

优先采用“不弹出菜单”。

### 3.4 忙碌状态

当程序处于忙碌状态，例如正在执行：

```text
自动获取连接
```

主界面已被禁用。

右键菜单也应不可用。

推荐：

```text
IsBusy = true 时，右键菜单不弹出。
```

## 4. 修改范围

主要修改：

```text
MainWindow.xaml
MainWindow.xaml.cs
```

不应修改：

```text
MainViewModel.cs 中现有 AdminUI / 编辑 / 删除业务逻辑
AdminUiService.cs
ConfigService.cs
ShortcutItem.cs
快捷项保存结构
```

说明：

- 允许为了绑定右键菜单而少量调整 XAML。
- 不允许复制一套新的 AdminUI、编辑、删除逻辑。

## 5. XAML 实现规格

目标控件：

```xml
<DataGrid x:Name="ShortcutsGrid" ...>
```

新增事件：

```xml
PreviewMouseRightButtonDown="ShortcutsGrid_PreviewMouseRightButtonDown"
```

新增右键菜单：

```xml
<DataGrid.ContextMenu>
    <ContextMenu>
        <MenuItem Header="AdminUI"
                  Command="{Binding PlacementTarget.DataContext.OpenAdminUiCommand, RelativeSource={RelativeSource AncestorType=ContextMenu}}" />
        <MenuItem Header="编辑"
                  Command="{Binding PlacementTarget.DataContext.EditShortcutCommand, RelativeSource={RelativeSource AncestorType=ContextMenu}}" />
        <MenuItem Header="删除"
                  Command="{Binding PlacementTarget.DataContext.DeleteShortcutCommand, RelativeSource={RelativeSource AncestorType=ContextMenu}}" />
    </ContextMenu>
</DataGrid.ContextMenu>
```

注意：

- WPF 的 `ContextMenu` 不在正常视觉树中。
- 不能直接写 `Command="{Binding OpenAdminUiCommand}"` 并假设一定能绑定到 `MainViewModel`。
- 推荐通过 `PlacementTarget.DataContext` 绑定到 DataGrid 的 ViewModel。

## 6. Code-behind 实现规格

修改：

```text
MainWindow.xaml.cs
```

新增事件处理：

```csharp
private void ShortcutsGrid_PreviewMouseRightButtonDown(object sender, MouseButtonEventArgs e)
{
    if (DataContext is MainViewModel { IsBusy: true })
    {
        e.Handled = true;
        return;
    }

    var row = FindVisualParent<DataGridRow>((DependencyObject)e.OriginalSource);
    if (row is null)
    {
        e.Handled = true;
        return;
    }

    row.Focus();
    row.IsSelected = true;
    ShortcutsGrid.SelectedItem = row.DataContext;
}
```

说明：

- `FindVisualParent<DataGridRow>` 当前项目中已经存在，可复用。
- 右键空白区域时 `row == null`，应阻止菜单弹出。
- 右键行时先选中该行，再让菜单正常弹出。

## 7. 命令复用规格

右键菜单必须复用现有命令：

```text
OpenAdminUiCommand
EditShortcutCommand
DeleteShortcutCommand
```

不能新增独立的：

```text
RightClickOpenAdminUiCommand
RightClickEditCommand
RightClickDeleteCommand
```

原因：

- 避免业务逻辑重复。
- 保证右键菜单和顶部按钮行为一致。
- 保证删除确认、AdminUI 缺失提示、忙碌状态禁用等行为一致。

## 8. 删除确认

右键菜单点击“删除”时，必须继续弹出原有确认框：

```text
确定要删除该快捷项吗？
```

确认后删除。

取消时不做修改。

## 9. AdminUI 行为

右键菜单点击 `AdminUI` 时：

- 如果已下载对应 `.jnlp`，正常打开。
- 如果未下载，使用现有提示：

```text
未找到对应 AdminUI 文件，请先点击“自动获取连接”。
```

不得改变现有 AdminUI 行为。

## 10. 验收标准

- 用户右键快捷项行时弹出菜单。
- 菜单包含 `AdminUI`、`编辑`、`删除`。
- 右键某一行时，该行会自动被选中。
- 当前选中 A、右键 B、点击编辑时，编辑的是 B。
- 当前选中 A、右键 B、点击删除时，删除的是 B。
- 当前选中 A、右键 B、点击 AdminUI 时，打开的是 B 对应的 `.jnlp`。
- 右键空白区域不弹出菜单。
- 忙碌状态下右键菜单不可用。
- 顶部按钮原有行为不受影响。
- 删除仍然弹确认框。
- `dotnet build .\VSLoader.sln` 必须通过。
