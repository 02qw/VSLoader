# v151 全应用按钮状态语义与焦点视觉编码规格说明

## 1. 背景

当前 VSLoader 已经完成了多轮窗口现代化改造，但按钮状态语义仍然不够统一。

用户反馈的核心问题不是单个按钮颜色不好看，而是：

```text
所有按钮都需要建立统一的软件设计语义。
用户看到按钮时，要能区分普通命令、主要命令、危险命令、禁用状态、模式启用状态、鼠标悬停、按下、键盘焦点。
```

当前最明显的问题出现在地图窗口：

```text
进入编辑模式后点击“连线”。
按钮会出现蓝色边框。
再次点击退出连线状态后，按钮仍可能保留蓝色焦点边框。
用户会误以为连线模式还在启用。
```

这个问题本质上是：

```text
键盘焦点视觉 和 业务激活状态 混在了一起。
```

后续实现必须从全应用层面统一按钮状态语义，而不是只修某一个按钮。

## 2. 当前代码现状

### 2.1 全局按钮样式

主要样式位于：

```text
VSLoader\Styles\ModernTheme.xaml
```

现有样式包含：

```text
ModernButtonStyle
ModernPrimaryButtonStyle
ModernQuietButtonStyle
ModernUpdateSoftwareButtonStyle
ModernDangerButtonStyle
ModernDialogPrimaryButtonStyle
ModernDialogSecondaryButtonStyle
ModernToolbarButtonStyle
ModernSettingsIconButtonStyle
ModernBannerActionButtonStyle
ModernWarningBannerActionButtonStyle
ModernErrorBannerActionButtonStyle
```

这些样式中多处存在 `IsKeyboardFocused` 触发器。

例如普通按钮在键盘焦点状态下会改为蓝色边框：

```xml
<Trigger Property="IsKeyboardFocused" Value="True">
    <Setter TargetName="Root" Property="Background" Value="#F8FBFF" />
    <Setter TargetName="Root" Property="BorderBrush" Value="{StaticResource ModernPrimaryBrush}" />
</Trigger>
```

这会导致普通鼠标点击后，按钮看起来像业务上被选中了。

问题是这些业务视觉和全局样式中的 `IsKeyboardFocused` 视觉可能叠加，导致按钮状态看起来不稳定。

## 3. 目标

本次目标是建立全应用统一按钮状态语义：

```text
普通按钮看起来像普通命令。
主要按钮看起来像推荐动作。
危险按钮看起来像危险操作。
禁用按钮明确不可操作。
模式按钮在业务启用时有明确 active 态。
键盘焦点不能被误解为 active 态。
鼠标点击后不应该让工具栏按钮长期残留强焦点视觉。
```

用户最终应能直观看懂：

```text
这个按钮只是刚刚被点过。
这个按钮当前真的处于启用状态。
这个按钮是主要推荐动作。
这个按钮有删除风险。
这个按钮现在不可用。
```

## 4. 非目标

本次不改业务逻辑：

```text
不改地图连线算法。
不改快捷项打开逻辑。
不改更新检测逻辑。
不改导入导出配置逻辑。
不改 AdminUI 自动登录逻辑。
```

本次不引入新的第三方 UI 框架。

本次不重构窗口结构，只收束按钮视觉语义和焦点处理边界。

## 5. 按钮状态语义规范

### 5.1 普通命令按钮

适用：

```text
打开
编辑
工作区
地图
AdminUI
导入图文件
导出图文件
普通取消按钮
```

视觉原则：

```text
白色或浅色背景
浅灰蓝边框
深色文字
hover 时轻微变亮或边框加深
pressed 时轻微压下或背景变浅蓝
不使用强蓝色边框表达鼠标点击后的焦点
```

### 5.2 主要命令按钮

适用：

```text
新增
保存
确认
确认导入
确定更新
```

视觉原则：

```text
蓝色填充
白色文字
hover 时蓝色加深
pressed 时更深
禁用时灰化
```

### 5.3 弱命令按钮

适用：

```text
检测更新
自动获取连接
批量新增识别
导出全局配置
导入全局配置
录制快捷键
清除快捷键
浏览路径
```

视觉原则：

```text
比普通按钮更低强调
适合放在第二行工具区或表单辅助区域
hover 有反馈，但不能抢主要按钮的视觉重心
```

### 5.4 危险命令按钮

适用：

```text
删除
删除工作区
确认删除类弹窗按钮
```

视觉原则：

```text
红色文字或红色边框
hover 时浅红背景
真正确认删除时可使用红色填充
不得使用蓝色焦点误导为普通操作
```

### 5.5 引导状态按钮

适用：

```text
更新软件
```

视觉原则：

```text
默认时按普通按钮显示
检测到软件更新时显示绿色引导态
用户点击“我知道了”或版本已经最新后恢复默认样式
hover / pressed 必须在绿色语义内变化
键盘焦点不能覆盖绿色引导态
```

### 5.6 模式开关按钮

适用：

```text
地图编辑模式
地图连线模式
地图多选模式
未来其他工具模式
```

视觉原则：

```text
业务状态为 true 时显示 active 态
业务状态为 false 时恢复普通工具按钮态
active 态必须强于 hover/focus
active 态由业务状态控制，不由 IsKeyboardFocused 控制
再次点击退出模式后，active 视觉必须立刻消失
```

建议文案：

```text
编辑模式开启时：编辑中
编辑模式关闭时：锁定
连线模式开启时：连线中
连线模式关闭时：连线
多选模式开启时：多选中
多选模式关闭时：多选节点
```

### 5.7 禁用状态

适用：

```text
没有可操作对象时的打开/编辑/删除
忙碌状态下不可点击按钮
未进入编辑模式时不可执行的地图编辑命令
```

视觉原则：

```text
灰化文字
灰化边框
浅灰背景
鼠标指针恢复 Arrow
hover 和 pressed 不应有明显反馈
```

### 5.8 键盘焦点

键盘焦点只表达：

```text
这个控件当前可通过键盘触发。
```

它不表达：

```text
这个模式正在启用。
这个按钮被选中。
这个功能处于打开状态。
```

视觉原则：

```text
键盘焦点使用轻量边框、细线、浅色外圈或轻微阴影。
不再使用和 active 态相同的蓝色粗边框。
鼠标点击工具栏按钮后，应尽量把焦点转移回内容区域。
表单和弹窗中保留合理键盘焦点。
```

## 6. 焦点处理边界

### 6.1 工具栏按钮

工具栏按钮通常是鼠标驱动操作。

适用窗口：

```text
MainWindow 顶部工具区
FactoryMapWindow 顶部工具区
```

处理规则：

```text
鼠标点击按钮完成后，不让按钮长期保留强焦点视觉。
主窗口按钮点击后，可将焦点恢复到 MainFocusTarget 或 ShortcutsGrid。
地图窗口按钮点击后，可将焦点恢复到 MapViewport 或地图窗口。
```

注意：

```text
不要影响按钮命令执行。
不要影响快捷键。
不要让焦点转移触发额外业务逻辑。
```

### 6.2 表单窗口按钮

适用窗口：

```text
SettingsWindow
ShortcutEditWindow
WorkspaceNameDialog
BatchImportWindow
MessageDialogWindow
```

处理规则：

```text
不要全局强制点击后失焦。
保留 Enter / Esc / Tab 的自然键盘体验。
只调整焦点视觉强度，避免看起来像 active 态。
```

### 6.3 标题栏按钮

适用：

```text
最小化
最大化/还原
关闭
```

处理规则：

```text
保持图标按钮语义。
hover/pressed 反馈清楚。
关闭按钮保留危险语义。
不参与业务 active 态。
```

## 7. 地图窗口专项要求

### 7.1 模式按钮状态

地图窗口需要将三类状态明确分开：

```text
编辑状态：isEditMode
连线状态：isConnectMode
多选状态：isMultiSelectMode
```

实现规则：

```text
isEditMode = false 时，连线和多选必须退出 active。
isConnectMode = true 时，MultiSelect 必须退出 active。
isMultiSelectMode = true 时，Connect 必须退出 active。
退出连线模式后，ConnectModeButton 不得残留 active 样式。
退出多选模式后，MultiSelectModeButton 不得残留 active 样式。
```

### 7.2 状态提示区

当前 `ModeStatusText` 只是普通灰字，不够醒目。

应改造成轻量状态提示组件，至少做到：

```text
浏览模式：低强调提示。
编辑模式：明确提示当前可拖动节点。
连线模式：明确提示“连线中：请选择起点端口”。
多选模式：明确提示“多选中：拖动空白区域框选节点”。
```

视觉建议：

```text
使用浅色背景胶囊或状态条。
文字颜色与状态一致。
不要遮挡地图内容。
不要占用过多工具栏空间。
```

## 8. 建议实现方式

### 8.1 新增或收束全局样式

在：

```text
VSLoader\Styles\ModernTheme.xaml
```

收束按钮样式。

建议保留并优化：

```text
ModernButtonStyle
ModernPrimaryButtonStyle
ModernQuietButtonStyle
ModernDangerButtonStyle
ModernUpdateSoftwareButtonStyle
ModernToolbarButtonStyle
ModernDialogPrimaryButtonStyle
ModernDialogSecondaryButtonStyle
ModernBannerActionButtonStyle
```

建议新增：

```text
ModernToolbarToggleButtonStyle
```

该样式用于地图连线、多选等模式按钮。

如果项目仍使用 `Button` 而非 `ToggleButton`，可以通过附加属性或绑定属性表达 active；若短期实现不引入附加属性，也可以通过 code-behind helper 统一设置 active 视觉，但不得继续散落手写颜色。

### 8.2 收束颜色资源

建议新增颜色资源：

```text
ModernFocusBorderBrush：轻量焦点边框
ModernActiveButtonBackgroundBrush：模式启用背景
ModernActiveButtonBorderBrush：模式启用边框
ModernActiveButtonTextBrush：模式启用文字
ModernSuccessBrush：绿色引导态
ModernSuccessHoverBrush：绿色 hover
ModernSuccessPressedBrush：绿色 pressed
```

避免不同文件中重复硬编码相近颜色。

### 8.3 地图按钮视觉刷新 helper

在：

```text
VSLoader\Views\FactoryMapWindow.xaml.cs
```

将：

```text
UpdateEditModeVisual
UpdateConnectModeVisual
UpdateMultiSelectModeVisual
```

改为更清晰的状态刷新。

建议结构：

```text
ApplyToolbarModeButtonVisual(Button button, bool isActive, string inactiveText, string activeText)
ApplyEditModeButtonVisual()
RefreshMapModeStatus()
RestoreMapFocusAfterToolbarClick()
```

原则：

```text
业务 active 状态集中由 helper 设置。
状态文字集中刷新。
点击后恢复 MapViewport 焦点。
不让键盘焦点覆盖 active 状态。
```

### 8.4 主窗口按钮焦点回收

在：

```text
VSLoader\MainWindow.xaml
VSLoader\MainWindow.xaml.cs
```

处理顶部工具区按钮点击后的焦点残留。

可选方案：

```text
对顶部工具按钮增加统一 PreviewMouseLeftButtonUp 或 Click 后焦点回收。
焦点恢复到 MainFocusTarget 或 ShortcutsGrid。
```

注意边界：

```text
设置图标按钮点击后会打开设置窗口，不需要强行抢焦点。
打开弹窗的按钮不应影响弹窗焦点。
搜索框输入时不能被工具按钮焦点逻辑干扰。
```

### 8.5 弹窗按钮只优化视觉，不强制失焦

弹窗和设置页按钮只改视觉强度：

```text
降低 IsKeyboardFocused 的强蓝边框。
保留键盘可达性。
保留 Enter / Esc 操作体验。
```
