# v17 主列表列头排序与升降序反馈编码规格说明

## 1. 需求背景

当前 VSLoader 主列表默认使用自定义排序逻辑：

```csharp
listCollectionView.CustomSort = new ShortcutSortService();
```

该逻辑主要用于让名称类似：

```text
热贴机_001
热贴机_002
热贴机_003
```

按照名称和编号自然排序。

但当前用户点击 `名称`、`备注`、`更新时间` 表头时，没有明显的排序反馈，例如：

- 没有升序/降序箭头。
- 用户不知道当前是否排序。
- 用户不知道当前是顺序还是逆序。

本次 v17 需求需要实现主列表列头点击排序，并显示直观的升降序反馈。

## 2. 需求目标

本次开发目标：

1. 用户点击 `名称` 表头时按名称排序。
2. 用户点击 `备注` 表头时按备注排序。
3. 用户点击 `更新时间` 表头时按更新时间排序。
4. 同一列重复点击时，在升序和降序之间切换。
5. 表头显示当前排序方向，例如上箭头/下箭头。
6. 初始状态默认按名称自然升序排序，并显示对应反馈。
7. 保持现有搜索、右键、双击、按钮逻辑不变。

## 3. 修改范围

可能涉及文件：

- `VSLoader\MainWindow.xaml`
- `VSLoader\MainWindow.xaml.cs`
- `VSLoader\ViewModels\MainViewModel.cs`
- `VSLoader\Services\ShortcutSortService.cs`

可根据实现方式新增：

- `VSLoader\Services\ShortcutColumnSortService.cs`
- 或扩展现有 `ShortcutSortService`

## 4. 当前技术现状

当前排序初始化逻辑在 `MainViewModel` 中：

```csharp
ShortcutsView = CollectionViewSource.GetDefaultView(Shortcuts);
ShortcutsView.Filter = FilterShortcut;
if (ShortcutsView is ListCollectionView listCollectionView)
{
    listCollectionView.CustomSort = new ShortcutSortService();
}
```

这会接管默认排序。

WPF `DataGrid` 默认列头排序依赖 `SortDescriptions`，但当前使用 `CustomSort`，因此不能简单依赖默认行为。

## 5. 推荐实现方案

### 5.1 使用 DataGrid Sorting 事件

在 `MainWindow.xaml` 的主列表 `DataGrid` 上增加：

```xml
Sorting="ShortcutsGrid_Sorting"
```

在 `MainWindow.xaml.cs` 中处理排序事件：

```csharp
private void ShortcutsGrid_Sorting(object sender, DataGridSortingEventArgs e)
```

要求：

- 设置 `e.Handled = true`。
- 根据点击列判断排序字段。
- 调用 ViewModel 的排序方法。
- 手动设置 `DataGridColumn.SortDirection`。

### 5.2 给列设置 SortMemberPath

每个可排序列应明确设置：

```xml
SortMemberPath="Name"
SortMemberPath="Description"
SortMemberPath="UpdatedAt"
```

这样 Sorting 事件可以可靠识别用户点击的是哪一列。

## 6. 排序字段定义

建议新增枚举：

```csharp
public enum ShortcutSortField
{
    Name,
    Description,
    UpdatedAt
}
```

也可以使用字符串，但枚举更清晰。

## 7. 排序规则

### 7.1 名称排序

名称排序必须继续使用当前自然排序逻辑。

当前自然排序逻辑来源：

```csharp
ShortcutSortService.Compare(...)
```

规则：

- 识别 `名称_编号`。
- 先按名称部分排序。
- 再按数字编号排序。
- 编号按数字比较，而不是字符串比较。

示例：

```text
热贴机_2
热贴机_10
```

应排序为：

```text
热贴机_2
热贴机_10
```

而不是：

```text
热贴机_10
热贴机_2
```

### 7.2 备注排序

按 `Description` 文本排序。

规则：

- 忽略大小写。
- 空值或空白值排在最后。

### 7.3 更新时间排序

按 `UpdatedAt` 时间排序。

升序：

```text
旧 -> 新
```

降序：

```text
新 -> 旧
```

## 8. 升降序切换规则

用户点击列头：

1. 如果点击的是当前排序列，则切换升序/降序。
2. 如果点击的是新列，则默认升序。

示例：

```text
点击名称：名称升序
再次点击名称：名称降序
点击备注：备注升序
再次点击备注：备注降序
点击更新时间：更新时间升序
再次点击更新时间：更新时间降序
```

## 9. 初始排序要求

程序启动后默认：

```text
排序字段：名称
排序方向：升序
```

并且界面应显示排序反馈。

如果使用 WPF 原生 `SortDirection`：

```csharp
column.SortDirection = ListSortDirection.Ascending;
```

则表头应显示默认排序箭头。

如果当前样式导致默认箭头不明显，可以在后续版本自定义表头箭头，但本次优先使用 WPF 原生箭头。

## 10. 推荐服务实现

建议扩展 `ShortcutSortService`，支持字段和方向：

```csharp
public sealed class ShortcutSortService : IComparer
{
    public ShortcutSortService(
        ShortcutSortField field = ShortcutSortField.Name,
        ListSortDirection direction = ListSortDirection.Ascending)
    {
        ...
    }
}
```

比较逻辑：

```csharp
var result = field switch
{
    ShortcutSortField.Name => CompareName(x, y),
    ShortcutSortField.Description => CompareText(x.Description, y.Description),
    ShortcutSortField.UpdatedAt => DateTime.Compare(x.UpdatedAt, y.UpdatedAt),
    _ => CompareName(x, y)
};

return direction == ListSortDirection.Descending ? -result : result;
```

注意：

- 空项仍然排在最后。
- 名称排序复用原有自然排序。

## 11. ViewModel 推荐接口

在 `MainViewModel` 中新增排序状态：

```csharp
public ShortcutSortField CurrentSortField { get; private set; }
public ListSortDirection CurrentSortDirection { get; private set; }
```

新增方法：

```csharp
public void ApplySort(ShortcutSortField field)
```

逻辑：

```csharp
if (CurrentSortField == field)
{
    CurrentSortDirection = CurrentSortDirection == ListSortDirection.Ascending
        ? ListSortDirection.Descending
        : ListSortDirection.Ascending;
}
else
{
    CurrentSortField = field;
    CurrentSortDirection = ListSortDirection.Ascending;
}

SetCustomSort(CurrentSortField, CurrentSortDirection);
```

另可新增：

```csharp
private void SetCustomSort(ShortcutSortField field, ListSortDirection direction)
```

用于构造比较器并刷新视图。

## 12. Code-behind 处理 UI 箭头

在 `MainWindow.xaml.cs` 的 `ShortcutsGrid_Sorting` 中：

1. 通过 `e.Column.SortMemberPath` 转换为 `ShortcutSortField`。
2. 调用 `viewModel.ApplySort(field)`。
3. 清空所有列的 `SortDirection`。
4. 设置当前列：

```csharp
e.Column.SortDirection = viewModel.CurrentSortDirection;
```

5. `e.Handled = true`。

示例：

```csharp
foreach (var column in ShortcutsGrid.Columns)
{
    column.SortDirection = null;
}

e.Column.SortDirection = viewModel.CurrentSortDirection;
```

## 13. 初始化排序箭头

程序打开后，默认排序已经是名称升序。

为了让界面也显示默认箭头，需要在窗口初始化后设置名称列的 `SortDirection`。

可在 `MainWindow.xaml.cs` 构造函数 `InitializeComponent()` 后执行：

```csharp
SetInitialSortDirection();
```

或在 `Loaded` 事件中执行。

要求：

- 找到 `SortMemberPath == "Name"` 的列。
- 设置 `SortDirection = ListSortDirection.Ascending`。

## 15. 验收标准

### 15.1 初始状态

启动应用后：

- 列表默认按名称自然升序排序。
- `名称` 表头显示升序箭头或等效排序反馈。

### 15.2 名称排序

点击 `名称` 表头：

- 如果当前为升序，则切换为降序。
- 如果当前为降序，则切换为升序。
- 名称排序必须保持自然编号排序。
- 表头箭头方向正确变化。

### 15.3 备注排序

点击 `备注` 表头：

- 按备注文本升序。
- 再次点击按备注文本降序。
- 表头箭头方向正确变化。

### 15.4 更新时间排序

点击 `更新时间` 表头：

- 按更新时间升序。
- 再次点击按更新时间降序。
- 表头箭头方向正确变化。

### 15.5 功能回归

以下功能必须正常：

1. 搜索过滤。
2. 单击选中。
3. 双击打开 VSCode。
4. 右键菜单。
5. AdminUI。
6. 打开。
7. 编辑。
8. 删除。
9. 自动获取连接。

### 15.6 编译验收

执行：

```powershell
dotnet build .\VSLoader.sln
```

期望：

```text
0 warnings
0 errors
```

如果提示 `VSLoader.exe` 被占用，说明程序正在运行，应先关闭 VSLoader 后重新构建。
