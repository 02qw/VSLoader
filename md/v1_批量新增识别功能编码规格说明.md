# v1 批量新增识别功能编码规格说明

## 1. 文档目的

本文档用于指导编程 agent 或开发人员在当前 VSLoader 项目中实现“批量新增识别”功能。

本功能基于现有 WPF / .NET 8 / MVVM 项目实现，必须遵守当前项目已有规则：

- 快捷项名称不可重复。
- 快捷项保存到 `%AppData%\VSLoader\config.json`。
- 新增快捷项后立即保存配置。
- 目标快捷项仍使用 `ShortcutItem` 模型。
- 不引入分组、最近打开记录、自动检测 VSCode 等额外功能。

## 2. 用户确认的实现选择

| 项目 | 选择 |
| --- | --- |
| CSV 解析 | 使用 `CsvHelper` NuGet 包 |
| 可新增项是否可取消勾选 | 可以勾选或取消勾选 |
| 是否记住上次路径 | 不记住 |
| 是否提供示例 CSV | 提供 `batch-rules.example.csv` |
| 预览显示范围 | 展示全部扫描结果，包括可新增、跳过、重名、规则错误 |

## 3. 需要新增的依赖

在 `VSLoader.csproj` 中新增 NuGet 包：

```powershell
dotnet add .\VSLoader\VSLoader.csproj package CsvHelper
```

用途：

- 稳定读取 Excel 导出的 CSV。
- 支持中文。
- 支持带引号字段。
- 支持字段内逗号。

## 5. 数据模型规格

### 5.1 BatchImportRule

用于表示 CSV 中的一条规则。

```csharp
public sealed class BatchImportRule
{
    public string MatchType { get; set; } = string.Empty;

    public string Pattern { get; set; } = string.Empty;

    public string DisplayName { get; set; } = string.Empty;

    public string NameTemplate { get; set; } = string.Empty;
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `MatchType` | v1 只支持 `Contains` |
| `Pattern` | 用于匹配文件夹名称的关键字 |
| `DisplayName` | 生成名称时使用的显示名，例如 `xxx` |
| `NameTemplate` | 生成快捷项名称的模板，例如 `{DisplayName}_{FolderName}` |

### 5.2 BatchImportPreviewItem

用于表示预览列表中的一行。

```csharp
public sealed partial class BatchImportPreviewItem : ObservableObject
{
    public string FolderName { get; set; } = string.Empty;

    public string TargetPath { get; set; } = string.Empty;

    public string GeneratedName { get; set; } = string.Empty;

    public string MatchedPattern { get; set; } = string.Empty;

    public string Status { get; set; } = string.Empty;

    public string Message { get; set; } = string.Empty;

    public bool CanImport { get; set; }

    [ObservableProperty]
    private bool isSelected;
}
```

`Status` 使用字符串即可，v1 不强制新增枚举。

状态值固定为：

```text
可新增
已跳过
名称重复
规则错误
```

规则：

- `CanImport = true` 时，`IsSelected` 默认 `true`。
- `CanImport = false` 时，`IsSelected` 必须为 `false`。
- 只有 `CanImport = true && IsSelected = true` 的项目会被导入。

## 6. CSV 文件规格

### 6.1 示例文件路径

项目中新增：

```text
VSLoader\Config\batch-rules.example.csv
```

文件内容：

```csv
MatchType,Pattern,DisplayName,NameTemplate
Contains,TSSM,xxx,{DisplayName}_{FolderName}
Contains,TSSP,yyy,{DisplayName}_{FolderName}
Contains,TRSM,zzz,{DisplayName}_{FolderName}
Contains,TPSM,aaa,{DisplayName}_{FolderName}
```

### 6.2 用户 CSV 文件表头

用户导入的 CSV 第一行必须是：

```csv
MatchType,Pattern,DisplayName,NameTemplate
```

字段名区分大小写按 CsvHelper 默认规则处理即可，但程序错误提示必须明确告诉用户正确表头。

### 6.3 CSV 规则校验

读取 CSV 后逐条校验：

- `MatchType` 必填。
- `Pattern` 必填。
- `DisplayName` 必填。
- `NameTemplate` 必填。
- `MatchType` v1 只允许 `Contains`，忽略大小写。

无效规则不参与匹配。

如果 CSV 中存在无效规则：

- 扫描可以继续。
- 预览中需要显示一条或多条 `规则错误` 记录。
- `规则错误` 记录不允许导入。

## 7. BatchImportService 职责

新增 `BatchImportService`。

职责：

- 读取 CSV 规则。
- 校验规则。
- 扫描目标父级目录下的一级子文件夹。
- 按规则生成预览项。
- 判断未匹配、名称重复、规则错误。
- 根据用户勾选结果生成 `ShortcutItem`。

建议方法：

```csharp
public IReadOnlyList<BatchImportRule> LoadRules(string csvPath, out List<string> errors);

public IReadOnlyList<BatchImportPreviewItem> BuildPreview(
    string parentFolderPath,
    IReadOnlyList<BatchImportRule> rules,
    IEnumerable<ShortcutItem> existingShortcuts);

public IReadOnlyList<ShortcutItem> CreateShortcuts(
    IEnumerable<BatchImportPreviewItem> previewItems);
```

实现规则：

- 只扫描目标父级目录下的一级子文件夹。
- 不递归扫描。
- 文件不参与扫描。
- 按 CSV 顺序从上到下匹配。
- 一个文件夹命中第一条规则后，不再继续匹配后续规则。
- 匹配忽略大小写。
- 生成名称后，需要和已有快捷项名称比较。
- 生成名称后，还需要和本次预览中已经可新增的名称比较。
- 重名项目状态为 `名称重复`。
- 未命中任何规则的文件夹状态为 `已跳过`。

## 8. 名称生成规则

名称模板 v1 支持两个变量：

```text
{DisplayName}
{FolderName}
```

用户确认的默认模板：

```text
{DisplayName}_{FolderName}
```

示例：

CSV：

```csv
MatchType,Pattern,DisplayName,NameTemplate
Contains,TSSM,xxx,{DisplayName}_{FolderName}
```

文件夹：

```text
8812_TSSM001
```

生成：

```text
xxx_8812_TSSM001
```

如果模板替换后得到空字符串，该预览项状态为：

```text
规则错误
```

## 9. 批量新增窗口 UI 规格

新增窗口：

```text
BatchImportWindow
```

窗口标题：

```text
批量新增识别
```

窗口至少包含：

- 目标父级文件夹路径输入框。
- “选择文件夹”按钮。
- CSV 规则文件路径输入框。
- “选择 CSV”按钮。
- “扫描预览”按钮。
- 预览统计区域。
- 预览列表。
- “确认新增”按钮。
- “取消”按钮。

### 9.1 预览统计区域

扫描后显示：

- 扫描文件夹数量。
- 可新增数量。
- 已跳过数量。
- 名称重复数量。
- 规则错误数量。
- 当前选中导入数量。

### 9.2 预览列表列

预览列表至少显示：

| 列名 | 说明 |
| --- | --- |
| 是否导入 | 复选框，仅可新增项可勾选 |
| 状态 | 可新增、已跳过、名称重复、规则错误 |
| 生成名称 | 生成的快捷项名称 |
| 目标路径 | 将要保存的目标路径 |
| 文件夹名 | 原始子文件夹名称 |
| 命中规则 | 命中的 `Pattern` |
| 说明 | 跳过或错误原因 |

### 9.3 按钮状态

- 未扫描前，“确认新增”不可用。
- 扫描后，如果没有任何已勾选的可新增项，“确认新增”不可用。
- “扫描预览”点击后刷新预览列表，覆盖上一次预览结果。

## 10. BatchImportViewModel 职责

新增 `BatchImportViewModel`。

职责：

- 持有目标父级路径。
- 持有 CSV 路径。
- 持有预览项集合。
- 调用 `DialogService` 选择文件夹。
- 调用 `DialogService` 选择 CSV。
- 调用 `BatchImportService` 扫描预览。
- 维护统计文本或统计属性。
- 提供确认新增命令。
- 返回用户确认导入的 `ShortcutItem` 列表。

建议属性：

```csharp
public string ParentFolderPath { get; set; }

public string CsvPath { get; set; }

public ObservableCollection<BatchImportPreviewItem> PreviewItems { get; }

public IReadOnlyList<ShortcutItem> ImportedShortcuts { get; }

public int ScannedCount { get; }

public int ImportableCount { get; }

public int SkippedCount { get; }

public int DuplicateCount { get; }

public int RuleErrorCount { get; }

public int SelectedImportCount { get; }
```

确认新增时：

- 只返回 `CanImport = true && IsSelected = true` 的项目。
- 不直接保存配置。
- 由 `MainViewModel` 接收返回结果后加入主列表并保存。

## 11. MainViewModel 修改规格

新增命令：

```csharp
OpenBatchImportCommand
```

点击后：

1. 创建 `BatchImportViewModel`，传入当前快捷项列表、`DialogService`、`BatchImportService`。
2. 打开 `BatchImportWindow`。
3. 如果窗口返回 `true`，读取 `ImportedShortcuts`。
4. 将导入的快捷项添加到 `Shortcuts`。
5. 调用现有保存逻辑保存配置。
6. 刷新主列表。

如果导入数量大于 0，建议弹窗提示：

```text
已新增 X 个快捷项。
```

## 13. 错误处理

| 场景 | 处理方式 |
| --- | --- |
| 目标父级路径为空 | 弹窗提示 |
| 目标父级路径不存在 | 弹窗提示 |
| CSV 路径为空 | 弹窗提示 |
| CSV 文件不存在 | 弹窗提示 |
| CSV 表头不正确 | 弹窗提示正确表头 |
| CSV 中有无效规则 | 预览显示 `规则错误` |
| 没有扫描到子文件夹 | 预览为空，并提示未扫描到子文件夹 |
| 没有任何可新增项 | “确认新增”不可用 |
| 重名项 | 预览显示 `名称重复`，不可导入 |
| 未匹配项 | 预览显示 `已跳过`，不可导入 |

## 14. 验收标准

- 主窗口“新增”按钮旁边出现“批量新增识别”按钮。
- 点击后打开“批量新增识别”窗口。
- 可以选择目标父级文件夹。
- 可以选择 CSV 文件。
- 项目中存在 `Config\batch-rules.example.csv` 示例文件。
- 使用以下 CSV 可以识别 TSSM 文件夹：

```csv
MatchType,Pattern,DisplayName,NameTemplate
Contains,TSSM,xxx,{DisplayName}_{FolderName}
```

- 文件夹 `8812_TSSM001` 生成名称 `xxx_8812_TSSM001`。
- 预览列表展示可新增、已跳过、名称重复、规则错误。
- 可新增项默认勾选，用户可以取消勾选。
- 取消勾选的项目不会导入。
- 未匹配任何规则的文件夹不会导入。
- 名称重复的项目不会导入。
- 点击确认新增后，导入项出现在主窗口快捷项列表。
- 导入后配置写入 `%AppData%\VSLoader\config.json`。
- 重启程序后，导入的快捷项仍然存在。
- `dotnet build .\VSLoader.sln` 必须通过。
