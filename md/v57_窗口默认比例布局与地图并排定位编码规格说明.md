# v57 窗口默认比例布局与地图并排定位编码规格说明

## 1. 需求背景

当前 VSLoader 主窗口和工厂地图窗口的尺寸主要来自 XAML 中的固定值：

```text
MainWindow:
Width="960"
Height="720"
MinWidth="900"
MinHeight="560"

FactoryMapWindow:
Width="620"
Height="720"
MinWidth="460"
MinHeight="360"
```

用户希望程序打开后的默认布局更接近当前截图：

```text
1. VSLoader 主窗口默认位于屏幕左侧。
2. 主窗口默认尺寸接近截图中左侧窗口的占比。
3. 地图窗口启动时默认关闭。
4. 用户点击“地图”按钮后，地图窗口打开在主窗口右侧。
5. 地图窗口位置和尺寸接近截图中右侧窗口。
6. 换不同分辨率电脑后，仍能保持相似比例和相对位置。
```

## 2. 需求目标

本次目标：

```text
用屏幕工作区百分比计算窗口默认布局，替代完全依赖固定像素尺寸。
```

完成后：

1. 程序启动时只显示主窗口，不自动打开地图窗口。
2. 主窗口默认显示在屏幕左侧，尺寸按当前屏幕工作区比例计算。
3. 点击“地图”后，地图窗口显示在主窗口右侧。
4. 地图窗口宽度使用主窗口右侧剩余空间。
5. 两个窗口在不同分辨率、不同任务栏高度、不同 Windows 缩放比例下，都能保持大致一致的布局感。

## 3. 非目标范围

本次不实现：

```text
1. 记忆用户上次手动拖动后的窗口位置。
2. 用户自定义窗口布局比例。
3. 多显示器复杂跨屏布局。
4. 地图窗口自动打开。
5. 地图内容坐标自动重新布局。
6. 改动主界面按钮、列表或地图内部节点逻辑。
```

本次只处理：

```text
主窗口默认位置/尺寸 + 地图窗口打开后的并排位置/尺寸。
```

## 4. 布局原则

必须使用：

```csharp
SystemParameters.WorkArea
```

不要使用：

```text
固定屏幕像素
SystemParameters.PrimaryScreenWidth
SystemParameters.PrimaryScreenHeight
```

原因：

```text
WorkArea 会自动扣除任务栏占用区域。
WPF 使用 DIP 单位，能更好适配 Windows 缩放比例。
```

## 5. 默认布局方案

### 5.1 主窗口默认布局

建议比例：

```text
Left = WorkArea.Left + WorkArea.Width * 0.01
Top = WorkArea.Top + WorkArea.Height * 0.055
Width = WorkArea.Width * 0.50
Height = WorkArea.Height * 0.70
```

含义：

```text
主窗口靠左。
顶部留一点桌面空间。
宽度约占可用工作区的一半。
高度约占可用工作区 70%。
```

### 5.2 地图窗口默认布局

地图窗口只有用户点击“地图”按钮后才打开。

建议：

```text
Gap = 10
MapLeft = MainWindow.Left + MainWindow.ActualWidth + Gap
MapTop = MainWindow.Top
MapRightMargin = WorkArea.Width * 0.01
MapWidth = WorkArea.Right - MapLeft - MapRightMargin
MapHeight = MainWindow.ActualHeight
```

含义：

```text
地图窗口贴在主窗口右侧。
地图窗口高度与主窗口一致。
地图窗口宽度吃掉右侧剩余空间。
右侧保留 1% 工作区边距。
```

## 6. 最小尺寸和小屏处理

现有 XAML 最小尺寸：

```text
MainWindow MinWidth = 900
MainWindow MinHeight = 560
FactoryMapWindow MinWidth = 460
FactoryMapWindow MinHeight = 360
```

在小分辨率电脑上，如果直接按比例计算，可能放不下两个窗口。

需要处理：

```text
1. 主窗口宽度不能小于 MinWidth。
2. 主窗口高度不能小于 MinHeight。
3. 地图窗口宽度不能小于 MinWidth。
4. 所有窗口不能超出 WorkArea 边界。
```

推荐策略：

```text
优先保证主窗口可用。
地图窗口如果右侧空间不足，则宽度取 Max(FactoryMapWindow.MinWidth, 可用右侧空间)。
如果仍然放不下，则地图窗口贴到 WorkArea.Right - MapWidth。
```

伪代码：

```csharp
var workArea = SystemParameters.WorkArea;
var gap = 10d;
var rightMargin = workArea.Width * 0.01;

var mainWidth = Clamp(workArea.Width * 0.50, MinWidth, workArea.Width * 0.70);
var mainHeight = Clamp(workArea.Height * 0.70, MinHeight, workArea.Height * 0.90);
var mainLeft = workArea.Left + workArea.Width * 0.01;
var mainTop = workArea.Top + workArea.Height * 0.055;

if (mainLeft + mainWidth > workArea.Right)
{
    mainLeft = workArea.Right - mainWidth;
}

if (mainTop + mainHeight > workArea.Bottom)
{
    mainTop = workArea.Bottom - mainHeight;
}
```

地图：

```csharp
var mapLeft = Left + ActualWidth + gap;
var mapTop = Top;
var availableRightWidth = workArea.Right - mapLeft - rightMargin;
var mapWidth = Math.Max(_factoryMapWindow.MinWidth, availableRightWidth);

if (mapLeft + mapWidth > workArea.Right)
{
    mapWidth = Math.Max(_factoryMapWindow.MinWidth, workArea.Right - mapLeft - rightMargin);
}

if (mapWidth < _factoryMapWindow.MinWidth)
{
    mapWidth = _factoryMapWindow.MinWidth;
    mapLeft = Math.Max(workArea.Left, workArea.Right - mapWidth - rightMargin);
}

var mapHeight = Math.Min(ActualHeight > 0 ? ActualHeight : Height, workArea.Height * 0.90);
```

## 7. 启动行为

程序启动时：

```text
1. 只显示 MainWindow。
2. 不自动打开 FactoryMapWindow。
3. MainWindow_Loaded 时应用默认比例布局。
4. 如果窗口当前不是 Normal 状态，不应用默认布局。
```

注意：

```text
不要在构造函数中应用布局。
原因是 WPF 窗口句柄和 DPI 信息在 Loaded 后更稳定。
```

推荐：

```csharp
private bool _hasAppliedDefaultLayout;

private void MainWindow_Loaded(object sender, RoutedEventArgs e)
{
    ApplyDefaultWindowLayoutOnce();
    ...
}
```

`_hasAppliedDefaultLayout` 保证只应用一次，避免窗口显示后因为 Loaded 或恢复操作重复跳位置。

## 8. 地图窗口打开行为

点击“地图”按钮：

```text
1. 如果地图窗口未打开，创建地图窗口。
2. 调用 PositionFactoryMapWindow()。
3. Show。
4. RefreshFactoryMap。
```

`PositionFactoryMapWindow()` 必须更新：

```text
Left
Top
Width
Height
```

当前代码只设置：

```csharp
_factoryMapWindow.Left = Left + ActualWidth;
_factoryMapWindow.Top = Top;
_factoryMapWindow.Height = ActualHeight > 0 ? ActualHeight : Height;
```

本次需要增加：

```csharp
_factoryMapWindow.Width = calculatedMapWidth;
```

并且需要加 `Gap`。

## 9. 主窗口移动/缩放后的地图跟随

当前已有：

```csharp
LocationChanged += MainWindow_LocationOrSizeChanged;
SizeChanged += MainWindow_LocationOrSizeChanged;
```

本次保留逻辑：

```text
如果地图窗口已经打开，主窗口移动或缩放时，地图窗口继续贴在主窗口右侧。
```

说明：

```text
这会让两个窗口保持并排关系。
```

## 10. 恢复窗口行为

托盘或快捷键恢复主窗口时：

```text
1. 主窗口恢复。
2. 如果用户之前打开了地图窗口，则地图窗口也恢复并重新定位。
3. 如果用户没有打开地图窗口，则不自动打开地图。
```

当前 `_isFactoryMapOpen` 已经表达用户是否打开地图窗口。

本次继续沿用：

```text
_isFactoryMapOpen = true 才 ShowFactoryMapIfNeeded。
```

## 11. 是否记忆用户位置

本次不记忆用户手动拖动窗口位置。

原因：

```text
当前需求是“启动时默认就是截图比例占比”。
固定比例默认布局比持久化位置更稳定。
```

后续如果需要，可再加：

```text
窗口布局记忆配置
重置布局按钮
```

## 14. 手工验收

### 14.1 启动默认主窗口

1. 关闭所有 VSLoader 进程。
2. 启动 VSLoader。
3. 确认只显示主窗口。
4. 确认地图窗口没有自动打开。
5. 确认主窗口位于屏幕左侧，比例接近截图。

### 14.2 打开地图窗口

1. 点击主窗口“地图”按钮。
2. 地图窗口打开在主窗口右侧。
3. 两个窗口中间有约 10px 间距。
4. 地图窗口高度和主窗口一致。
5. 地图窗口宽度占满右侧剩余空间，但不越过屏幕右边界。

### 14.3 主窗口移动

1. 地图窗口打开状态下拖动主窗口。
2. 地图窗口跟随定位到主窗口右侧。

### 14.4 主窗口缩放

1. 地图窗口打开状态下调整主窗口大小。
2. 地图窗口继续贴在主窗口右侧。
3. 地图窗口宽度根据右侧剩余空间重新计算。

### 14.5 最小化恢复

1. 打开地图窗口。
2. 最小化主窗口。
3. 地图窗口隐藏。
4. 通过托盘或快捷键恢复主窗口。
5. 地图窗口重新显示在主窗口右侧。

### 14.6 不同分辨率

在不同分辨率电脑上观察：

```text
1. 主窗口仍在左侧。
2. 地图窗口仍在右侧。
3. 两个窗口不超出屏幕工作区。
4. 整体比例与截图相似。
```
