# v158 工厂地图浏览编辑双模式与统一交互编码规格说明

## 1. 背景

当前工厂地图已经完成 Version 4 点线拓扑改造，节点、连接点和线段已经具备独立对象语义。

但地图窗口的操作模式仍然沿用旧设计：

```text
编辑模式
连线模式
多选模式
```

当前代码分别使用：

```text
isEditMode
isConnectMode
isMultiSelectMode
```

并在工具栏中提供：

```text
EditModeButton
ConnectModeButton
MultiSelectModeButton
```

其中连线和多选依赖编辑模式，并且会互相关闭。鼠标事件需要同时判断多组布尔状态，已经出现以下问题：

```text
1. 用户必须先进入编辑模式，再选择连线或多选，操作步骤不连贯。
2. 同一个连接点在不同模式下具有完全不同的行为。
3. 空白区域拖动有时平移、有时框选，取决于额外开关。
4. 连线和多选按钮状态可能与实际交互状态不一致。
5. selectedDevices 与 FactoryMapSelectionState 并存，选择状态仍然分裂。
6. 新增对象类型后，继续增加模式开关会使事件分支进一步膨胀。
```

本次改造需要将地图窗口收束为两个长期模式：

```text
浏览模式
编辑模式
```

所有对象编辑、连接、框选和移动能力都归入编辑模式，不再保留独立的连线模式和多选模式。

## 2. 核心目标

本次必须实现：

```text
1. 地图只存在 Browse 和 Edit 两个长期模式。
2. 删除连线模式和多选模式两个长期状态及对应按钮。
3. 编辑模式下可以移动节点、普通连接点、折弯点和线段。
4. 编辑模式下可以直接建立点与点、点与线段的连接。
5. 编辑模式下在空白区域左键拖动即可矩形框选。
6. 框选对象只包含节点和普通连接点。
7. 多选对象可以整体移动，并保持一次事务、一次保存。
8. 浏览模式继续负责查看、缩放、平移和打开节点。
9. 两种模式切换时保持当前缩放比例和视口位置。
10. 所有临时交互状态有统一的进入、结束和取消规则。
```

## 3. 非目标

本次不做：

```text
1. 不修改 Version 4 地图文件结构。
2. 不修改点线拓扑的业务定义。
3. 不实现斜线或新的自动布线算法。
4. 不实现完整撤销/重做栈。
5. 不让节点附属连接点脱离节点独立移动。
6. 不把线段和折弯点加入矩形框选。
7. 不修改地图快捷键 Alt+X 和窗口独立性逻辑。
8. 不修改地图导入导出和全局配置业务边界。
9. 不修改主窗口、AdminUI、更新器等非地图功能。
10. 不因为视觉交叉或线段重叠自动建立拓扑连接。
```

## 4. 两层状态模型

### 4.1 长期模式

新增明确枚举：

```csharp
public enum FactoryMapMode
{
    Browse,
    Edit
}
```

窗口中只保留一个权威字段：

```csharp
private FactoryMapMode mapMode = FactoryMapMode.Browse;
```

不得继续使用多个布尔值组合表达地图模式。

必须删除：

```text
isEditMode
isConnectMode
isMultiSelectMode
```

如迁移期间需要兼容只读判断，可以临时使用：

```csharp
private bool IsEditMode => mapMode == FactoryMapMode.Edit;
```

该属性不得再承载独立状态。

### 4.2 短期交互状态

连接、拖动、框选和平移不是长期模式，而是一次鼠标或键盘交互期间的短期状态。

建议新增：

```csharp
public enum FactoryMapInteractionKind
{
    Idle,
    Panning,
    MarqueeSelecting,
    DraggingObject,
    DraggingSelection
}
```

要求：

```text
1. 任意时刻最多只能有一个 InteractionKind。
2. 所有状态切换通过集中方法执行。
3. 不允许同时处于框选、拖动和平移状态。
4. MouseCapture 丢失、模式切换、地图重载和窗口关闭时必须收束活动手势。
```

等待连接终点不占用鼠标手势状态，应保存为独立但短生命周期的“连接草稿”：

```text
pendingTopologyPointId == null：没有连接草稿。
pendingTopologyPointId != null：正在等待连接终点。
```

连接草稿不是模式，不对应按钮，也不阻止用户通过中键或 `Space + 左键`临时平移地图。

连接草稿与其他手势的并存边界：

```text
允许与 Panning 并存，平移结束后继续等待原连接终点。
开始框选、拖动节点、拖动 Free 点、拖动 Bend 点或拖动线段时，先取消连接草稿。
完成连接、取消连接、切换模式、地图重载或窗口失焦时必须清空连接草稿。
```

建议提供：

```text
SetMapMode
BeginInteraction
CompleteInteraction
CancelInteraction
ResetTransientInteractionState
BeginConnectionDraft
CompleteConnectionDraft
CancelConnectionDraft
```

辅助坐标、拖动起点和内存快照可以继续保存在窗口中，但不得再由多组互斥布尔值决定当前交互。

## 5. 工具栏与模式视觉

### 5.1 工具栏结构

移除：

```text
ConnectModeButton
MultiSelectModeButton
```

将原来的单个“锁定 / 编辑中”按钮改成明确的两项分段模式控件：

```text
浏览
编辑
```

要求：

```text
1. 两项始终有且只有一项为 Active。
2. Active 由 mapMode 决定，不由键盘焦点决定。
3. 点击当前已激活项不产生额外状态变化。
4. 点击模式项后将焦点恢复到 MapViewport。
5. 导入图文件、导出图文件和自动获取连接按钮保持原有业务。
```

### 5.2 状态提示

`ModeStatusBadge` 继续保留，但文案只表达当前状态，不再展示三个模式。

基础文案：

```text
浏览模式
编辑模式
```

短期状态可以临时覆盖：

```text
请选择连接终点
已选中 N 个对象
正在移动 N 个对象
连接已创建
```

短期操作结束后恢复对应模式文案。

## 6. 浏览模式交互

浏览模式保持只读语义：

```text
滚轮：缩放地图。
空白区域左键拖动：平移地图。
中键拖动：允许从任意命中位置平移地图。
点击节点：执行现有快捷项打开或选中行为。
右键节点：保留现有浏览模式菜单行为。
```

浏览模式禁止：

```text
显示编辑连接点和折弯点手柄。
移动节点或其他拓扑对象。
创建、断开或删除线段。
空白框选。
空白右键新增普通连接点。
响应对象移动方向键。
```

节点点击与地图平移必须使用拖动阈值区分。发生明显拖动后，鼠标抬起不得再触发节点打开。

## 7. 编辑模式对象交互

### 7.1 通用命中优先级

编辑模式下命中优先级从高到低：

```text
1. 可见连接点。
2. 节点本体。
3. 线段透明命中区域。
4. 地图空白区域。
```

连接点位于线段或节点边缘时，必须优先命中连接点，避免用户想连接却拖动节点或线段。

所有点击与拖动使用统一阈值：

```text
DragThreshold 建议 4px。
```

鼠标移动未超过阈值时视为点击；超过阈值后才进入移动、平移或框选。

### 7.2 节点

```text
单击节点：单选节点。
Ctrl + 单击节点：追加或移除节点选择。
拖动未选中的节点：先单选，再移动该节点。
拖动已选中的节点：移动当前多选集合。
方向键：移动当前节点或多选集合。
```

节点移动继续带动四个 Attached 连接点，并更新相关线段。

### 7.3 节点附属连接点

节点的上、右、下、左四个 Attached 点在编辑模式可见。

```text
单击 Attached 点：选中并设为待连接起点。
再次单击同一点：取消待连接起点。
单击另一个有效连接点：完成连接。
方向键移动 Attached 点：沿用 V4 规则，移动所属节点。
```

Attached 点不得加入矩形框选，也不得脱离节点单独保存坐标。

### 7.4 普通连接点

```text
单击 Free 点：选中并设为待连接起点。
Ctrl + 单击 Free 点：追加或移除多选。
拖动 Free 点超过阈值：移动连接点，不进入待连接状态。
拖动已在多选集合中的 Free 点：移动整个多选集合。
方向键：移动当前 Free 点或多选集合。
右键：保留开始连接、断开和删除入口。
```

关键规则：

```text
连接草稿只在“未发生拖动的单击”完成后建立。
不能在 MouseDown 时立即建立待连接状态，否则拖动普通连接点会误触发连接。
Ctrl + 单击只负责追加或移除选择，不得建立连接草稿。
```

### 7.5 折弯点

```text
单击 Bend 点：单选折弯点。
拖动 Bend 点：调整路径形状。
方向键：调整折弯点。
右键：保留转换为普通连接点、删除折弯点等现有入口。
```

Bend 点不加入矩形框选，也不自动成为待连接起点。

需要从 Bend 点分支时，必须先通过拓扑服务转换为 Free 点。

### 7.6 线段

```text
单击线段：单选逻辑线段。
拖动线段：移动水平或垂直通道。
方向键：沿现有线段移动规则调整通道。
右键：保留从此处开始连接、插入普通连接点和断开线段。
```

线段不加入矩形框选。

存在待连接起点时单击线段：

```text
1. 计算投影位置。
2. 靠近端点时复用端点。
3. 否则在线段上插入 Free 点并拆分线段。
4. 将待连接起点连接到该 Free 点。
5. 一次事务保存全部变化。
```

## 8. 统一连接流程

### 8.1 开始连接

允许以下入口：

```text
单击节点 Attached 点。
单击普通 Free 点。
连接点右键菜单选择“开始连接”。
线段右键菜单选择“从此处开始连接”。
```

开始连接后：

```text
pendingTopologyPointId = 起点 ID
起点显示明确高亮
状态栏显示“请选择连接终点”
```

### 8.2 完成连接

有效终点：

```text
Attached 点
Free 点
可拆分线段
```

禁止：

```text
连接起点自身。
连接不存在的对象。
重复创建相同拓扑连接。
直接连接 Bend 点。
创建零长度或斜线段。
```

连接成功后：

```text
1. 清空 pendingTopologyPointId。
2. 选中终点或新创建的 Free 点。
3. 保存布局。
4. 状态栏显示“连接已创建”。
```

连接失败时：

```text
不得留下半完成线段。
恢复操作前拓扑快照。
保留或取消待连接状态必须有确定规则。
```

本规格统一为：

```text
业务校验失败：保留起点，允许用户重新选择终点。
保存失败：回滚全部变化并取消待连接状态。
```

### 8.3 取消连接

以下行为取消待连接：

```text
再次单击原起点。
单击地图空白区域。
按 Escape。
切换到浏览模式。
导入或重新加载地图。
窗口失去激活且当前尚未提交连接。
```

点击节点主体时，应先取消待连接，再执行节点选择，不得把节点主体隐式当成连接点。

## 9. 空白框选

### 9.1 开始条件

仅满足以下条件时开始框选：

```text
mapMode == Edit
鼠标左键从真实空白区域按下
未按 Space
不是中键操作
不存在其他正在执行的拖动
鼠标移动超过 DragThreshold
```

单击空白但未超过阈值：

```text
取消待连接。
清空当前选择。
不创建零尺寸选择框。
```

### 9.2 框选对象范围

矩形框选只包含：

```text
节点 Device
普通连接点 Free
```

明确排除：

```text
Attached 节点连接点
Bend 折弯点
Segment 线段
```

节点命中规则：

```text
节点边界矩形与选择矩形相交即选中。
```

普通连接点命中规则：

```text
连接点中心位于选择矩形内，或连接点可见圆形边界与选择矩形相交即选中。
```

### 9.3 选择集合规则

```text
普通框选：替换原选择集合。
Ctrl + 框选：在原选择集合上追加命中的节点和 Free 点。
Ctrl + 单击已选对象：从集合中移除该对象。
Escape：无待连接时清空选择。
```

不引入 Shift 框选语义，避免与 1px 精细移动和其他快捷键产生额外冲突。

## 10. 多选整体移动

### 10.1 可整体移动对象

多选集合只允许包含：

```text
Device
Free ConnectionPoint
```

单击 Bend 或 Segment 时应切换为该对象单选，不得形成包含线段或 Bend 的混合多选集合。

### 10.2 移动事务

多选移动不得逐个对象保存。

必须：

```text
1. 操作前捕获一次完整拓扑快照。
2. 所有选中对象基于同一个原始坐标和同一个 delta 计算目标位置。
3. 所有对象移动完成后统一执行拓扑校验和正交归一化。
4. 任意对象移动失败则整体回滚。
5. 鼠标拖动期间只更新必要 Visual。
6. 鼠标释放后执行一次网格吸附和一次保存。
7. 键盘连续移动使用现有约 150ms 保存防抖。
```

建议为 `FactoryMapMovementService` 增加批量入口，避免窗口循环调用单对象移动造成中间状态互相影响：

```csharp
MoveObjects(
    FactoryMapDeviceViewData map,
    IReadOnlyCollection<FactoryMapObjectRef> objects,
    double deltaX,
    double deltaY,
    bool snapToGrid,
    double gridSize)
```

特别边界：

```text
两个彼此相连的 Free 点同时移动时，连接它们的线段应整体平移，不能被重复归一化后变形。
节点与其关联的 Free 点同时移动时，两者使用同一 delta，不能重复移动 Attached 点。
```

## 11. 编辑模式平移

由于空白左键拖动已用于框选，编辑模式需要保留明确的平移入口：

```text
中键拖动：平移地图。
Space + 左键拖动：平移地图。
滚轮：缩放地图。
```

优先级：

```text
1. 中键拖动或 Space + 左键拖动始终优先于框选。
2. Space 仅在按住期间生效，松开后恢复编辑行为。
3. 平移不得改变对象选择。
4. 平移不得创建、取消或完成连接草稿；平移结束后继续等待原终点。
5. 触控板现有双指滚动逻辑保持不变。
```

## 12. 统一选择状态

当前存在：

```text
selectedDevices
topologySelection
selectedConnector
selectedEdge 等旧选择字段
```

最终权威选择状态必须收束到：

```text
FactoryMapSelectionState
```

建议扩展接口：

```text
Select
Toggle
ReplaceWith
AddRange
Remove
Clear
Contains
```

`selectedDevices` 不得继续作为第二份权威状态。

如现有移动或视觉方法仍需要节点实例，应根据 `FactoryMapObjectRef` 从 `currentMap.Devices` 派生：

```text
GetSelectedDevices()
GetSelectedFreePoints()
```

不得在两个集合中分别增加、删除和清空同一选择。

旧 Version 3 运行时对象只能用于迁移兼容，不得重新参与新的双模式交互链路。

## 13. 模式切换规则

### 13.1 浏览切换到编辑

```text
1. 保持当前缩放比例和地图偏移。
2. 清理残留 MouseCapture 和短期交互状态。
3. 清空待连接起点。
4. 切换 mapMode 为 Edit。
5. 显示节点 Attached 点、Free 点和必要编辑命中区域。
6. 更新工具栏和状态提示。
7. 恢复 MapViewport 焦点。
```

不得调用自动适配视图或重置缩放。

### 13.2 编辑切换到浏览

```text
1. 收束当前拖动或框选。
2. 刷新或回滚未完成的拓扑修改。
3. 调用 FlushPendingTopologySave。
4. 保存失败时保持 Edit，不得静默切换。
5. 清空待连接起点和选择状态。
6. 释放 MouseCapture。
7. 切换 mapMode 为 Browse。
8. 隐藏编辑手柄并重绘地图。
9. 保持当前缩放比例和地图偏移。
```

### 13.3 地图重载和窗口关闭

以下入口必须调用统一清理逻辑：

```text
导入图文件成功。
切换当前地图。
重新打开地图窗口。
关闭地图窗口。
退出 VSLoader。
```

要求：

```text
不保留指向旧地图对象的选择引用。
不保留待连接点 ID。
不保留 MouseCapture。
不保留未结束的框选矩形。
未保存拓扑必须保存成功或回滚。
```

## 14. Escape 与焦点边界

### 14.1 Escape 优先级

编辑模式下按 Escape：

```text
1. 正在拖动、框选或平移：取消当前交互并恢复操作前状态。
2. 正在等待连接终点：取消待连接，但保留当前对象选择。
3. 没有短期交互：清空对象选择。
4. 以上都不存在：不处理按键。
```

### 14.2 窗口失去激活

窗口失去激活时：

```text
正在拖动：结束或回滚，不能保持 MouseCapture。
正在框选：取消框选矩形。
存在连接草稿：取消待连接状态。
普通选择：可以保留。
```

窗口重新激活后必须回到 `Idle`，不能因为上次失焦留下下一次点击误操作。

## 15. 保存与错误处理

以下操作必须走快照、校验、保存、回滚链路：

```text
创建连接。
在线段上插入 Free 点并连接。
移动单个 Free/Bend/Segment。
移动多个节点和 Free 点。
断开或删除拓扑对象。
```

错误处理要求：

```text
1. 业务校验失败只显示可追溯原因，不写入文件。
2. 保存失败恢复操作前快照。
3. 回滚后重绘当前地图。

```

错误提示应说明失败动作，例如：

```text

```
