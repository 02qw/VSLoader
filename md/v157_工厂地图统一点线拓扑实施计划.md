# v157 工厂地图统一点线拓扑实施计划

> **供编程 Agent 执行：** 按任务顺序使用测试驱动开发。每一项先增加失败测试，再写最小实现；每阶段完成后运行 FactoryMap 目标测试和 Debug 独立输出构建。

**目标：** 将现有 `FactoryMapDeviceEdge + Points` 地图升级为 Version 4 点线拓扑，同时兼容读取 Version 3 布局并保留现有地图窗口行为。

**架构：** 持久化层使用稳定节点 ID、独立连接点和独立线段；`FactoryMapTopologyService` 负责所有拓扑事务，窗口只负责输入编排与渲染。旧 Edge/Connector 模型仅作为 Version 3 迁移 DTO 保留，迁移成功后运行时只使用 Version 4 对象。

**技术栈：** .NET 8、WPF、System.Text.Json、xUnit。
