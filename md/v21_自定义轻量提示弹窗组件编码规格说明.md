# v21 自定义轻量提示弹窗组件编码规格说明

## 1. 需求背景

v20 已经尝试为系统 `MessageBox` 传入 Owner，让提示框挂到 VSLoader 当前窗口。

但实际运行发现：

- 系统 `MessageBox` 即使传入 Owner，也不一定严格以 VSLoader 窗口为中心。
- 弹窗位置仍可能受 Windows 原生消息框策略、DPI、多屏、窗口状态影响。
- 用户明确希望提示框以 VSLoader 程序窗口为中心。

因此，本次 v21 需求决定放弃系统 `MessageBox`，改为自定义轻量 WPF 提示弹窗组件。

## 2. 需求目标

本次开发目标：

1. 自定义一个轻量提示弹窗窗口。
2. 替换 `DialogService.ShowInfo`。
3. 替换 `DialogService.ShowError`。
4. 替换 `DialogService.Confirm`。
5. 保证提示弹窗相对 VSLoader 当前活动窗口居中。
6. 保证弹窗是模态窗口。
7. 保持业务层调用方式不变。
8. 不重写文件选择框。
9. 不引入第三方库。
10. 不影响主列表性能。

## 3. 修改范围

需要新增：

- `VSLoader\Views\MessageDialogWindow.xaml`
- `VSLoader\Views\MessageDialogWindow.xaml.cs`

需要修改：

- `VSLoader\Services\DialogService.cs`

原则上不需要修改：

- 所有 ViewModel 调用点
- `MainViewModel`
- `ShortcutEditViewModel`
- `BatchImportViewModel`
- `SettingsViewModel`
- 文件选择框逻辑
- AdminUI 逻辑

## 4. 当前项目中弹窗使用情况

经源码检查，项目业务提示弹窗均通过 `DialogService` 调用，没有发现业务代码绕过 `DialogService` 直接调用 `MessageBox.Show`。

因此只要替换以下三个方法，即可覆盖当前所有业务提示/错误/确认弹窗：

```csharp
DialogService.ShowInfo(...)
DialogService.ShowError(...)
DialogService.Confirm(...)
```

## 5. 必须覆盖的提示类型

### 5.1 信息提示

来源示例：

- 当前没有快捷项可处理。
- 自动获取连接完成。
- 批量新增完成。
- 未扫描到子文件夹。

按钮：

```text
确定
```

### 5.2 错误提示

来源示例：

- 名称不能为空。
- 目标路径不能为空。
- CSV 文件不存在。
- AdminUI 打开失败。
- 打开 VSCode 失败。
- 配置文件读取失败。
- 配置保存失败。
- 写入剪贴板失败。

按钮：

```text
确定
```

### 5.3 确认提示

来源示例：

- 删除快捷项确认。

按钮：

```text
是
否
```

返回：

```text
是 -> true
否 / 关闭窗口 -> false
```

## 6. 不重写的内容

本次不重写以下系统选择框：

- `SelectExeFile`
- `SelectFile`
- `SelectCsvFile`
- `SelectFolder`

原因：

- 文件选择器和文件夹选择器属于系统级交互。
- 自己重写成本高且没有必要。
- 当前主要问题集中在提示/错误/确认弹窗。

## 7. 自定义窗口设计

### 7.1 文件结构

新增：

```text
VSLoader\Views\MessageDialogWindow.xaml
VSLoader\Views\MessageDialogWindow.xaml.cs
```

### 7.2 窗口基础属性

建议：

```xml
<Window
    Title="VSLoader"
    Width="420"
    SizeToContent="Height"
    MinHeight="180"
    MaxWidth="560"
    WindowStartupLocation="CenterOwner"
    ResizeMode="NoResize"
    ShowInTaskbar="False"
    WindowStyle="SingleBorderWindow">
```

要求：

- `Owner` 必须在 code-behind 中设置。
- `WindowStartupLocation` 必须为 `CenterOwner`。
- 如果没有 owner，则回退 `CenterScreen`。

### 7.3 内容结构

推荐布局：

```text
标题栏：系统窗口标题 VSLoader

内容区：
[图标] [消息文本]

按钮区：
[确定]
或
[是] [否]
```

XAML 推荐：

```xml
<Grid>
    <Grid.RowDefinitions>
        <RowDefinition Height="*" />
        <RowDefinition Height="Auto" />
    </Grid.RowDefinitions>

    <Grid Grid.Row="0">
        <Grid.ColumnDefinitions>
            <ColumnDefinition Width="Auto" />
            <ColumnDefinition Width="*" />
        </Grid.ColumnDefinitions>
        <TextBlock Text="{Binding IconText}" />
        <TextBlock Text="{Binding Message}" TextWrapping="Wrap" />
    </Grid>

    <StackPanel Grid.Row="1" Orientation="Horizontal" HorizontalAlignment="Right">
        ...
    </StackPanel>
</Grid>
```

### 7.4 图标设计

为了轻量化，不引入图片资源，不引入图标库。

推荐使用文字符号：

```text
Info:    i
Error:   !
Confirm: ?
```

可用圆形 Border 包住文字，颜色区分：

```text
Info: 蓝色
Error: 红色
Confirm: 蓝色或橙色
```

注意：

- 不使用复杂 SVG。
- 不使用动画。
- 不使用图片。

### 7.5 文本要求

消息文本：

- 支持多行。
- 支持自动换行。
- 不截断错误信息。
- 最大宽度受窗口控制。

建议：

```xml
TextWrapping="Wrap"
FontSize="14"
```

## 8. 弹窗类型设计

建议新增枚举：

```csharp
public enum MessageDialogKind
{
    Info,
    Error,
    Confirm
}
```

可以放在：

```text
VSLoader\Views\MessageDialogWindow.xaml.cs
```

或单独文件：

```text
VSLoader\Views\MessageDialogKind.cs
```

为简单起见，可放在窗口 code-behind 同 namespace 下。

## 9. 返回结果设计

建议内部使用：

```csharp
public bool Confirmed { get; private set; }
```

行为：

- Info / Error 点击确定：关闭窗口。
- Confirm 点击是：`Confirmed = true`，关闭窗口。
- Confirm 点击否：`Confirmed = false`，关闭窗口。
- Confirm 点击右上角关闭：`Confirmed = false`。

`DialogService.Confirm` 返回：

```csharp
return dialog.ShowDialog() == true && dialog.Confirmed;
```

也可以让 Confirm 的 Yes 设置：

```csharp
DialogResult = true;
```

No 设置：

```csharp
DialogResult = false;
```

## 10. Owner 居中策略

`DialogService` 中继续保留 Owner 获取逻辑：

```csharp
private static Window? GetOwnerWindow()
{
    return System.Windows.Application.Current?.Windows
        .OfType<Window>()
        .FirstOrDefault(window => window.IsActive)
        ?? System.Windows.Application.Current?.MainWindow;
}
```

创建自定义弹窗时：

```csharp
var owner = GetOwnerWindow();
var dialog = new MessageDialogWindow(...);
if (owner is not null)
{
    dialog.Owner = owner;
    dialog.WindowStartupLocation = WindowStartupLocation.CenterOwner;
}
else
{
    dialog.WindowStartupLocation = WindowStartupLocation.CenterScreen;
}
dialog.ShowDialog();
```

这样可以保证：

- 主窗口中弹出的提示框居中于主窗口。
- 设置窗口、批量导入窗口、编辑窗口中弹出的提示框居中于当前子窗口。
- 忙碌遮罩期间弹窗仍然在 VSLoader 窗口中心。

## 11. DialogService 改造要求

### 11.1 ShowInfo

从系统 MessageBox 改为：

```csharp
ShowMessage(message, MessageDialogKind.Info);
```

### 11.2 ShowError

从系统 MessageBox 改为：

```csharp
ShowMessage(message, MessageDialogKind.Error);
```

### 11.3 Confirm

从系统 MessageBox 改为：

```csharp
return ShowConfirm(message);
```

### 11.4 文件选择框保持原状

以下方法保留 v20 的 owner 处理：

- `SelectExeFile`
- `SelectFile`
- `SelectCsvFile`
- `SelectFolder`

不要改回无 owner。

## 12. 性能要求

自定义弹窗必须轻量：

- 不使用第三方 UI 库。
- 不使用动画。
- 不使用复杂阴影。
- 不常驻内存。
- 每次调用时创建，用完关闭。
- 不影响主列表虚拟化。

## 13. 不允许改变的内容

本次不允许改变：

- 业务提示文案。
- 调用点。
- ViewModel 逻辑。
- 错误判断逻辑。
- 文件选择框逻辑。
- 主窗口布局。
- AdminUI 逻辑。
- 配置保存逻辑。

## 14. 验收标准

### 14.1 主窗口弹窗居中

在主窗口触发：

- 当前没有快捷项可处理。
- 自动获取连接完成。
- 打开 VSCode 失败。

期望：

- 弹窗中心与 VSLoader 主窗口中心一致。
- 不再出现在屏幕中心或主窗口偏右。

### 14.2 子窗口弹窗居中

在以下窗口中触发校验错误：

- 新增/编辑窗口
- 批量新增识别窗口
- 设置窗口

期望：

- 弹窗居中于当前子窗口。

### 14.3 确认弹窗

点击删除快捷项：

- 弹出自定义确认框。
- 点击 `是` 执行删除。
- 点击 `否` 或关闭窗口不删除。

### 14.4 信息/错误弹窗

- Info 显示信息样式。
- Error 显示错误样式。
- 长文本能够换行显示。

### 14.5 编译验收

执行：

```powershell
dotnet build .\VSLoader.sln
```

期望：

```text
0 warnings
0 errors
```

如果提示 `VSLoader.exe` 被占用，说明程序正在运行，应先关闭 VSLoader 后重新构建。
