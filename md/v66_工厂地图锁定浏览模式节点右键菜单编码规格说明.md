# v66 工厂地图锁定浏览模式节点右键菜单编码规格说明

## 1. 需求背景

当前 VSLoader 主界面快捷项列表已经支持右键菜单：

```text
1. VSCode
2. AdminUI
3. 获取AdminUI连接
4. WebUI
5. 编辑
6. 删除
```

当前工厂地图窗口中，每个设备节点也和一个快捷项一一对应。  
用户在地图中看到设备节点后，希望可以直接右键节点执行快捷项相关操作，不需要再回到左侧主列表中找对应快捷项。

新需求：

```text
在工厂地图窗口处于红色“锁定”浏览模式时，用户右键某个地图节点，弹出一个节点右键菜单。
菜单功能仿照主界面快捷项右键菜单，底层尽量复用主界面已有快捷项命令逻辑。
```

## 2. 需求目标

完成后：

```text
1. 地图窗口处于红色“锁定”浏览模式时，右键设备节点会弹出右键菜单。
2. 地图窗口处于绿色“编辑”模式时，右键设备节点不弹出快捷项操作菜单。
3. 地图节点右键菜单样式参考主界面快捷项右键菜单。
4. 地图节点右键菜单功能和主界面快捷项右键菜单一致。
5. 右键地图节点时，先把该节点对应快捷项同步选中到主窗口 SelectedShortcut。
6. 菜单功能尽量复用 MainViewModel 已有命令，不重复实现 VSCode/AdminUI/WebUI/编辑/删除业务逻辑。
7. 删除快捷项后，地图自动刷新，对应节点消失，相关连线不再显示。
```

## 3. 非目标范围

本次不实现：

```text
1. 地图节点专属删除，仅从地图隐藏节点但保留快捷项。
2. 删除节点后自动重连前后节点。
3. 地图右键菜单自定义菜单项配置。
4. 编辑地图节点名称但不修改快捷项名称。
5. 编辑地图节点坐标。
6. 编辑模式下的节点右键快捷项菜单。
7. 批量选择节点后的批量右键菜单。
8. 修改主界面快捷项右键菜单功能。
9. 修改 AdminUI/WebUI/VSCode 的底层打开算法。
```

说明：

```text
本次地图右键菜单不是地图编辑功能，而是快捷项功能入口。
```

## 5. 推荐设计

### 5.1 回调设计

地图窗口不应该直接持有 `MainViewModel`，也不应该直接实现 VSCode/AdminUI/WebUI 逻辑。

推荐让 `FactoryMapWindow` 新增一个回调：

```csharp
Action<ShortcutItem, string> executeShortcutAction
```

或者更类型安全地新增枚举：

```csharp
internal enum FactoryMapShortcutAction
{
    OpenVsCode,
    OpenAdminUi,
    DownloadAdminUiLink,
    OpenWebUi,
    Edit,
    Delete
}
```

然后构造函数改为：

```csharp
public FactoryMapWindow(
    Action<ShortcutItem> selectShortcut,
    Action<ShortcutItem, FactoryMapShortcutAction> executeShortcutAction,
    Func<FactoryMapDeviceViewData, bool> saveLayout,
    Func<IReadOnlyList<ShortcutItem>> getCurrentShortcuts,
    Func<string> getLayoutPath)
```

推荐采用枚举方案，避免字符串拼写错误。

### 5.2 MainWindow 负责命令复用

`MainWindow` 创建 `FactoryMapWindow` 时传入回调：

```csharp
_factoryMapWindow = new FactoryMapWindow(
    SelectShortcutFromMap,
    ExecuteShortcutActionFromMap,
    SaveFactoryMapLayout,
    GetCurrentShortcutsForMap,
    ResolveFactoryMapLayoutPath)
{
    Owner = this
};
```

新增方法：

```csharp
private void ExecuteShortcutActionFromMap(ShortcutItem shortcut, FactoryMapShortcutAction action)
{
    SelectShortcutFromMap(shortcut);

    if (DataContext is not MainViewModel viewModel)
    {
        return;
    }

    switch (action)
    {
        case FactoryMapShortcutAction.OpenVsCode:
            if (viewModel.OpenShortcutCommand.CanExecute(null))
            {
                viewModel.OpenShortcutCommand.Execute(null);
            }
            break;

        case FactoryMapShortcutAction.OpenAdminUi:
            if (viewModel.OpenAdminUiCommand.CanExecute(null))
            {
                viewModel.OpenAdminUiCommand.Execute(null);
            }
            break;

        case FactoryMapShortcutAction.DownloadAdminUiLink:
            if (viewModel.DownloadSelectedAdminUiLinkCommand.CanExecute(null))
            {
                viewModel.DownloadSelectedAdminUiLinkCommand.Execute(null);
            }
            break;

        case FactoryMapShortcutAction.OpenWebUi:
            if (viewModel.OpenWebUiCommand.CanExecute(null))
            {
                viewModel.OpenWebUiCommand.Execute(null);
            }
            break;

        case FactoryMapShortcutAction.Edit:
            if (viewModel.EditShortcutCommand.CanExecute(null))
            {
                viewModel.EditShortcutCommand.Execute(null);
            }
            break;

        case FactoryMapShortcutAction.Delete:
            if (viewModel.DeleteShortcutCommand.CanExecute(null))
            {
                viewModel.DeleteShortcutCommand.Execute(null);
            }
            break;
    }
}
```

说明：

```text
1. 先选中快捷项，再执行命令。
2. 复用 MainViewModel 现有命令。
3. 不在地图窗口中重复写打开/编辑/删除逻辑。
```

```csharp
private MenuItem CreateDeviceMenuItem(string header, FactoryMapDeviceViewNode device, FactoryMapShortcutAction action)
{
    var item = new MenuItem
    {
        Header = header,
        MinWidth = 130,
        Padding = new Thickness(14, 8, 14, 8),
        Foreground = new SolidColorBrush(WpfColor.FromRgb(17, 24, 39)),
        Background = WpfBrushes.Transparent,
        Tag = (device, action)

    item.Click += DeviceMenuItem_Click;
    return item;
```

点击处理：

```csharp
private void DeviceMenuItem_Click(object sender, RoutedEventArgs e)
{
    if (sender is not MenuItem { Tag: ValueTuple<FactoryMapDeviceViewNode, FactoryMapShortcutAction> payload })
    {
        return;
    }

    var (device, action) = payload;
    executeShortcutAction(device.Shortcut, action);
}
```

## 8. 删除快捷项与地图连线行为

删除菜单项复用主界面 `DeleteShortcutCommand`。

删除后的行为：

```text
1. 删除的是快捷项，不是单纯地图节点。
2. 快捷项从配置和主列表中删除。
3. MainViewModel.RefreshShortcutsView 触发 ShortcutsChanged。
4. MainWindow.MainViewModel_ShortcutsChanged 触发 RefreshFactoryMap。
5. 地图重新根据当前快捷项列表构建。
6. 被删除快捷项对应节点不再生成。
7. 指向该节点或从该节点出发的连线因为节点不存在，不再显示。
8. 程序不会自动把前后节点重新连接。
```

说明：

```text
不自动重连是正确行为，因为程序无法判断工艺流程中删除某台设备后是否应该让前后设备直接相连。
```

## 9. 编辑快捷项后的地图行为

编辑菜单项复用主界面 `EditShortcutCommand`。

编辑后的行为：

```text
1. 编辑名称：地图节点文字随快捷项名称刷新。
2. 编辑备注：地图上通常不显示备注，视觉可能无变化。
3. 编辑目标路径：如果 TargetPath 变化，地图布局 Key 也变化，可能被视为新节点，位置可能回到默认位置。
```

说明：

```text
当前地图布局主要通过 TargetPath 匹配节点位置。
本次不改变这个匹配算法。
```

## 10. 与编辑模式的关系

浏览模式：

```text

```

注意：

```text

```

## 12. 风险点

### 12.1 右键菜单执行了错误快捷项

风险：

```text
用户右键地图节点 A，但当前主列表选中的是快捷项 B。
如果直接执行 MainViewModel 命令，可能误操作 B。
```

规避：

```text
右键节点弹出菜单前，必须先调用 selectShortcut(device.Shortcut)。
执行菜单项时，也必须再次确保 MainViewModel.SelectedShortcut 已经是该节点对应快捷项。
```

### 12.2 编辑模式与右键菜单冲突

风险：

```text
编辑模式中右键节点可能和地图编辑操作冲突。
```

规避：

```text
isEditMode == true 时直接不弹节点快捷项菜单。
```

### 12.3 删除节点导致连线消失

风险：

```text
用户可能以为删除的是地图节点，不知道快捷项也会被删除。
```

规避：

```text
当前继续复用主界面删除确认弹窗。
后续如有需要，可单独优化删除确认文案，提示“地图中对应节点及相关连线将不再显示”。
本次不强制修改弹窗文案，以保持最小改动。
```

## 13. 验收标准

本需求完成必须满足：

```text
1. 地图红色锁定浏览模式下，右键节点出现菜单。

5. 右键菜单操作对象必须是被右键的地图节点对应快捷项。
6. 编辑快捷项后地图刷新。
7. 删除快捷项后地图节点和相关连线消失。
8. 原有地图拖拽、缩放、多选、连线编辑功能不受影响。

```
