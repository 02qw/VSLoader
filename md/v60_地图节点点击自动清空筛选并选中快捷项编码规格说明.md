# v60 地图节点点击自动清空筛选并选中快捷项编码规格说明

## 1. 需求背景

当前 VSLoader 已经支持：

```text
1. 主界面快捷项列表支持搜索筛选。
2. 工厂地图中的设备节点和主界面快捷项一一对应。
3. 点击地图节点时，可以联动选中主界面对应快捷项。
4. 主界面选中快捷项时，地图对应节点可以高亮。
```

现在存在一个体验问题：

```text
当主界面搜索框有筛选条件时，主界面列表只显示匹配到的快捷项。
如果用户点击地图中一个没有出现在当前筛选结果里的节点，程序虽然能找到原始快捷项对象，但主界面 DataGrid 当前视图里没有这一行。
此时左侧主界面无法滚动并高亮显示该快捷项。
```

用户期望：

```text
点击地图节点是一个强定位行为。
当地图节点对应的快捷项被当前搜索条件过滤掉时，程序应自动清空搜索条件，然后在主界面中选中并高亮该快捷项。
```

## 2. 需求目标

本次目标：

```text
地图节点点击后，始终保证主界面可以显示并选中对应快捷项。
```

完成后：

```text
1. 主界面没有筛选条件时，点击地图节点保持原有行为。
2. 主界面存在筛选条件时，点击地图节点自动清空搜索框。
3. 搜索框清空后，主列表恢复显示全部快捷项。
4. 对应快捷项在主列表中被选中、高亮，并滚动到可见区域。
5. 不影响地图节点自身的选中/高亮逻辑。
```

## 3. 非目标范围

本次不实现：

```text
1. 修改搜索算法。
2. 修改中文首字母或拼音全拼匹配逻辑。
3. 修改 ShortcutSearchService。
4. 修改地图节点匹配算法。
5. 修改地图布局 JSON。
6. 修改快捷项数据结构。
7. 新增用户配置项。
8. 新增弹窗提示。
```

本次只做：

```text
地图节点点击联动主列表时，如果存在搜索条件，则自动清空搜索条件并完成选中。
```

### 4.3 地图节点点击联动主列表

位置：

```text
VSLoader/MainWindow.xaml.cs
```

当前方法：

```csharp
private void SelectShortcutFromMap(VSLoader.Models.ShortcutItem shortcut)
{
    if (DataContext is not MainViewModel viewModel)
    {
        return;
    }

    viewModel.SelectedShortcut = shortcut;
    ShortcutsGrid.SelectedItem = shortcut;
```

当前问题：

```text
如果 shortcut 被 SearchText 过滤掉，它不在 ShortcutsView 当前可见集合中。
此时 ScrollIntoView(shortcut) 无法让不可见项变成可见项。
```

## 5. 设计方案

### 5.1 最小改动位置

只修改：

```text
VSLoader/MainWindow.xaml.cs
```

具体修改：

```text
SelectShortcutFromMap(...)
```

不修改：

```text
FactoryMapWindow.xaml.cs
MainViewModel.cs
ShortcutSearchService.cs
MainWindow.xaml
```

### 5.2 目标流程

点击地图节点后：

```text
1. 进入 MainWindow.SelectShortcutFromMap(shortcut)。
2. 判断 DataContext 是否是 MainViewModel。
3. 如果 viewModel.SearchText 不为空白：
   3.1 设置 viewModel.SearchText = string.Empty。
   3.2 等待 WPF 列表视图刷新和 DataGrid 行生成。
4. 选中 shortcut。
5. 设置 ShortcutsGrid.SelectedItem = shortcut。
6. 调用 ShortcutsGrid.ScrollIntoView(shortcut)。
7. 让 ShortcutsGrid.Focus()。
```

### 5.3 推荐实现方式

推荐在 `SelectShortcutFromMap` 中拆出一个小方法：

```csharp
private void SelectShortcutInGrid(MainViewModel viewModel, VSLoader.Models.ShortcutItem shortcut)
{
    viewModel.SelectedShortcut = shortcut;
    ShortcutsGrid.SelectedItem = shortcut;
    ShortcutsGrid.ScrollIntoView(shortcut);
    ShortcutsGrid.Focus();
}
```

然后 `SelectShortcutFromMap` 负责处理筛选：

```csharp
private void SelectShortcutFromMap(VSLoader.Models.ShortcutItem shortcut)
{
    if (DataContext is not MainViewModel viewModel)
    {
        return;
    }

    if (!string.IsNullOrWhiteSpace(viewModel.SearchText))
    {
        viewModel.SearchText = string.Empty;
        Dispatcher.BeginInvoke(new Action(() =>
        {
            SelectShortcutInGrid(viewModel, shortcut);
        }), DispatcherPriority.Background);
        return;
    }

    SelectShortcutInGrid(viewModel, shortcut);
}
```

需要新增 using：

```csharp
using System.Windows.Threading;
```

如果当前文件已经有可用命名空间，则不重复添加。

### 5.4 为什么使用 Dispatcher.BeginInvoke

原因：

```text
SearchText 清空后，ShortcutsView 会刷新。
DataGrid 的可视行生成可能需要等到 Dispatcher 后续一轮。
如果立即 ScrollIntoView，偶发情况下可能仍然找不到刚恢复可见的行。
```

因此：

```text
清空筛选后，延迟一拍执行选中和滚动更稳。
```

建议 Dispatcher 优先级：

```csharp
DispatcherPriority.Background
```

或：

```csharp
DispatcherPriority.ContextIdle
```

推荐使用：

```csharp
DispatcherPriority.Background
```

## 6. 行为细节

### 6.1 搜索框为空时

如果：

```text
viewModel.SearchText 为空或空白字符串
```

则：

```text
不做清空动作。
直接执行原有选中逻辑。
```

### 6.2 搜索框有内容时

如果：

```text
viewModel.SearchText = "热贴机"
```

用户点击地图中一个不在当前筛选结果里的节点。

则：

```text
1. 搜索框自动变为空。
2. 主列表恢复显示全部快捷项。
3. 地图节点对应快捷项被选中并滚动到可见区域。
```

### 6.3 点击的节点原本就在筛选结果中

本次采用简单一致逻辑：

```text
只要 SearchText 不为空，点击地图节点就清空 SearchText。
```

理由：

```text
地图点击是强定位行为。
清空筛选后，用户可以看到该快捷项在全局列表中的位置。
逻辑简单，不需要判断该项是否已经在当前 ShortcutsView 中。
```

### 6.4 不弹提示

自动清空筛选不需要弹窗提示。

原因：

```text
这是用户点击地图节点后的自然定位动作。
搜索框文字变为空已经是明确反馈。
```

## 7. 风险与边界

### 7.1 不应影响地图高亮

主列表选中后会触发：

```text
MainViewModel.PropertyChanged -> SyncFactoryMapSelection()
```

地图对应节点仍应保持高亮。

### 7.2 不应改变排序

清空筛选只影响过滤，不应改变当前排序状态。

当前排序应继续由：

```text
CurrentSortField
CurrentSortDirection
```

控制。

### 7.3 不应修改快捷项数据

本次只修改 UI 选择和搜索条件，不修改：

```text
ShortcutItem.Name
ShortcutItem.TargetPath
ShortcutItem.Description
ShortcutItem.UpdatedAt
config.json
```

## 8. 手工验收

### 8.1 无筛选条件

步骤：

```text
1. 清空主界面搜索框。
2. 打开地图。
3. 点击任意地图节点。
```

期望：

```text
1. 主界面对应快捷项被选中。
2. 主列表滚动到该快捷项。
3. 地图节点保持高亮。
```

### 8.2 有筛选条件且目标不在筛选结果中

步骤：

```text
1. 在主界面搜索框输入一个条件，使列表只显示少量快捷项。
2. 点击地图中一个不在当前筛选结果中的节点。
```

期望：

```text
1. 搜索框自动清空。
2. 主列表恢复显示全部快捷项。
3. 被点击节点对应的快捷项在主列表中被选中并高亮。
4. 主列表滚动到该快捷项。
```

### 8.3 有筛选条件且目标原本就在筛选结果中

步骤：

```text
1. 在主界面搜索框输入条件。
2. 点击地图中当前筛选结果里也存在的节点。
```

期望：

```text
1. 搜索框仍自动清空。
2. 对应快捷项被选中。
3. 不出现错误提示。
```

### 8.4 排序不变

步骤：

```text
1. 点击主列表列头设置排序。
2. 输入搜索条件。
3. 点击地图节点。
```

期望：

```text
1. 搜索条件清空。
2. 列表排序状态不被重置。
3. 对应快捷项被选中。
```
