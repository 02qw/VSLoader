# v130 主窗口与工厂地图独立窗口及地图全局快捷键编码规格说明

## 1. 背景

当前 VSLoader 已经把工厂地图做成 `FactoryMapWindow`，具备独立窗口形态和任务栏窗口能力。

但从现有代码看，地图窗口在控制逻辑上仍然和主窗口强耦合：

```text
1. 主窗口最小化时会调用 HideFactoryMapWindow()，地图会跟随主窗口隐藏。
2. 主程序快捷键 ToggleWindowFromHotkey() 会顺带隐藏或恢复地图。
3. 主程序恢复时，如果地图处于打开状态，会优先激活地图。
4. 地图快捷键目前不是系统全局热键，而是通过 MainWindow / FactoryMapWindow 的 PreviewKeyDown 捕获。
5. MapHotkeyConfig 当前只支持一个无修饰键 Key，默认 M，不支持 Alt + X。
6. GlobalHotkeyService 当前只支持一个全局热键 ID，主要服务主程序快捷键。
```

这导致主窗口和地图窗口在最小化、恢复、前后台层级上互相影响，后续继续修补会越来越复杂。

本次需求要把两者彻底拆开：

```text
主窗口就是主窗口。
工厂地图就是工厂地图。
主窗口快捷键只控制主窗口。
地图快捷键只控制地图窗口。
```

## 2. 当前相关代码

### 2.1 主窗口

文件：

```text
VSLoader/MainWindow.xaml.cs
```

当前关键点：

```text
_hotkeyService.Initialize(this, ToggleWindowFromHotkey)
ToggleWindowFromHotkey()
RestoreAndActivate()
HideFactoryMapWindow()
RestoreFactoryMapForBackgroundActivation()
ShowFactoryMapIfNeeded()
MainWindow_StateChanged()
TryToggleFactoryMapFromHotkey(...)
```

当前主窗口快捷键逻辑会影响地图：

```csharp
HideFactoryMapWindow();
WindowState = WindowState.Minimized;
```

当前主窗口恢复逻辑也会影响地图：

```csharp
if (ShouldActivateFactoryMapWhenRestoringFromBackground(_isFactoryMapOpen))
{
    RestoreFactoryMapForBackgroundActivation();
    return;
}
```

### 2.2 工厂地图窗口

文件：

```text
VSLoader/Views/FactoryMapWindow.xaml.cs
```

当前构造函数接收：

```csharp
Func<WpfKeyEventArgs, bool>? tryToggleMapFromHotkey
```

并在 `PreviewKeyDown` 中转发地图快捷键：

```text
FactoryMapWindow_PreviewKeyDown
ShouldForwardMapHotkey(...)
tryToggleMapFromHotkey?.Invoke(e)
```

这说明地图快捷键仍然依赖当前窗口焦点，不是系统级全局热键。

### 2.3 主程序全局快捷键服务

文件：

```text
VSLoader/Models/Services/GlobalHotkeyService.cs
```

当前只有一个热键 ID：

```csharp
private const int HotkeyId = 0x5653;
```

`WndProc` 只处理一个热键：

```csharp
if (msg == WmHotkey && wParam.ToInt32() == HotkeyId)
{
    _hotkeyPressed?.Invoke();
}
```

因此当前结构无法同时注册：

```text
主窗口全局快捷键
地图全局快捷键
```

### 2.4 地图快捷键配置

文件：

```text
VSLoader/Models/MapHotkeyConfig.cs
VSLoader/Models/Services/MapHotkeyService.cs
```

当前配置：

```csharp
public bool Enabled { get; set; } = true;
public string Key { get; set; } = "M";
```

当前匹配规则：

```csharp
modifiers == ModifierKeys.None
```

因此当前只支持无修饰键单键，不支持默认需求 `Alt + X`。

## 3. 目标

本次目标：

- 主窗口和工厂地图窗口的显示、隐藏、最小化、恢复逻辑彻底独立。
- 主程序快捷键只控制主窗口，不再隐藏、恢复、激活地图。
- 工厂地图拥有独立全局快捷键，默认 `Alt + X`。
- 只要 VSLoader 进程还活着，地图快捷键就可以独立控制地图窗口。
- 地图快捷键可以在设置中配置。
- 地图快捷键行为符合独立窗口习惯：

```text
地图未打开：打开地图并置前。
地图已最小化：恢复地图并置前。
地图被其它程序遮挡：激活地图到前台。
地图已经处于前台活动窗口：最小化地图。
```

- 主窗口最小化只最小化主窗口，不影响地图。
- 地图最小化只最小化地图，不影响主窗口。
- 主窗口恢复只恢复主窗口，不影响地图。
- 程序退出或工作区切换时，仍然统一关闭地图，避免残留窗口。

## 4. 非目标

本次不做以下事项：

- 不改地图节点、连线、布局编辑、导入导出逻辑。
- 不改主窗口快捷键的配置 UI 样式，除非为了冲突校验做必要提示。
- 不改地图窗口视觉样式。
- 不新增多地图窗口。
- 不改变地图按钮的基本含义。
- 不改托盘图标视觉样式。
- 不引入复杂窗口层级持久化。
- 不再维护“主窗口恢复时地图在上还是主窗口在上”的旧层级快照逻辑。

## 5. 推荐设计

### 5.1 主窗口快捷键独立化

主程序快捷键只控制主窗口：

```text
主窗口不可见 / 最小化 / VSLoader 不在前台：
  显示并激活主窗口。

主窗口可见且主窗口本身处于活动状态：
  保存主窗口位置。
  最小化或隐藏主窗口。
```

需要移除或停止调用：

```text
ToggleWindowFromHotkey -> HideFactoryMapWindow()
RestoreAndActivate -> RestoreFactoryMapForBackgroundActivation()
MainWindow_StateChanged -> HideFactoryMapWindow()
MainWindow_StateChanged -> ShowFactoryMapIfNeeded()
```

保留：

```text
程序退出时 CloseFactoryMapForExit()
工作区切换时 CleanupForClose()
地图窗口自身位置保存
```

### 5.2 地图窗口独立化

地图窗口状态只由以下入口控制：

```text
1. 主界面地图按钮。
2. 地图窗口自己的最小化/关闭按钮。
3. 地图全局快捷键 Alt + X。
4. 程序退出/工作区切换的统一清理。
```

主窗口状态变化不再影响地图：

```text
主窗口最小化：地图保持当前状态。
主窗口恢复：地图保持当前状态。
主窗口隐藏到托盘：地图保持当前状态。
```

注意：

```text
如果用户选择从托盘彻底退出程序，地图必须关闭。
如果用户切换工作区，地图必须关闭，因为地图数据属于当前工作区。
```

### 5.3 地图快捷键行为

新增方法建议：

```csharp
private void ToggleFactoryMapFromGlobalHotkey()
```

行为顺序：

```text
1. 如果程序正在退出、已清理、工作区切换中：
   直接返回。

2. 如果 DataContext 不是 MainViewModel：
   直接返回。

3. 如果地图窗口不存在或已关闭：
   _isFactoryMapOpen = true;
   创建地图窗口；
   显示地图；
   恢复位置；
   刷新地图；
   激活地图；

4. 如果地图窗口 WindowState == Minimized：
   WindowState = Normal;
   Show();
   ActivateFactoryMapWindow();
   RefreshFactoryMap();

5. 如果地图窗口存在但不是前台活动窗口：
   Show();
   ActivateFactoryMapWindow();
   RefreshFactoryMap();

6. 如果地图窗口存在、可见、非最小化且 IsActive == true：
   SaveFactoryMapStateToSession(includeViewState: false);
   WindowState = Minimized;
```

前台判断第一版使用：

```csharp
_factoryMapWindow is { IsVisible: true, WindowState: not WindowState.Minimized, IsActive: true }
```

如果后续发现 WPF `IsActive` 不够准确，再引入 Win32 `GetForegroundWindow()` 比对地图窗口句柄。

### 5.4 地图按钮行为

主界面地图按钮继续保留“打开/关闭地图”的语义：

```text
地图未打开：打开地图。
地图已最小化：恢复地图。
地图已打开且正常显示：关闭地图。
```

原因：

```text
按钮是明确的主界面控制入口，继续沿用用户已有习惯。
Alt + X 是快速窗口切换入口，按前台状态执行最小化/恢复/激活。
```

### 5.5 全局快捷键服务支持两个热键

推荐扩展现有 `GlobalHotkeyService`，而不是新增完全重复服务。

原因：

```text
RegisterHotKey / UnregisterHotKey / WndProc / 校验逻辑已经存在。
扩展成多热键 ID 可以避免重复 Win32 代码。
```

建议设计：

```csharp
private const int MainHotkeyId = 0x5653;
private const int MapHotkeyId = 0x4D50;

private readonly Dictionary<int, Action> _keyboardHotkeyCallbacks = [];
```

提供方法：

```csharp
public void Initialize(Window window)
public SaveResult RegisterMainHotkey(HotkeyConfig config, Action callback)
public SaveResult RegisterMapHotkey(HotkeyConfig config, Action callback)
public void UnregisterMainHotkey()
public void UnregisterMapHotkey()
```

也可以保留旧方法兼容：

```csharp
Initialize(Window window, Action hotkeyPressed)
Register(HotkeyConfig config)
```

旧方法内部转发到 `RegisterMainHotkey`，减少调用面改动。

### 5.6 地图快捷键配置升级

将 `MapHotkeyConfig` 改成支持修饰键：

```csharp
public sealed class MapHotkeyConfig
{
    public bool Enabled { get; set; } = true;

    public bool Ctrl { get; set; }

    public bool Alt { get; set; } = true;

    public bool Shift { get; set; }

    public string Key { get; set; } = "X";
}
```

`Clone()` 需要包含全部字段。

`MapHotkeyService` 改为类似主程序快捷键校验：

```text
启用时必须有主键。
至少一个修饰键。
默认 Alt + X 合法。
Alt + F4 / Alt + Space 等高风险组合拦截。
支持 A-Z、0-9、F1-F12、Space。
第一版不支持鼠标侧键作为地图快捷键。
```

格式化：

```text
Alt + X
Ctrl + Alt + M
```

### 5.7 设置界面配置

设置页中地图快捷键需要支持：

```text
启用/禁用
Ctrl
Alt
Shift
主键
```

可以复用主程序快捷键的 UI 结构或 ViewModel 校验模式。

保存时必须：

```text
1. 校验主程序快捷键。
2. 校验地图快捷键。
3. 校验两个快捷键不能完全相同。
4. 尝试注册主程序快捷键。
5. 尝试注册地图快捷键。
6. 任一失败时给出明确错误，并回滚到原有可用配置。
```

如果当前项目的设置保存入口暂时只支持 `TryRegisterHotkey`，需要扩展为同时注册主程序和地图快捷键。

## 6. 关键边界规则

### 6.1 主窗口最小化

期望：

```text
只最小化主窗口。
不 Hide 地图。
不 Close 地图。
不激活地图。
```

### 6.2 地图窗口最小化

期望：

```text
只最小化地图窗口。
不影响主窗口。
不修改 _isFactoryMapOpen 为 false。
保存地图 RestoreBounds。
```

### 6.3 主程序快捷键

期望：

```text
只控制主窗口。
不再判断地图是否打开。
不再恢复地图。
不再激活地图。
不再隐藏地图。
```

### 6.4 地图快捷键 Alt + X

期望：

```text
地图不存在：打开并激活。
地图最小化：恢复并激活。
地图被遮挡：激活。
地图处于前台：最小化。
```

### 6.5 地图快捷键和文本输入

因为地图快捷键是系统全局热键，`Alt + X` 不依赖文本框焦点。

但要注意：

```text
如果设置页正在捕获快捷键输入，应避免触发真实地图切换。
如果地图窗口有模态弹窗打开，Alt + X 不应强制最小化地图导致弹窗丢失焦点。
```

建议第一版：

```text
如果存在活动模态窗口，地图快捷键不执行最小化，只执行必要的恢复/激活或直接忽略。
```

### 6.6 程序退出

期望：

```text
托盘退出 / RequestRealApplicationExit / 工作区切换：
  保存主窗口位置；
  保存地图窗口位置和视图；
  关闭地图窗口；
  注销主程序热键；
  注销地图热键；
  退出程序。
```

### 6.7 工作区切换

地图数据属于当前工作区，因此：

```text
切换工作区前必须关闭当前地图窗口。
新工作区打开后，地图默认关闭。
Alt + X 打开新工作区对应地图。
```

### 6.8 快捷键冲突

需要阻止：

```text
主程序快捷键和地图快捷键完全相同。
地图快捷键被系统或其它程序占用。
地图快捷键是高风险系统组合。
```

冲突提示要明确：

```text
地图快捷键注册失败，可能已被系统或其他程序占用，请更换快捷键。
主程序快捷键和地图快捷键不能相同。
```

## 9. 手工验证场景

### 9.1 主窗口最小化不影响地图

步骤：

```text
1. 打开主窗口。
2. 打开地图。
3. 点击主窗口最小化。
```

期望：

```text
主窗口最小化。
地图保持原状态。
```

### 9.2 地图最小化不影响主窗口

步骤：

```text
1. 打开主窗口。
2. 打开地图。
3. 点击地图最小化。
```

```text
地图进入任务栏最小化。
主窗口保持原状态。
```

## 11. 验收标准

实现完成后必须满足：

- 主窗口和地图窗口最小化互不影响。
- 主窗口恢复不恢复地图。
- 地图恢复不恢复主窗口。
- 主程序快捷键只控制主窗口。
- 地图快捷键默认是 `Alt + X`。
- 地图快捷键可以在设置中配置。
- `Alt + X` 在地图未打开时打开地图。
- `Alt + X` 在地图最小化时恢复地图。
- `Alt + X` 在地图后台时激活地图。
- `Alt + X` 在地图前台时最小化地图。
- 主程序退出或工作区切换时仍能关闭地图并保存状态。
- 主程序快捷键和地图快捷键冲突时不允许保存或注册。
- 地图快捷键被系统占用时有明确提示。
- 原有地图右键菜单、节点选择、地图布局保存不被破坏。
- 定向测试通过。
- 全量测试通过。
- Debug 构建通过。
