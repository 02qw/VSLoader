# v144 地图连线右键菜单与折点编辑基础编码规格说明

## 1. 背景

v143 已经完成连线折点的基础能力：

```text
FactoryMapDeviceEdge 支持 Points。
FactoryMapDeviceEdgeViewData 支持 Points。
factory-map.layout.json 能保存/加载 points。
FactoryMapWindow 渲染时优先使用手动 Points。
没有 Points 的旧连线仍使用当前自动中折线。
```

本阶段继续推进第二步：

```text
让用户能通过连线右键菜单编辑折点。
```

本阶段仍然不做折点拖动控制点，不做自动分叉/汇流识别，不做自动避障。

目标是先让用户可以：

```text
右键连线 -> 添加折点
右键连线 -> 清除折点
右键连线 -> 删除连线
```

添加折点后，用户可以通过多次右键添加折点，手动构造视觉分叉/汇流所需的折线路径。

## 3. 目标行为

### 3.1 添加折点

用户在编辑模式下右键某条连线，点击“添加折点”：

```text
1. 使用用户右键点击位置作为折点候选坐标。
2. 将坐标转换到 MapCanvas 坐标系。
3. 坐标按 10px 网格吸附。
4. 将折点插入到距离点击位置最近的线段之后。
5. 保存布局。
6. 重新渲染地图。
7. 状态栏提示“折点已添加。”
```

说明：

```text
添加折点不是简单追加到 Points 末尾。
必须插入最近线段，否则多折线编辑会越来越难控制。
```

### 3.2 清除折点

用户在编辑模式下右键某条连线，点击“清除折点”：

```text
1. 清空 edge.Points。
2. 保存布局。
3. 重新渲染地图。
4. 连线恢复默认自动中折线。
5. 状态栏提示“折点已清除，连线已恢复自动路径。”
```

如果该连线没有折点：

```text
菜单项可禁用。
```

### 3.3 删除连线

保留当前行为：

```text
右键连线 -> 删除连线
```

只需要确保菜单顺序调整为：

```text
添加折点
清除折点
删除连线
```

## 4. 数据与兼容边界

本阶段不新增新模型。

继续使用 v143 的：

```csharp
FactoryMapDeviceEdge.Points
FactoryMapDeviceEdgeViewData.Points
FactoryMapPoint
```

保存仍由：

```text
FactoryMapLayoutService.Save / SaveToFile
```

负责。

要求：

```text
1. 添加折点后必须立即保存到 factory-map.layout.json。
2. 清除折点后必须立即保存。
3. 保存失败时保留内存改动，但弹窗提示保存失败。
4. 不影响旧 From/To 连线。
```

## 5. 最近线段插入算法

### 5.1 获取当前连线路径

新增或复用 helper：

```csharp
private static List<WpfPoint> GetEditableEdgePoints(FactoryMapDeviceEdgeViewData edge)
```

返回值：

```text
起点 + 当前有效 Points + 终点
```

注意：

```text
用于编辑插入时应使用非 inset 的完整端点路径。
否则最近线段计算会和命中线略有偏差。
```

### 5.2 计算点到线段距离

新增 helper：

```csharp
internal static double CalculatePointToSegmentDistanceSquared(
    WpfPoint point,
    WpfPoint segmentStart,
    WpfPoint segmentEnd)
```

规则：

```text
1. 对投影参数 t 做 0..1 clamp。
2. 使用平方距离，避免频繁 Math.Sqrt。
3. 退化线段长度为 0 时，按点到 segmentStart 的距离计算。
```

### 5.3 插入位置

新增 helper：

```csharp
internal static int GetInsertPointIndex(
    FactoryMapDeviceEdgeViewData edge,
    WpfPoint clickPoint)
```

含义：

```text
返回应插入 edge.Points 的索引。
```

规则：

```text
路径点为：start + points + end。
如果最近线段是 path[i] -> path[i + 1]：
    插入到 edge.Points 的 index = i。
```

例子：

```text
start -> end
最近线段 i=0
插入 points[0]

start -> p0 -> end
最近线段 start -> p0，i=0，插入 points[0]
最近线段 p0 -> end，i=1，插入 points[1]
```

## 6. 坐标转换与网格吸附

### 6.1 点击坐标

`Edge_PreviewMouseRightButtonDown` 中已经能拿到命中线 Polyline。

本阶段应记录右键点击位置：

```csharp
var clickPoint = e.GetPosition(MapCanvas);
```

传给菜单项：

```text
Tag 中不仅要放 edge，还要放 clickPoint。
```

建议新增 payload：

```csharp
private sealed record EdgeContextMenuPayload(
    FactoryMapDeviceEdgeViewData Edge,
    WpfPoint ClickPoint);
```

如果需要区分菜单动作，也可以新增：

```csharp
private sealed record EdgeContextMenuPayload(
    FactoryMapDeviceEdgeViewData Edge,
    WpfPoint ClickPoint,
    FactoryMapEdgeMenuAction Action);
```

### 6.2 网格吸附

新增 helper：

```csharp
private static FactoryMapPoint SnapEdgePointToGrid(WpfPoint point)
```

规则：

```text
X = FactoryMapEditMath.ClampAndSnapToGrid(point.X, SnapGridSize)
Y = FactoryMapEditMath.ClampAndSnapToGrid(point.Y, SnapGridSize)
```

说明：

```text
本阶段沿用节点的 clamp 规则。
如果后续地图支持负坐标，再统一调整节点和折点 clamp 策略。
```

## 7. 菜单实现要求

### 7.1 菜单项顺序

右键连线菜单按顺序：

```text
添加折点
清除折点
删除连线
```

### 7.2 清除折点启用规则

```text
edge.Points 有有效点时启用。
edge.Points 为空或只有无效点时禁用。
```

### 7.3 菜单风格

继续使用当前：

```csharp
ApplyModernContextMenuStyle(menu)
ApplyModernMenuItemStyle(item, isDanger: ...)
```

其中：

```text
添加折点：普通样式
清除折点：普通样式
删除连线：危险样式
```

## 8. 保存与错误处理

添加/清除折点后应复用现有保存方式：

```csharp
if (!saveLayout(currentMap))
{
    dialogService.ShowError("折点已添加，但地图布局保存失败。");
    return;
}
```

建议提示：

```text
添加折点保存失败：折点已添加，但地图布局保存失败。
清除折点保存失败：折点已清除，但地图布局保存失败。
```

说明：

```text
与现有删除连线逻辑保持一致：
内存先更新，然后保存失败时提示用户。
不做自动回滚。
```

## 9. 本阶段不做的内容

本阶段不做：

```text
1. 不显示折点控制点。
2. 不支持拖动折点。
3. 不支持删除单个折点。
4. 不支持多选连线。
5. 不支持自动分叉/汇流。
6. 不支持自动避障。
7. 不支持右键“对齐到同一分叉点/汇流点”。
8. 不改变节点连线创建方式。
```

## 10. 测试要求

建议新增或更新：

```text

VSLoader.Tests/FactoryMapWindowSourceTests.cs
```

如果已有 source test 文件可复用，优先复用。
