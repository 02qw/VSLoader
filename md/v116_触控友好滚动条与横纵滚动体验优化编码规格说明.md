# v116 触控友好滚动条与横纵滚动体验优化编码规格说明

## 1. 背景

当前 VSLoader 多个窗口中存在纵向滚动条和横向滚动条：

- 主界面快捷项列表 `DataGrid`
- 批量新增识别结果 `DataGrid`
- 设置窗口 `ScrollViewer`
- 工作区选择窗口 `ListBox`
- 快捷项编辑窗口备注多行 `TextBox`

这些控件主要依赖 WPF 默认滚动行为。默认行为对鼠标滚轮基本可用，但对触控板、触摸屏、横向手势和手指拖动的支持偏弱，表现为：

- 触控拖动滚动不自然。
- 横向滚动区域命中困难。
- 滚动条太窄，不适合手指或触控板精细操作。
- 部分输入控件会吃掉滚轮事件，设置页之前已经通过 `PreviewMouseWheel` 做过补偿，但触控平移仍不完整。

因此需要做一轮统一的滚动体验优化。

## 2. 目标

本次目标：

- 为主要滚动区域启用 WPF 触控平移能力。
- 优化纵向和横向滚动条的命中面积。
- 保持当前现代化 UI 风格，不回到系统默认粗糙滚动条。
- 支持触控板/触摸屏下的纵向滑动和横向滑动。
- 不破坏 DataGrid 虚拟化性能。
- 不影响地图画布已有的缩放、拖拽、节点移动逻辑。

## 3. 非目标

本次不做以下事项：

- 不引入第三方滚动控件库。
- 不重写 DataGrid。
- 不改地图画布的缩放、拖拽、节点编辑算法。
- 不做惯性物理动画引擎。
- 不改变列表数据排序、筛选、选择逻辑。
- 不改变列宽持久化逻辑。

## 4. 当前代码分析

### 4.1 主界面 DataGrid

位置：

```text
VSLoader/MainWindow.xaml
```

当前快捷项表格使用：

```xml
<DataGrid
    ScrollViewer.CanContentScroll="True"
    EnableColumnVirtualization="True"
    EnableRowVirtualization="True"
    VirtualizingPanel.IsVirtualizing="True"
    VirtualizingPanel.VirtualizationMode="Recycling" />
```

优点：

- 虚拟化已开启，性能基础较好。
- 已支持横向滚动条，因为列宽可能超过可视区域。

不足：

- 未显式配置 `ScrollViewer.PanningMode`。
- 未配置触控平移比例。
- 滚动条样式未统一做触控友好尺寸。

### 4.2 批量新增识别 DataGrid

位置：

```text
VSLoader/Views/BatchImportWindow.xaml
```

当前结果表格列较多，存在横向滚动需求。

不足：

- 未显式启用横纵触控平移。
- 未显式配置虚拟化和触控滚动附加属性。

### 4.3 设置窗口 ScrollViewer

位置：

```text
VSLoader/Views/SettingsWindow.xaml
VSLoader/Views/SettingsWindow.xaml.cs
```

当前设置页外层有：

```xml
<ScrollViewer x:Name="SettingsScrollViewer"
              VerticalScrollBarVisibility="Auto">
```

并且输入框上已经通过：

```csharp
SettingsInput_PreviewMouseWheel
```

将鼠标滚轮转交给外层 ScrollViewer。

不足：

- 未启用 `PanningMode`。
- 触控拖动输入框区域时，体验可能仍不如鼠标滚轮。
- 仅处理了 MouseWheel，不等价于完整触控平移。

### 4.4 工作区选择 ListBox

位置：

```text
VSLoader/Views/WorkspaceSelectorWindow.xaml
```

当前工作区列表：

```xml
<ListBox
    ScrollViewer.VerticalScrollBarVisibility="Auto">
```

不足：

- 未启用触控平移。
- 工作区卡片较大，适合触控点击，但滚动容器没有对应增强。

### 4.5 快捷项编辑备注 TextBox

位置：

```text
VSLoader/Views/ShortcutEditWindow.xaml
```

备注框使用：

```xml
VerticalScrollBarVisibility="Auto"
```

该控件自身是可编辑文本区，内部滚动属于 TextBox 自身行为。

处理原则：

- 不强行将备注框滚动全部转交给外层。
- 只通过公共滚动条样式改善命中面积和视觉。

### 4.6 地图画布

位置：

```text
VSLoader/Views/FactoryMapWindow.xaml
VSLoader/Views/FactoryMapWindow.xaml.cs
```

地图没有使用 ScrollViewer，而是自己处理：

- 鼠标滚轮缩放
- 空白区域拖拽平移
- 节点拖拽
- 多选节点拖拽

处理原则：

- 地图不套 ScrollViewer。
- 不把地图画布纳入本次普通滚动条优化。
- 后续如果要增强触控缩放/双指平移，应单独出地图触控手势规格。

## 5. 推荐方案

### 5.1 新增公共触控滚动样式

在：

```text
VSLoader/Styles/ModernTheme.xaml
```

新增或扩展以下样式：

```xml
ModernScrollViewerStyle
ModernScrollBarStyle
```

目标：

- 统一滚动条视觉。
- 增大滚动条触控命中面积。
- 保持现代浅色风格。

建议尺寸：

```text
Vertical ScrollBar Width: 14
Horizontal ScrollBar Height: 14
Thumb 最小长度: 28
Track 背景: #F1F5F9
Thumb 默认: #CBD5E1
Thumb Hover: #94A3B8
Thumb Pressed: #64748B
```

说明：

- 14px 比默认滚动条更容易命中。
- 仍然不会像系统经典滚动条那样笨重。
- 横向滚动条同样加高，方便触控板/手指拖动。

### 5.2 为 ScrollViewer 启用触控平移

在主要 ScrollViewer 上启用：

```xml
PanningMode="Both"
PanningRatio="1.0"
PanningDeceleration="0.001"
```

推荐公共样式：

```xml
<Setter Property="PanningMode" Value="Both" />
<Setter Property="PanningRatio" Value="1" />
<Setter Property="PanningDeceleration" Value="0.001" />
```

对仅纵向滚动页面，例如设置窗口，可以使用：

```xml
PanningMode="VerticalOnly"
```

但为减少样式数量，也可以使用 `Both`，由内容尺寸决定是否横向可滚。

### 5.3 DataGrid 显式开启横纵平移

在 `ModernDataGridStyle` 中增加：

```xml
<Setter Property="ScrollViewer.PanningMode" Value="Both" />
<Setter Property="ScrollViewer.PanningRatio" Value="1" />
<Setter Property="ScrollViewer.PanningDeceleration" Value="0.001" />
<Setter Property="ScrollViewer.HorizontalScrollBarVisibility" Value="Auto" />
<Setter Property="ScrollViewer.VerticalScrollBarVisibility" Value="Auto" />
```

保留现有虚拟化：

```xml
ScrollViewer.CanContentScroll="True"
VirtualizingPanel.IsVirtualizing="True"
VirtualizingPanel.VirtualizationMode="Recycling"
```

不要为了触控滚动关闭虚拟化。

### 5.4 SettingsWindow 外层 ScrollViewer

设置页外层 ScrollViewer 建议改为：

```xml
Style="{StaticResource ModernScrollViewerStyle}"
PanningMode="VerticalOnly"
VerticalScrollBarVisibility="Auto"
```

保留现有 `SettingsInput_PreviewMouseWheel`。

原因：

- 该事件解决的是鼠标滚轮在输入框上不向外层滚动的问题。
- `PanningMode` 解决的是触控拖动体验。
- 两者互补，不冲突。

### 5.5 WorkspaceSelectorWindow ListBox

为工作区列表增加：

```xml
ScrollViewer.PanningMode="VerticalOnly"
ScrollViewer.PanningRatio="1"
ScrollViewer.PanningDeceleration="0.001"
```

工作区列表只需要纵向滚动，不需要横向滚动。

### 5.6 BatchImportWindow DataGrid

批量新增识别结果表格列多，应支持横向触控平移。

建议增加：

```xml
ScrollViewer.PanningMode="Both"
ScrollViewer.HorizontalScrollBarVisibility="Auto"
ScrollViewer.VerticalScrollBarVisibility="Auto"
```

并确认仍使用 `ModernDataGridStyle`。

### 5.7 TextBox 内部滚动

`ModernMultilineTextBoxStyle` 内部使用 `ScrollViewer x:Name="PART_ContentHost"`。

对于 TextBox，不建议强行统一 `PanningMode` 到内部 `PART_ContentHost`，因为 TextBox 文本选择、光标拖动、触控编辑行为更复杂。

本次只通过全局 `ScrollBar` 样式优化其滚动条命中面积。

如果后续备注框触控滚动仍不佳，再单独针对多行 TextBox 设计。

## 7. 编码要求

### 7.1 滚动条样式

滚动条样式应满足：

- 支持横向和纵向。
- 不显示传统上下箭头按钮，或将箭头按钮压缩为 0，减少视觉噪音。
- Track 背景轻。
- Thumb 圆角。
- Hover/Pressed 有明显但克制的反馈。
- 尺寸适合触控，不低于 12px，推荐 14px。

### 7.2 触控平移属性

对 DataGrid / ScrollViewer / ListBox 明确设置：

```xml
PanningMode
PanningRatio
PanningDeceleration
```

注意 DataGrid/ListBox 要使用附加属性：

```xml
ScrollViewer.PanningMode="Both"
```

或：

```xml
ScrollViewer.PanningMode="VerticalOnly"
```

### 7.3 不破坏虚拟化

主界面 DataGrid 必须保留：

```xml
EnableColumnVirtualization="True"
EnableRowVirtualization="True"
VirtualizingPanel.IsVirtualizing="True"
VirtualizingPanel.VirtualizationMode="Recycling"
```

不要把 `ScrollViewer.CanContentScroll` 改成 `False`。

### 7.4 地图不纳入本次滚动条体系

地图画布当前不是 ScrollViewer。不要为了触控滚动给地图套 ScrollViewer。

地图已经有自定义：

- 缩放
- 平移
- 节点拖拽
- 多选拖拽

如果把地图套进普通滚动容器，会和现有逻辑冲突。

## 9. 验收标准

满足以下条件即完成：

- 主界面快捷项列表可通过触控板/触摸屏更自然地纵向滚动。
- 主界面快捷项列表在横向内容溢出时，横向滚动条更容易拖动。
- 批量新增识别结果表格横向滚动更容易操作。
- 设置页触控拖动滚动更自然，原有鼠标滚轮转交逻辑不失效。
- 工作区列表触控纵向滚动更自然。
- 现代化滚动条视觉和项目整体 UI 风格一致。

- 地图画布缩放、拖拽、节点编辑不受影响。

- `dotnet build .\VSLoader.sln -c Debug --no-restore` 通过。

## 10. 风险与边界

### 10.1 WPF 触控支持边界

WPF 的 `PanningMode` 能改善触摸屏平移和部分触控板体验，但不同硬件、驱动、Windows 设置可能表现不同。

本次优化目标是提升基础体验，不承诺达到原生 UWP/WinUI 那种完整触控惯性体验。

### 10.2 DataGrid 横向滚动和列宽调整

主界面支持用户调整列宽并持久化。

滚动优化不能影响：

- 列宽拖拽
- 列宽保存
- 横向滚动条出现逻辑

### 10.3 TextBox 编辑冲突

多行 TextBox 同时涉及：

- 文本选择
- 光标定位
- 内部滚动

本次只改滚动条视觉和命中面积，不强行接管 TextBox 触控手势。

### 10.4 地图手势冲突

地图已有专门的鼠标滚轮缩放和拖拽平移。

不要把普通 ScrollViewer 手势套到地图上，否则可能造成：

- 地图滚轮缩放失效
- 空白区域拖拽冲突
- 节点拖拽误触

地图触控手势应单独设计。
