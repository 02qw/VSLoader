# v113 地图独立任务栏窗口与主快捷键联动编码规格说明

## 1. 背景

当前工厂地图窗口最初被设计为主窗口的附属窗口：

```text
FactoryMapWindow
```

其核心设计目标是：

```text
主窗口通过程序快捷键隐藏 / 恢复时，地图窗口也能一起消失 / 出现。
```

因此当前地图窗口具有以下特征：

```xml
ShowInTaskbar="False"
```

并且创建窗口时：

```csharp
Owner = this
```

同时主窗口监听地图窗口 `StateChanged`，当地图窗口进入最小化状态时，将其等同为用户关闭地图：

```csharp
internal static bool ShouldCloseFactoryMapOnStateChanged(WindowState state)
{
    return state == WindowState.Minimized;
}
```

该设计来自 v105：

```text
地图窗口最小化等同关闭
```

当时这样做是为了解决附属窗口 `ShowInTaskbar=False` 时最小化后变成屏幕底部小窗口的问题。

但现在由于 v111/v112 已经自绘了现代标题栏，地图窗口右上角保留了最小化、最大化/还原、关闭三个按钮。用户自然会按照普通产品语义理解：

```text
最小化：缩到任务栏
最大化：占满屏幕工作区
还原：恢复原窗口
关闭：关闭窗口
```

当前实际行为与用户预期不一致：

- 地图点击最小化并不会正常最小化到任务栏。
- 地图最小化被主窗口拦截成关闭地图。
- 地图最大化 / 还原时容易让用户误解当前窗口到底是不是独立窗口。
- 地图标题栏按钮语义和普通产品不一致。

用户现在希望重构地图窗口关系：

```text
地图窗口获得独立窗口能力，可以正常最小化到任务栏；
但必须保留主窗口程序快捷键一键带着地图一起隐藏 / 恢复的能力。
```

## 2. 目标

本次目标是将地图窗口从“附属窗口行为”重构为：

```text
系统窗口行为上独立；
业务生命周期上仍由主窗口统一管理。
```

完成后：

- 地图窗口显示在任务栏。
- 地图窗口点击最小化后，正常最小化到任务栏。
- 地图窗口点击任务栏图标后，可以正常恢复。
- 地图窗口点击最大化 / 还原，遵循普通窗口语义。
- 地图窗口点击关闭 X，仍表示关闭地图。
- 主窗口程序快捷键隐藏主程序时，地图窗口也一起隐藏。
- 主窗口程序快捷键恢复主程序时，如果地图之前是打开状态，地图也一起恢复。
- 地图快捷键仍保持“打开 / 关闭地图”的语义。
- 主程序快捷键仍保持“显示 / 隐藏主程序，并联动地图”的语义。
- 保留地图窗口位置、大小、缩放、平移状态保存逻辑。

## 3. 非目标

本次不做：

- 不重做地图节点、连线、缩放、拖拽、编辑功能。
- 不改变地图 JSON 格式。
- 不改变地图布局文件导入导出格式。
- 不改变主窗口最小化到托盘逻辑。
- 不改变程序真正退出流程。
- 不把地图快捷键改成 Windows 全局快捷键。
- 不改变程序全局快捷键配置格式。
- 不新增复杂多窗口管理框架。
- 不新增多显示器高级策略，只沿用现有工作区 Clamp 逻辑。

## 4. 当前代码定位

### 4.1 地图窗口 XAML

文件：

```text
VSLoader/Views/FactoryMapWindow.xaml
```

当前：

```xml
ShowInTaskbar="False"
```

这意味着地图窗口不会显示在任务栏。

### 4.2 地图窗口创建

文件：

```text
VSLoader/MainWindow.xaml.cs
```

当前创建逻辑：

```csharp
_factoryMapWindow = new FactoryMapWindow(...)
{
    Owner = this,
    DataContext = DataContext
};
```

其中：

```csharp
Owner = this
```

使地图窗口成为主窗口 owned window。

### 4.3 地图窗口最小化拦截

当前：

```csharp
_factoryMapWindow.StateChanged += FactoryMapWindow_StateChanged;
```

对应逻辑：

```csharp
private void FactoryMapWindow_StateChanged(object? sender, EventArgs e)
{
    if (sender is not FactoryMapWindow window || !ShouldCloseFactoryMapOnStateChanged(window.WindowState))
    {
        return;
    }

    CloseFactoryMapByUserAction();
}
```

当前静态判断：

```csharp
internal static bool ShouldCloseFactoryMapOnStateChanged(WindowState state)
{
    return state == WindowState.Minimized;
}
```

本次需要废弃该语义。

### 4.4 主程序快捷键

当前入口：

```csharp
private void ToggleWindowFromHotkey()
```

隐藏路径中当前会：

```csharp
SaveMainWindowBoundsToSession();
HideFactoryMapWindow();
WindowState = WindowState.Minimized;
```

恢复路径中当前会：

```csharp
RestoreAndActivate();
```

其中 `RestoreAndActivate()` 最后调用：

```csharp
ShowFactoryMapIfNeeded();
```

该联动能力必须保留。

### 4.5 地图快捷键

当前入口：

```csharp
private bool TryToggleFactoryMapFromHotkey(KeyEventArgs e)
```

符合条件后调用：

```csharp
ToggleFactoryMapWindow();
```

地图窗口内部也会通过构造参数：

```csharp
Func<KeyEventArgs, bool>? tryToggleMapFromHotkey
```

把地图快捷键转交给主窗口处理。

该设计必须保留。

## 5. 产品语义重定义

本次后地图窗口语义如下：

### 5.1 地图窗口最小化

用户点击地图窗口最小化：

```text
地图窗口进入 Windows 正常最小化状态。
任务栏出现地图窗口图标。
_isFactoryMapOpen 保持 true。
WasFactoryMapOpen 保持 true。
不关闭地图窗口。
不清空 _factoryMapWindow。
```

### 5.2 地图窗口任务栏恢复

用户从任务栏点击地图窗口：

```text
地图窗口从 Minimized 恢复到 Normal 或 Maximized。
地图内容、缩放、平移、窗口大小尽量保持原状态。
```

### 5.3 地图窗口关闭 X

用户点击地图窗口 X：

```text
表示关闭地图。
保存地图状态。
_isFactoryMapOpen = false。
WasFactoryMapOpen = false。
关闭并清空 _factoryMapWindow。
```

### 5.4 主界面“地图”按钮

用户点击主界面地图按钮：

```text
地图未打开：打开地图。
地图已打开且可见或最小化：关闭地图。
地图已临时隐藏：恢复地图或关闭地图，取决于当前 _isFactoryMapOpen 和用户动作路径。
```

建议简化为：

```text
如果 _isFactoryMapOpen == true 且 _factoryMapWindow 存在：
    点击地图按钮 = 用户主动关闭地图。
否则：
    点击地图按钮 = 打开地图。
```

这样地图按钮仍然是“打开 / 关闭地图”，不是“显示 / 隐藏地图”。

### 5.5 地图快捷键

地图快捷键保持和地图按钮一致：

```text
打开 / 关闭地图。
```

如果地图窗口已经最小化到任务栏，按地图快捷键应视为“关闭地图”。

原因：

```text
地图快捷键语义一直是开关地图，不是恢复最小化窗口。
```

### 5.6 主程序快捷键

主程序快捷键保持：

```text
显示 / 隐藏 VSLoader 主程序。
```

同时联动地图：

隐藏主程序时：

```text
如果地图处于打开状态，不管地图当前是 Normal / Maximized / Minimized，都临时隐藏地图。
不把 _isFactoryMapOpen 改成 false。
```

恢复主程序时：

```text
如果 _isFactoryMapOpen == true，则恢复地图窗口。
如果地图隐藏前是最小化状态，也建议恢复显示到 Normal 或 RestoreBounds 对应状态。
```

本次采用用户确认的产品倾向：

```text
主程序快捷键恢复主程序时，也恢复地图窗口。
```

## 6. 状态模型设计

当前已有：

```csharp
private FactoryMapWindow? _factoryMapWindow;
private bool _isFactoryMapOpen;
private readonly RuntimeLayoutState _runtimeLayoutState = new();
```

本次建议新增运行期字段：

```csharp
private bool _isFactoryMapHiddenByMainWindow;
```

语义：

```text
地图是否因为主窗口隐藏 / 主窗口快捷键 / 主窗口最小化而临时隐藏。
```

不要用 `_isFactoryMapOpen` 表示临时隐藏。

建议状态含义：

```text
_isFactoryMapOpen：
    用户是否认为地图是打开的。
    地图最小化时仍为 true。
    主窗口临时隐藏地图时仍为 true。
    用户关闭地图时才为 false。

_isFactoryMapHiddenByMainWindow：
    地图是否被主窗口临时隐藏。
    主窗口恢复时用于决定是否 Show 地图。

_factoryMapWindow：
    当前地图窗口实例。
    最小化时不为 null。
    主窗口临时隐藏时不为 null。
    用户关闭地图或程序退出后为 null。
```

## 7. 核心改造方案

### 7.1 让地图成为任务栏窗口

修改：

```text
VSLoader/Views/FactoryMapWindow.xaml
```

从：

```xml
ShowInTaskbar="False"
```

改为：

```xml
ShowInTaskbar="True"
```

或直接删除该属性，使用 WPF 默认值 `True`。

建议显式保留：

```xml
ShowInTaskbar="True"
```

让语义清楚。

### 7.2 移除 Owner 绑定

修改：

```text
VSLoader/MainWindow.xaml.cs
```

创建地图窗口时，从：

```csharp
_factoryMapWindow = new FactoryMapWindow(...)
{
    Owner = this,
    DataContext = DataContext
};
```

改为：

```csharp
_factoryMapWindow = new FactoryMapWindow(...)
{
    DataContext = DataContext
};
```

原因：

- 独立任务栏窗口不应作为主窗口 owned window。
- Owned window 可能跟随 owner 最小化 / 激活 / z-order，和独立窗口语义冲突。
- 主窗口和地图联动由业务代码控制，不依赖 WPF Owner。

### 7.3 停止最小化转关闭

移除或改写：

```csharp
_factoryMapWindow.StateChanged += FactoryMapWindow_StateChanged;
```

以及：

```csharp
FactoryMapWindow_StateChanged
ShouldCloseFactoryMapOnStateChanged
```

推荐保留 `FactoryMapWindow_StateChanged` 方法，但语义改为只保存状态，不关闭窗口：

```csharp
private void FactoryMapWindow_StateChanged(object? sender, EventArgs e)
{
    if (sender is not FactoryMapWindow)
    {
        return;
    }

    SaveFactoryMapStateToSession(includeViewState: false);
}
```

如果不需要，可直接取消订阅。

注意：

- 地图最小化后 `_isFactoryMapOpen` 必须仍为 true。
- `Closed` 回调才表示用户关闭地图。

### 7.4 地图窗口关闭事件区分用户关闭与程序关闭

当前 `Closed` 回调中会：

```csharp
SaveFactoryMapStateToSession();
_isFactoryMapOpen = false;
_runtimeLayoutState.WasFactoryMapOpen = false;
_factoryMapWindow = null;
```

该逻辑仍适合“用户点击 X”。

但 `CloseFactoryMapByUserAction()` 会先手动设置 `_factoryMapWindow = null` 再 Close。需保持幂等。

建议新增字段：

```csharp
private bool _isClosingFactoryMapByCode;
```

但为降低复杂度，也可以保持现有幂等结构：

```csharp
var window = _factoryMapWindow;
_factoryMapWindow = null;
window.Close();
```

Closed 回调中如果 `_factoryMapWindow is null`，仍只需保存失败时不异常即可。

建议更清晰地抽方法：

```csharp
private void MarkFactoryMapClosedByUser()
{
    _isFactoryMapOpen = false;
    _isFactoryMapHiddenByMainWindow = false;
    _runtimeLayoutState.WasFactoryMapOpen = false;
}
```

## 8. 主程序快捷键联动设计

### 8.1 隐藏主程序时

当前：

```csharp
HideFactoryMapWindow();
WindowState = WindowState.Minimized;
```

改造 `HideFactoryMapWindow()`：

```csharp
private void HideFactoryMapWindow()
{
    SaveFactoryMapStateToSession();
    if (_factoryMapWindow is not null)
    {
        _isFactoryMapHiddenByMainWindow = true;
        _factoryMapWindow.Hide();
    }
}
```

注意：

- 不改 `_isFactoryMapOpen`。
- 不改 `WasFactoryMapOpen` 为 false。
- 如果地图当前已最小化，也仍保存 `RestoreBounds`。

### 8.2 恢复主程序时

`RestoreAndActivate()` 当前最后会：

```csharp
ShowFactoryMapIfNeeded();
```

保留该调用。

改造 `ShowFactoryMapIfNeeded()`：

```text
如果 !_isFactoryMapOpen：return。
如果主窗口不可见或最小化：return。
如果地图窗口不存在：创建地图窗口。
如果地图窗口存在但隐藏：Show。
如果地图窗口存在且 WindowState == Minimized：
    WindowState = Normal。
Show / Activate 地图窗口。
RefreshFactoryMap。
_isFactoryMapHiddenByMainWindow = false。
```

注意：

- 如果地图窗口隐藏前是 Maximized，恢复时是否保持 Maximized 可由 `WindowState` 自己保留。
- 如果地图窗口被主程序快捷键临时隐藏前是 Minimized，本次建议恢复到 Normal，保证“一键一起出现”体验。

### 8.3 主窗口最小化到托盘

主窗口 `MainWindow_StateChanged` 当前：

```csharp
if (WindowState == WindowState.Minimized)
{
    SaveMainWindowBoundsToSession();
    HideFactoryMapWindow();
    return;
}

ShowFactoryMapIfNeeded();
```

该思路保留。

但需要确保：

```text
地图是 Hide，不是 Close。
_isFactoryMapOpen 仍为 true。
```

## 9. 地图按钮与地图快捷键设计

### 9.1 ToggleFactoryMapWindow

当前：

```csharp
if (_factoryMapWindow is { IsVisible: true })
{
    CloseFactoryMapByUserAction();
    return;
}

_isFactoryMapOpen = true;
_runtimeLayoutState.WasFactoryMapOpen = true;
ShowFactoryMapIfNeeded();
```

本次建议改为基于 `_isFactoryMapOpen`：

```csharp
private void ToggleFactoryMapWindow()
{
    if (_isFactoryMapOpen)
    {
        CloseFactoryMapByUserAction();
        return;
    }

    _isFactoryMapOpen = true;
    _isFactoryMapHiddenByMainWindow = false;
    _runtimeLayoutState.WasFactoryMapOpen = true;
    ShowFactoryMapIfNeeded();
}
```

原因：

- 地图窗口最小化时 `IsVisible` 可能仍为 true 或状态不符合用户语义。
- 地图窗口被 Hide 时 `IsVisible` 为 false，但 `_isFactoryMapOpen` 仍为 true。
- 地图按钮 / 地图快捷键应基于“用户是否打开地图”的状态判断。

### 9.2 CloseFactoryMapByUserAction

用户主动关闭地图时：

```csharp
private void CloseFactoryMapByUserAction()
{
    if (_factoryMapWindow is null)
    {
        _isFactoryMapOpen = false;
        _isFactoryMapHiddenByMainWindow = false;
        _runtimeLayoutState.WasFactoryMapOpen = false;
        return;
    }

    SaveFactoryMapStateToSession();
    _isFactoryMapOpen = false;
    _isFactoryMapHiddenByMainWindow = false;
    _runtimeLayoutState.WasFactoryMapOpen = false;
    var window = _factoryMapWindow;
    _factoryMapWindow = null;
    window.Close();
}
```

### 9.3 地图最小化后按地图快捷键

地图已经最小化到任务栏时，按地图快捷键：

```text
执行 CloseFactoryMapByUserAction。
```

理由：

```text
地图快捷键语义是打开 / 关闭，不是恢复。
```

如果未来用户希望地图快捷键在最小化时恢复地图，可另做需求。

## 10. 地图位置与视图状态保存

### 10.1 保存 Bounds

当前 `SaveFactoryMapStateToSession` 已处理：

```csharp
var sourceBounds = _factoryMapWindow.WindowState == WindowState.Minimized
    ? _factoryMapWindow.RestoreBounds
    : new Rect(...);
```

该逻辑需要保留。

原因：

```text
地图最小化到任务栏时，Left/Top/ActualWidth/ActualHeight 可能不是可用窗口大小。
RestoreBounds 才是恢复前尺寸。
```

### 10.2 最大化状态

当前 RuntimeLayoutState 保存的是位置、大小、视图，没有显式保存：

```text
FactoryMapWindowState
```

本次第一阶段不强制新增状态字段。

建议行为：

```text
如果地图最大化后隐藏，再恢复，WPF 自身通常保留 WindowState。
如果窗口被关闭后重建，则按保存 Bounds 恢复 Normal 状态。
```

如果后续发现用户强需求保持最大化状态，可新增字段：

```csharp
public WindowState FactoryMapWindowState { get; set; }
```

本次暂不做，避免扩大配置和持久化改动。

## 11. 主窗口与地图激活关系

由于移除 `Owner = this`，地图窗口不会天然跟随主窗口前置。

本次推荐：

- 主程序快捷键恢复时，先恢复主窗口，再显示地图。
- 地图显示后可以不强制抢焦点。
- 如果用户是通过地图快捷键打开地图，可以允许地图显示但主窗口仍可保持激活。

推荐 `ShowFactoryMapIfNeeded()` 中：

```csharp
_factoryMapWindow.Show();
if (_factoryMapWindow.WindowState == WindowState.Minimized)
{
    _factoryMapWindow.WindowState = WindowState.Normal;
}
```

不强制：

```csharp
_factoryMapWindow.Activate();
```

除非手动验证发现地图窗口被其他窗口遮挡严重。

## 12. 标题栏焦点框顺手修复

当前地图标题栏最大化/还原按钮点击后会出现 WPF 默认虚线焦点框。

该问题来自：

```text
VSLoader/Styles/ModernWindowChrome.xaml
```

`ModernTitleBarButtonStyle` 未设置：

```xml
FocusVisualStyle="{x:Null}"
```

本次可顺手加入：

```xml
<Setter Property="FocusVisualStyle" Value="{x:Null}" />
```

适用于所有现代标题栏按钮。

这是视觉修复，不影响业务逻辑。

## 14. 手动验证清单

### 14.1 地图独立任务栏行为

1. 启动 VSLoader。
2. 点击“地图”按钮打开地图。
3. 确认任务栏中出现地图窗口。
4. 点击地图窗口最小化按钮。
5. 地图应正常最小化到任务栏。
6. 点击任务栏地图图标。
7. 地图应正常恢复。
8. 地图不应被主窗口自动关闭。

### 14.2 地图最大化 / 还原

1. 打开地图。
2. 点击最大化。
3. 地图应占满可用工作区，不遮挡任务栏。
4. 底部状态栏仍可见。
5. 点击还原。
6. 地图恢复原窗口大小。
7. 右上角按钮不出现虚线焦点框。

### 14.3 地图关闭语义

1. 打开地图。
2. 点击地图窗口 X。
3. 地图关闭。
4. 再点击主界面“地图”按钮。
5. 地图重新打开。

### 14.4 地图按钮 / 地图快捷键

1. 地图关闭时点击地图按钮，地图打开。
2. 地图打开时点击地图按钮，地图关闭。
3. 地图关闭时按地图快捷键，地图打开。
4. 地图打开时按地图快捷键，地图关闭。
5. 地图最小化到任务栏时按地图快捷键，地图关闭。

### 14.5 主程序快捷键联动

1. 打开主窗口和地图。
2. 调整地图窗口大小、位置、缩放、平移。
3. 按程序快捷键隐藏主窗口。
4. 地图也应一起隐藏。
5. 再按程序快捷键恢复主窗口。
6. 地图也应一起恢复。
7. 地图位置、大小、缩放、平移尽量保持隐藏前状态。

### 14.6 主窗口托盘行为

1. 打开主窗口和地图。
2. 点击主窗口 X 最小化到托盘。
3. 地图也应隐藏。
4. 从托盘恢复主窗口。
5. 如果地图之前打开，地图应恢复。
6. 托盘右键退出程序，无残留地图窗口。

## 15. 风险与规避

### 15.1 移除 Owner 后地图不跟随主窗口

风险：

```text
地图窗口不再天然跟随主窗口最小化 / 前置。
```

规避：

```text
通过 MainWindow 显式 Hide / Show 地图。
主程序快捷键和托盘恢复都调用 ShowFactoryMapIfNeeded。
```

### 15.2 地图最小化后状态保存错误

风险：

```text
最小化时保存 ActualWidth/ActualHeight 可能不准确。
```

规避：

```text
继续使用 RestoreBounds 保存最小化前窗口位置大小。
```

### 15.3 地图按钮语义和最小化语义混淆

风险：

```text
地图窗口最小化后，点击地图按钮到底恢复还是关闭。
```

本次明确：

```text
地图按钮和地图快捷键是打开 / 关闭地图。
地图任务栏图标负责恢复最小化窗口。
```

### 15.4 主程序快捷键和地图快捷键冲突

风险：

```text
主程序快捷键隐藏程序时误把 _isFactoryMapOpen 改成 false。
```

规避：

```text
主程序快捷键只 Hide 地图，不 Close 地图。
只有地图按钮、地图快捷键、地图 X 才把 _isFactoryMapOpen 改成 false。
```
