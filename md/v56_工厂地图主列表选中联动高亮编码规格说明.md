# v56 工厂地图主列表选中联动高亮编码规格说明

## 1. 需求背景

当前 VSLoader 工厂地图已经支持：

```text
1. 点击地图节点后，左侧主列表快捷项会被选中并高亮。
2. 地图节点支持编辑、连线、多选、整体拖动。
3. 地图节点在多选、连线起点等场景下有蓝色视觉状态。
```

现在需要补齐反向联动：

```text
当用户在左侧主列表选中某个快捷项时，右侧地图中对应的节点也应该自动蓝色高亮。
```

目标效果：

```text
左侧主列表选中 “热贴机_001”
右侧地图中对应 “热贴机_001” 的节点显示浅蓝色填充和蓝色边框
```

## 2. 需求目标

本次实现目标：

```text
实现主列表选中快捷项与工厂地图节点的双向视觉联动。
```

完成后：

1. 点击地图节点，左侧快捷项仍然会被选中。
2. 点击左侧快捷项，右侧地图对应节点也会被高亮。
3. 地图窗口已打开时，高亮实时更新。
4. 地图窗口未打开时，不做额外操作。
5. 地图刷新、导入图文件、快捷项列表变化后，仍能保持当前主列表选中项的地图高亮。
6. 不破坏连线模式、多选模式、节点拖拽和键盘微调。

## 3. 非目标范围

本次不实现：

```text
1. 地图自动滚动到高亮节点。
2. 地图自动缩放到高亮节点。
3. 多节点同时跟随主列表高亮。
4. 主列表多选。
5. 地图节点闪烁动画。
6. 高亮颜色自定义配置。
```

本次只实现：

```text
主列表当前 SelectedShortcut 对应单个地图节点的视觉高亮。
```

## 4. 匹配规则

主列表快捷项和地图节点的匹配必须使用：

```text
ShortcutItem.TargetPath
```

匹配规范：

```text
1. Trim()
2. 忽略大小写
```

不使用：

```text
1. Name
2. Description
3. 文件夹名
4. 模糊匹配
```

原因：

```text
名称可能变化，TargetPath 是当前项目中最稳定的快捷项身份标识。
```

## 5. 视觉状态优先级

地图节点现在可能同时处于多种状态。

必须按以下优先级渲染：

```text
连线起点 > 多选节点选中 > 主列表选中联动高亮 > 普通节点
```

含义：

```text
1. 如果节点是连线起点，显示连线起点样式。
2. 否则如果节点在多选集合里，显示多选选中样式。
3. 否则如果节点匹配主列表 SelectedShortcut，显示主列表联动高亮样式。
4. 否则显示普通样式。
```

主列表联动高亮样式建议：

```text
浅蓝色填充
蓝色边框
2px 边框
```

可以复用现有多选节点选中样式。

## 6. MainWindow 侧改造

### 6.1 监听 SelectedShortcut 变化

当前 `MainWindow` 已经在 `Loaded` 中订阅：

```csharp
viewModel.ShortcutsChanged += MainViewModel_ShortcutsChanged;
```

本次需要同时监听 `MainViewModel.PropertyChanged`：

```csharp
viewModel.PropertyChanged += MainViewModel_PropertyChanged;
```

在窗口关闭或 DataContext 切换时需要避免重复订阅。

当前已有字段：

```csharp
private bool _isViewModelEventsAttached;
```

可以复用这个字段，保证只订阅一次。

### 6.2 变化处理

新增处理方法：

```csharp
private void MainViewModel_PropertyChanged(object? sender, PropertyChangedEventArgs e)
{
    if (e.PropertyName == nameof(MainViewModel.SelectedShortcut))
    {
        SyncFactoryMapSelection();
    }
}
```

同步方法：

```csharp
private void SyncFactoryMapSelection()
{
    if (_factoryMapWindow is null || DataContext is not MainViewModel viewModel)
    {
        return;
    }

    _factoryMapWindow.HighlightShortcut(viewModel.SelectedShortcut);
}
```

说明：

```text
即使地图窗口当前 Hide，也可以更新内部状态。
如果地图窗口还没创建，不需要做任何事。
```

### 6.3 地图刷新后同步

`RefreshFactoryMap()` 调用 `_factoryMapWindow.RenderMap(loadResult.Map)` 后，必须继续同步当前选中项：

```csharp
SyncFactoryMapSelection();
```

原因：

```text
RenderMap 会重建 MapCanvas 子元素。
重建后需要重新应用主列表选中态。
```

### 6.4 从地图点击节点时避免问题

已有逻辑：

```csharp
private void SelectShortcutFromMap(ShortcutItem shortcut)
{
    viewModel.SelectedShortcut = shortcut;
    ShortcutsGrid.SelectedItem = shortcut;
    ShortcutsGrid.ScrollIntoView(shortcut);
    ShortcutsGrid.Focus();
}
```

该逻辑会触发 `SelectedShortcut` 的 PropertyChanged，从而回调地图高亮。

这是正确行为，不需要阻止。

## 7. FactoryMapWindow 侧改造

### 7.1 新增字段

```csharp
private ShortcutItem? externallyHighlightedShortcut;
```

或仅保存 key：

```csharp
private string? externallyHighlightedShortcutKey;
```

推荐保存 key：

```text
减少对象引用依赖，只按 TargetPath 匹配。
```

字段：

```csharp
private string? highlightedShortcutKey;
```

### 7.2 新增公开方法

```csharp
public void HighlightShortcut(ShortcutItem? shortcut)
{
    highlightedShortcutKey = string.IsNullOrWhiteSpace(shortcut?.TargetPath)
        ? null
        : shortcut.TargetPath.Trim();

    RefreshDeviceSelectionVisuals();
}
```

说明：

```text
如果 shortcut 为 null，则清空主列表联动高亮。
```

### 7.3 渲染时应用

当前节点绘制后会调用类似：

```csharp
ApplyDeviceNormalVisual(border);
```

并且后续有：

```csharp
RefreshDeviceSelectionVisuals()
```

本次需要在 `RefreshDeviceSelectionVisuals()` 中增加主列表高亮判断。

伪代码：

```csharp
private void RefreshDeviceSelectionVisuals()
{
    foreach (var (device, border) in elementByDevice)
    {
        if (pendingConnectionStart is not null && IsSameDevice(pendingConnectionStart, device))
        {
            ApplyDeviceConnectionStartVisual(border);
        }
        else if (selectedDevices.Contains(device))
        {
            ApplyDeviceSelectedVisual(border);
        }
        else if (IsHighlightedShortcut(device))
        {
            ApplyDeviceHighlightedVisual(border);
        }
        else
        {
            ApplyDeviceNormalVisual(border);
        }
    }
}
```

### 7.4 匹配方法

```csharp
private bool IsHighlightedShortcut(FactoryMapDeviceViewNode device)
{
    return !string.IsNullOrWhiteSpace(highlightedShortcutKey)
        && string.Equals(
            device.Key?.Trim(),
            highlightedShortcutKey,
            StringComparison.OrdinalIgnoreCase);
}
```

### 7.5 高亮样式

可以复用：

```csharp
ApplyDeviceSelectedVisual(border)
```

也可以新增：

```csharp
private static void ApplyDeviceHighlightedVisual(Border border)
```

推荐新增方法，方便后续调整主列表联动高亮颜色。

建议：

```csharp
private static void ApplyDeviceHighlightedVisual(Border border)
{
    border.Background = new SolidColorBrush(WpfColor.FromRgb(239, 246, 255));
    border.BorderBrush = new SolidColorBrush(WpfColor.FromRgb(59, 130, 246));
    border.BorderThickness = new Thickness(2);
}
```

## 8. 与多选模式的关系

主列表联动高亮不应改变多选集合。

也就是说：

```text
左侧选中快捷项，只影响地图节点视觉，不把节点加入 selectedDevices。
```

如果用户处于多选模式：

```text
1. 多选节点的蓝色选中态优先。
2. 主列表联动高亮仍记录，但视觉上可能被多选态覆盖。
3. 退出多选或清空多选后，如果该节点仍是主列表选中项，应继续显示主列表高亮。
```

## 9. 与连线模式的关系

主列表联动高亮不应影响连线起点。

如果某节点同时是：

```text
连线起点 + 主列表选中项
```

显示：

```text
连线起点样式
```

清空连线起点后，如果该节点仍匹配主列表选中项，应恢复为主列表联动高亮样式。

## 10. 与地图刷新/导入的关系

以下操作后必须重新应用联动高亮：

```text
1. RenderMap。
2. RenderCurrentMap。
3. 导入图文件成功后。
4. 快捷项列表变化后刷新地图。
```

最简单做法：

```text
每次 DrawDevice 后记录 elementByDevice。
RenderCurrentMap 结束后调用 RefreshDeviceSelectionVisuals。
MainWindow.RefreshFactoryMap 后调用 SyncFactoryMapSelection。
```

## 12. 手工验收

### 12.1 左侧选中同步右侧地图

1. 打开 VSLoader。
2. 打开地图窗口。
3. 在左侧快捷项列表点击某个快捷项。
4. 观察右侧地图中对应节点变成浅蓝色高亮。

### 12.2 切换左侧选中项

1. 左侧点击快捷项 A。
2. 地图节点 A 高亮。
3. 左侧点击快捷项 B。
4. 地图节点 A 恢复普通样式。
5. 地图节点 B 高亮。

### 12.3 地图点击仍能同步左侧

1. 点击右侧地图节点 C。
2. 左侧快捷项 C 被选中。
3. 地图节点 C 保持高亮。

### 12.4 多选模式优先级

1. 左侧选中快捷项 A。
2. 地图节点 A 高亮。
3. 进入多选模式并框选节点 A、B。
4. A、B 显示多选选中态。
5. 退出多选模式。
6. 如果左侧仍选中 A，则 A 继续显示主列表联动高亮。

### 12.5 连线模式优先级

1. 左侧选中快捷项 A。
2. 地图节点 A 高亮。
3. 进入连线模式。
4. 点击 A 作为连线起点。
5. A 显示连线起点样式。
6. 取消起点。
7. A 恢复主列表联动高亮。

### 12.6 地图刷新后保持

1. 左侧选中快捷项 A。
2. 打开地图，A 高亮。
3. 导入图文件或触发地图刷新。
4. A 仍然高亮。
