# v37 搜索框中文首字母检索编码规格说明

## 1. 需求背景

当前 VSLoader 主界面的搜索框只支持普通字符串搜索。用户必须输入快捷项名称、目标路径或备注中已经存在的原文内容，才能筛选出对应快捷项。

随着快捷项数量增加，很多快捷项名称是中文设备名称，例如：

- `热贴机_012`
- `银烧结_005`
- `自动点锡机_012`
- `银烧结NG抓取装置_003`

用户希望可以直接输入中文名称的拼音首字母进行检索，例如输入 `rt`、`rtj`、`ysj`、`zddxj`，快速定位对应快捷项。

本次需求是在不改变现有搜索框 UI 的前提下，增强主界面搜索能力。

## 2. 需求目标

在主界面搜索框中新增中文拼音首字母检索能力。

实现后搜索框应同时支持：

1. 原有原文搜索。
2. 英文、数字、符号的普通字符串搜索。
3. 中文字段的拼音首字母搜索。
4. 中文、英文、数字混合内容的组合搜索。

示例：

| 字段原文 | 生成的首字母搜索串 | 用户输入 | 预期结果 |
| --- | --- | --- | --- |
| `热贴机_012` | `rtj_012` | `rt` | 匹配 |
| `热贴机_012` | `rtj_012` | `rtj` | 匹配 |
| `热贴机_012` | `rtj_012` | `rtj012` | 匹配 |
| `银烧结_005` | `ysj_005` | `ysj` | 匹配 |
| `自动点锡机_012` | `zddxj_012` | `zddxj` | 匹配 |
| `银烧结NG抓取装置_003` | `ysjngzqzz_003` | `ysjng` | 匹配 |

## 3. 非目标范围

本次不实现以下内容：

1. 不修改搜索框 UI。
2. 不新增搜索模式开关。
3. 不新增配置项。
4. 不实现完整拼音搜索，例如输入 `retieji` 匹配 `热贴机`。
5. 不实现多音字人工纠错。
6. 不改变列表排序逻辑。
7. 不改变批量新增识别页面的搜索或预览逻辑。

## 4. 当前代码现状

当前主界面搜索逻辑位于：

`VSLoader/ViewModels/MainViewModel.cs`

核心逻辑：

```csharp
private bool FilterShortcut(object item)
{
    if (item is not ShortcutItem shortcut)
    {
        return false;
    }

    var keyword = SearchText.Trim();
    if (string.IsNullOrEmpty(keyword))
    {
        return true;
    }

    return Contains(shortcut.Name, keyword)
        || Contains(shortcut.TargetPath, keyword)
        || Contains(shortcut.Description, keyword);
}

private static bool Contains(string source, string keyword)
{
    return source.Contains(keyword, StringComparison.OrdinalIgnoreCase);
}
```

当前搜索字段包括：

- `ShortcutItem.Name`
- `ShortcutItem.TargetPath`
- `ShortcutItem.Description`

## 5. 推荐技术方案

采用方案 A：引入成熟拼音 NuGet 包，并封装独立搜索服务。

推荐新增服务：

`VSLoader/Models/Services/ShortcutSearchService.cs`

职责：

1. 接收字段原文和搜索关键词。
2. 保留原有普通字符串匹配。
3. 将中文字符转换为拼音首字母。
4. 对首字母串执行包含匹配。
5. 对搜索串进行规范化处理，提升用户输入容错。

主界面 `MainViewModel` 不直接处理拼音算法，只调用搜索服务。

## 6. NuGet 依赖

建议引入一个支持 .NET 8 的拼音转换库。

候选库：

- `NPinyin`
- 或其他稳定、轻量、支持中文转拼音首字母的 NuGet 包

编码 Agent 实现时应优先选择：

1. 支持 `net8.0-windows`。
2. 能够从中文字符串生成拼音或首字母。
3. API 简单，依赖轻量。

如果采用 `NPinyin`，需要在 `VSLoader/VSLoader.csproj` 中添加类似依赖：

```xml
<PackageReference Include="NPinyin" Version="版本号" />
```

具体版本由编码时可用的 NuGet 版本确定。

## 7. 匹配字段规则

本次建议规则：

1. `Name` 支持原文搜索和拼音首字母搜索。
2. `Description` 支持原文搜索和拼音首字母搜索。
3. `TargetPath` 保留原有普通字符串搜索即可。

原因：

- 名称和备注更可能包含中文设备名。
- 目标路径通常包含英文、数字、下划线、网络路径，不需要转换拼音。
- 避免对长路径频繁做拼音转换，减少无意义开销。

最终过滤逻辑应等价于：

```csharp
return _shortcutSearchService.IsTextMatch(shortcut.Name, keyword)
    || Contains(shortcut.TargetPath, keyword)
    || _shortcutSearchService.IsTextMatch(shortcut.Description, keyword);
```

## 8. 搜索规范化规则

为了让用户输入更自然，搜索服务应做规范化处理。

### 8.1 普通原文搜索

继续使用不区分大小写的包含匹配：

```text
source.Contains(keyword, StringComparison.OrdinalIgnoreCase)
```

示例：

- 输入 `热贴` 匹配 `热贴机_012`
- 输入 `TSSM` 匹配目标路径或名称中的 `TSSM`
- 输入 `ng` 匹配 `银烧结NG抓取装置`

### 8.2 拼音首字母搜索

中文转首字母后执行包含匹配。

示例：

```text
热贴机_012 -> rtj_012
```

输入 `rt`、`rtj`、`rtj012` 均应匹配。

### 8.3 忽略分隔符

拼音首字母匹配时，建议忽略以下分隔符：

- 空格
- `_`
- `-`
- `.`

示例：

```text
热贴机_012 -> rtj012
```

用户输入：

```text
rtj012
```

应匹配。

注意：普通原文搜索仍保留原行为，不需要强制忽略符号。

## 10. 性能要求

MVP 阶段不强制做缓存。

原因：

- 当前快捷项数量预计较小。
- 搜索只发生在主列表过滤时。
- 服务逻辑简单，性能压力有限。

但实现时应避免明显低效写法：

1. 不要在每次字符拼接时大量使用 `string +=`。
2. 中文转首字母时使用 `StringBuilder`。
3. 搜索字段为空时尽早返回。

后续如果快捷项数量明显增加，可以再引入缓存字段或搜索索引。

## 11. MainViewModel 改造要求

`MainViewModel` 当前已有多个服务依赖，新增搜索服务时应保持现有构造函数风格。

建议新增字段：

```csharp
private readonly ShortcutSearchService _shortcutSearchService;
```

默认构造函数中创建：

```csharp
new ShortcutSearchService()
```

完整构造函数中接收：

```csharp
ShortcutSearchService shortcutSearchService
```

过滤逻辑改为：

```csharp
return _shortcutSearchService.IsTextMatch(shortcut.Name, keyword)
    || Contains(shortcut.TargetPath, keyword)
    || _shortcutSearchService.IsTextMatch(shortcut.Description, keyword);
```

保留现有 `Contains` 方法用于目标路径普通搜索。

## 12. 异常处理

拼音转换不应导致主界面搜索崩溃。

要求：

1. 如果拼音库转换某个字符失败，应保留原字符或跳过该字符。
2. `IsTextMatch` 不应向外抛出异常。
3. 搜索失败时应退化为原有普通字符串搜索能力。

## 13. 验收场景

完成后至少验证以下场景：

1. 搜索框为空时，显示全部快捷项。
2. 输入中文原文 `热贴`，可以匹配 `热贴机_012`。
3. 输入首字母 `rt`，可以匹配 `热贴机_012`。
4. 输入完整首字母 `rtj`，可以匹配 `热贴机_012`。
5. 输入首字母加编号 `rtj012`，可以匹配 `热贴机_012`。
6. 输入 `ysj`，可以匹配 `银烧结_005`。
7. 输入 `zddxj`，可以匹配 `自动点锡机_012`。
8. 输入 `ng`，可以通过原文搜索匹配 `银烧结NG抓取装置_003`。
9. 输入目标路径中的英文或数字，仍然可以通过原有路径搜索匹配。
10. 输入不存在的关键词，不显示无关快捷项。

## 16. 风险说明

1. 多音字结果以拼音库默认结果为准，本次不做人工纠错。
2. 不同拼音库对个别汉字的首字母结果可能略有差异。
3. 如果后续快捷项数量非常大，可能需要增加搜索缓存，但本次不提前实现。
