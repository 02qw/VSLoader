# v28 最小化到托盘与托盘退出编码规格说明

## 1. 需求背景

当前 VSLoader 是普通 WPF 桌面程序。

用户点击主窗口右上角关闭按钮 `X` 时，程序会真正关闭。

现在希望 VSLoader 更像一个常驻启动器：

```text
点击 X -> 不退出程序 -> 隐藏到系统托盘
```

程序隐藏到托盘后仍然需要继续运行，并继续监听已配置的全局快捷键。

只有用户在系统托盘图标上右键点击 `退出`，程序才真正关闭。

## 2. 需求目标

本次开发目标：

1. 用户点击窗口右上角 `X` 时，不真正退出程序。
2. 点击 `X` 后主窗口隐藏到系统托盘。
3. 系统托盘区显示 VSLoader 图标。
4. 托盘图标右键菜单提供 `显示 VSLoader` 和 `退出`。
5. 点击 `显示 VSLoader` 可以恢复并激活主窗口。
6. 点击 `退出` 才真正关闭程序。
7. 程序隐藏到托盘时，全局快捷键仍然有效。
8. 程序隐藏到托盘时，按快捷键可以恢复并激活主窗口。
9. 真正退出时释放全局快捷键和托盘图标资源。

## 3. 用户交互规则

### 3.1 点击右上角 X

操作：

```text
用户点击窗口右上角关闭按钮 X
```

期望：

```text
窗口隐藏
程序进程继续运行
托盘区保留 VSLoader 图标
全局快捷键继续监听
```

不弹出确认退出提示。

### 3.2 托盘右键菜单

托盘图标右键菜单包含：

```text
显示 VSLoader
退出
```

点击 `显示 VSLoader`：

```text
恢复主窗口
激活主窗口
置于前台
```

点击 `退出`：

```text
真正关闭程序
释放全局快捷键
销毁托盘图标
进程退出
```

### 3.3 双击托盘图标

推荐支持：

```text
双击托盘图标 -> 显示 VSLoader
```

该行为符合 Windows 常见托盘程序习惯。

### 3.4 快捷键行为

程序隐藏到托盘后，快捷键仍然需要生效。

快捷键触发规则沿用 v26：

```text
如果窗口最小化或隐藏：恢复窗口 + 激活
如果窗口当前前台激活：最小化窗口
如果窗口在后台：恢复/置前
```

本次需要特别补充：

```text
如果窗口处于 Hide 状态，按快捷键应 Show + Restore + Activate
```


## 6. MainWindow 新增字段

在 `MainWindow.xaml.cs` 中新增字段：

```csharp
private readonly GlobalHotkeyService _hotkeyService = new();
private System.Windows.Forms.NotifyIcon? _notifyIcon;
private bool _isExitRequested;
```

说明：

- `_notifyIcon` 保存托盘图标实例。
- `_isExitRequested` 用于区分“用户点 X 隐藏”和“托盘菜单点退出”。

## 7. 初始化托盘图标

在 `MainWindow` 构造函数或 `Loaded` 事件中初始化托盘图标。

推荐新增方法：

```csharp
private void InitializeTrayIcon()
{
    _notifyIcon = new System.Windows.Forms.NotifyIcon
    {
        Icon = new System.Drawing.Icon("Assets\\tomato.ico"),
        Text = "VSLoader",
        Visible = true,
        ContextMenuStrip = CreateTrayMenu()
    };

    _notifyIcon.DoubleClick += (_, _) => RestoreAndActivate();
}
```

注意：

- 图标路径要保证运行时可以访问。
- 如果直接使用相对路径，需要确认工作目录是程序输出目录。
- 更稳妥的方式是基于 `AppContext.BaseDirectory` 拼接：

```csharp
var iconPath = Path.Combine(AppContext.BaseDirectory, "Assets", "tomato.ico");
```

由于项目当前 `tomato.ico` 是 `Resource`，如果输出目录没有该文件，需要改为从程序集资源或窗口 Icon 获取。

推荐实现时优先检查当前构建输出中是否存在：

```text
bin\Debug\net8.0-windows\Assets\tomato.ico
```

如果不存在，应调整 `.csproj`：

```xml
<Resource Include="Assets\tomato.ico" />
```

改为或额外添加可复制输出：

```xml
<Content Include="Assets\tomato.ico">
  <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
</Content>
```

但注意不要破坏应用图标配置：

```xml
<ApplicationIcon>Assets\tomato.ico</ApplicationIcon>
```

## 8. 托盘菜单

推荐新增方法：

```csharp
private System.Windows.Forms.ContextMenuStrip CreateTrayMenu()
{
    var menu = new System.Windows.Forms.ContextMenuStrip();

    var showItem = new System.Windows.Forms.ToolStripMenuItem("显示 VSLoader");
    showItem.Click += (_, _) => RestoreAndActivate();

    var exitItem = new System.Windows.Forms.ToolStripMenuItem("退出");
    exitItem.Click += (_, _) => ExitApplication();

    menu.Items.Add(showItem);
    menu.Items.Add(exitItem);

    return menu;
}
```

## 9. 拦截关闭按钮

当前代码使用：

```csharp
Closed += MainWindow_Closed;
```

本次需要新增：

```csharp
Closing += MainWindow_Closing;
```

推荐逻辑：

```csharp
private void MainWindow_Closing(object? sender, CancelEventArgs e)
{
    if (_isExitRequested)
    {
        return;
    }

    e.Cancel = true;
    Hide();
}
```

说明：

- 用户点 `X` 时，`_isExitRequested` 为 `false`。
- 所以取消关闭，执行 `Hide()`。
- 程序继续运行，托盘图标继续存在。
- 全局快捷键仍然存在，因为窗口没有真正 `Closed`。

## 10. 真正退出

新增方法：

```csharp
private void ExitApplication()
{
    _isExitRequested = true;
    Close();
}
```

流程：

```text
托盘菜单点击退出
-> _isExitRequested = true
-> Close()
-> Closing 不再拦截
-> Closed 释放资源
```

## 11. 释放资源

当前 `MainWindow_Closed` 中已有：

```csharp
_hotkeyService.Dispose();
```

本次需要扩展：

```csharp
private void MainWindow_Closed(object? sender, EventArgs e)
{
    _hotkeyService.Dispose();

    if (_notifyIcon is not null)
    {
        _notifyIcon.Visible = false;
        _notifyIcon.Dispose();
        _notifyIcon = null;
    }
}
```

说明：

- 真正退出时释放全局快捷键。
- 真正退出时移除托盘图标。
- 避免程序退出后托盘残留图标。

## 12. RestoreAndActivate 修改

当前 `RestoreAndActivate()` 需要兼容隐藏状态。

推荐逻辑：

```csharp
private void RestoreAndActivate()
{
    Show();

    if (WindowState == WindowState.Minimized)
    {
        WindowState = WindowState.Normal;
    }

    Activate();
    Topmost = true;
    Topmost = false;
    Focus();
}
```

关键点：

- 先 `Show()`，保证隐藏状态可以重新显示。
- 再处理最小化恢复。
- 最后激活置前。

## 13. ToggleWindowFromHotkey 修改

当前 v26 逻辑大致是：

```csharp
if (WindowState == WindowState.Minimized)
{
    RestoreAndActivate();
    return;
}

if (IsActive)
{
    WindowState = WindowState.Minimized;
    return;
}

RestoreAndActivate();
```

本次需要兼容隐藏到托盘后的状态：

```csharp
if (!IsVisible || WindowState == WindowState.Minimized)
{
    RestoreAndActivate();
    return;
}

if (IsActive)
{
    WindowState = WindowState.Minimized;
    return;
}

RestoreAndActivate();
```

说明：

- `Hide()` 后 `IsVisible == false`。
- 快捷键触发时应恢复窗口。

## 14. 是否将最小化按钮也隐藏到托盘

本次需求明确的是：

```text
点击叉号关闭程序窗口的时候会最小化到托盘区
```

因此本次不强制改变最小化按钮行为。

默认规则：

```text
点击最小化按钮 -> 普通最小化到任务栏
点击 X -> 隐藏到托盘
```

后续如果用户希望最小化按钮也隐藏到托盘，可以另开需求。

## 15. 任务栏显示规则

本次不强制修改：


- 点击 X 隐藏到托盘后，因为窗口被 `Hide()`，任务栏自然不显示。
- 托盘图标仍然显示。
